# Research Memory

The rehearsal workspace's global memory, a placeholder that only a rehearsal
export holds: the tables a workspace's programs read, with the example project
as the one portfolio row. It holds no one's research.

* [MEMORY.md](MEMORY.md) - Research Policy, Active Projects, and Key Decisions.
* [paper-sources.json](paper-sources.json) - On/off switches for the literature sources `paper-search` may query; empty, so every source keeps its default.

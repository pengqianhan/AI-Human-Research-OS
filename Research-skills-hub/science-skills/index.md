# Science Skills

* [uv](uv/SKILL.md) - Checks/installs the `uv` Python package manager required by script-based skills. Installed.
* [literature_search_arxiv](literature_search_arxiv/SKILL.md) - Searches arXiv metadata; downloads PDFs, HTML, or source archives. Installed.
* [literature_search_biorxiv](literature_search_biorxiv/SKILL.md) - Searches bioRxiv/medRxiv metadata by DOI or date/category ranges. Not installed.
* [literature_search_europepmc](literature_search_europepmc/SKILL.md) - Searches Europe PMC open-access literature; retrieves PDFs, full text, citations. Not installed.
* [literature_search_openalex](literature_search_openalex/SKILL.md) - Queries OpenAlex for works, authors, institutions, topics, bibliometrics. Installed.
* [science_skills_common](science_skills_common/SKILL.md) - Shared HTTP client package used by the literature-search skills (support package, not standalone). Installed.
* [workflow_skill_creator](workflow_skill_creator/SKILL.md) - Distills a completed research workflow into a reusable agent skill. Not installed.

# Open Paper Skills

Repo-local custom skills. Part of the [Research Skills Hub](../index.md). Open a skill's
`SKILL.md` only when it is relevant to the current task; install via the commands in the
[hub index](../index.md).

| Skill | Purpose | Installed? |
|---|---|---|
| [`uv-env`](uv-env/SKILL.md) | uv-based Python environment setup for research projects | yes |
| [`filetree-simple`](filetree-simple/SKILL.md) | Maintains and lints the compact `FILETREE.md` index | yes |
| [`session-handoff`](session-handoff/SKILL.md) | Maintains `task_plan.md` + `CHANGE_SUMMARY.md` as cross-session hand-off records (resume from the progress TODO, record changes/decisions/deviations) | yes |

# Q1 问题定义

* **输入（X）：** 来自三个领域之一的用户请求（购物：1,500 条 WebShop 目标；住宿：214 条 HotelQuEST 请求加 572 条替换地点的变体；学术：2,536 条 ScholarGym 查询；共 4,822 条）；一个处于 ReAct 循环中的 LLM 智能体，配有 Tavily 网页搜索工具，每次最多返回 10 条结果（标题、摘要片段、URL；平均 8.83 条）；五步环境动作预算。智能体不能打开网页，最后从最近一页结果中选出任意子集来结束回合。
* **输出（Y）：** 针对每个模型和领域：每个来源（站点的可注册域名）的偏好分数 τ_s；一个标签（偏好 "Source+"、回避 "Source−" 或中性）；两条目相差一项满足要求时的"反转率"；以及对显示来源、训练数据和提示进行干预后的效果。
* **核心问题：** 当智能体替用户挑选商品、酒店或引用文献时，对某些来源的偏好会缩小用户看到的范围，还可能让更好的条目落选。只看原始选中率无法证明这一点，因为某个来源的条目可能本来就更符合请求，或排在更靠前的位置。论文要回答：在端到端搜索中控制了这些因素后，来源偏好是否仍然存在；显示出的来源信息是否是原因；它如何产生、又如何减轻。

# Q2 问题新颖性

部分新颖。来源与权威效应对 LLM 选择的影响已有记录：Khan 等（ICLR 2026）给语义相同的内容附上不同来源，发现了潜在的来源偏好；Dai 等（EMNLP 2025）发现 LLM 引文中的媒体来源偏差；Schuster 等研究知识冲突下的来源偏好；BiasBusters 发现工具选择中的提供方偏差与位置偏差；Allouah 等与 Cherep 等研究购物智能体的偏差。新的地方在于设定：智能体自己从实时网页检索条目，因此不同来源的条目在内容和质量上都不同；论文为此设计了配对比较，把来源与质量、位置区分开。它还把观测结果与因果干预（隐藏、恢复、互换来源）、一种训练机制，以及推理时的缓解手段联系起来。这个问题对用户重要（可能拿到更差的条目），对提供方也重要（智能体在分配它们的曝光）。

# Q3 科学假设

1. **存在性。** 如果只比较满足完全相同要求的条目，并在相同显示位置上比较，智能体仍会更多地选择某些来源、更少地选择另一些，而且不同模型在偏好哪些来源上大体一致（表 1、图 2、表 E.1）。
2. **压过质量。** 来源偏好可以压过对请求的满足程度：当较差的条目带着偏好来源时，它被选中的频率远高于反过来的情形（反转率，图 3）。
3. **显示来源是原因。** 隐藏 URL 与来源名称会减弱偏好，恢复会加大偏好；把同样的内容重新标注为偏好来源，会提高其被选中率（图 4、表 3）。
4. **训练途径。** 如果偏好训练反复把某个来源与更好的条目配对，智能体会把来源当作捷径，即使条目同样好也偏爱它；重新平衡这种配对可以减弱已有偏好（表 4-5）。
5. **推理途径。** 当条目缺少请求所需的信息（例如价格）时，智能体会用对来源的成见来填补空白；补上信息或反驳这种成见可以减轻偏好（表 6）。

# Q5 关键解法思想

核心贡献是一个度量设计：在自然检索得到的结果列表中，把来源与质量、位置分离开，再用干预检验成因。

* **要求匹配配对。** 一个看不到来源的 LLM 评审（Qwen3.8-27B，去掉 URL 和来源名称）判断每条结果的标题和摘要满足了哪些要求。同一列表中来自不同来源、满足要求集合完全相同的两条条目构成一个匹配对。
* **位置控制。** 每个长度为 L 的列表按全部 L 种循环轮换各运行一次（循环拉丁方），使每个条目在每个位置恰好出现一次。对每个位置，两条条目的结果构成一次比较，选择差 D ∈ {−1, 0, 1}。
* **偏好分数。** 带 Davidson 平局参数的 Bradley-Terry 模型（岭惩罚 λ = 0.005，比较次数少的来源合并为一个对手）为每个来源给出评分；τ_s 是相对于平均来源的期望选择差（例如 τ_s = 0.10 表示被选中的频率高 10 个百分点）。请求级聚类自助法（B = 10,000）加每个模型-领域内 5% 的 FDR 控制，给出 Source+、Source− 或中性标签。
* **反转率。** 对恰好相差一项满足要求的配对，Inv_{ℓ,m} 是"恰好选中一条"的比较中，选中较差条目的比例，按两个来源的标签分组。
* **干预。** 在冻结轨迹上重放的三种披露条件（Hidden、URL-only、Original）；内容固定、经平衡设计的来源互换；用虚构来源名（Kelto/Varnis 及另外两对）做 DPO，在 50%、80% 或 20% 的训练对中把目标来源分配给更好的条目；以亚马逊对 eBay、Etsy、AliExpress 做重新平衡；以及针对缺失价格的提示或内容干预。

# Q6 实验设计

* **智能体。** 12 个模型：GPT-5.4-nano、GPT-5.6-Luna、Gemini-3.7-Flash、GLM-5.3-Flash、DeepSeek-v4-Flash、Llama-4-Maverick、Llama-4-Scout、Llama-3.1-8B-Instruct、Tulu-3-8B、Qwen3.5-27B、Qwen3-30B-A3B、Qwen2.5-32B-Instruct。共享系统提示，支持时温度设为 0、种子 42（GPT-5.6-Luna 要求温度为 1）。
* **评审验证。** 两名人工标注者与评审在要求层面标注 375 条购物、375 条住宿、100 条学术结果；评审与人工的 Krippendorff α 为 0.65-0.75，人工之间为 0.67-0.72（表 D.1）。
* **规模。** 表 E.1 给出每个模型和领域的有效请求数、匹配对数、位置比较数（例如 GPT-5.4-nano 在购物上有 9,857 个匹配对、86,362 次比较）以及被评分的来源数。
* **稳健性。** 用 λ ∈ {0, 0.01, 0.1, 1} 重拟合，没有来源在 Source+ 与 Source− 之间翻转；与主拟合的秩相关至少 0.98；反转率的大小顺序在 36 个单元中的 35 个、对所有 λ 都成立。
* **干预实验。** 披露重放用 11 个模型（因成本省略 Gemini）；互换实验用全部 12 个模型，每对评估四次；DPO 用 Qwen3.5-9B、Llama-3.1-8B、Tulu-3-8B-SFT，5,000 个训练对（LoRA，5,000 次更新，β = 0.1），在 1,000 个同等满足的评测对上比较两个选择动作的对数概率；缺失价格的干预只在购物领域用五个模型。
* **未纳入设计的部分。** 智能体从不打开网页，所有证据只有标题、摘要和 URL；要求满足也是根据同一段摘要判断的。DPO 研究用的是两条目选择提示，而不是端到端智能体。缓解手段只在购物领域、只针对价格缺失做了测试。

# Q8 证据质量

* **支撑充分的部分。**
  * 存在性结论建立在细致的设计上：满足集合匹配、完整的位置轮换、聚类自助法、FDR 控制，以及惩罚参数的敏感性检查。模型间一致性很强：在最常见的 12 个来源中，有 10 个没有出现"一个模型偏好、另一个模型回避"的情况；在图 2 中 32 个有标签的来源里，有 27 个所有模型的符号一致。
  * 压过质量的结果幅度大且一致：Inv_{+,−} 中位数 68%，Inv_{−,+} 为 2%，Inv_{0,0} 为 19%，这一顺序在各模型-领域单元中都成立。
  * 互换实验是最强的因果证据：在内容和位置平衡的前提下，显示 Source+ 而不是 Source− 会在每个模型、每个领域提高选中率（所有 12 个模型都至少在一个领域达到 p < 0.01；最大为 Llama-4-Maverick 在购物上的 +64.7 个百分点）。
  * DPO 研究说明捷径机制足以产生偏好：在同等满足的配对上，平衡训练下目标来源的选中率保持在 50% 左右，对齐训练下升至 70.1-75.1%，反向训练下降至 24.5-28.5%。
* **比标题结论更弱或更窄的部分。**
  * 只看摘要片段是很强的范围限制。片段常常缺少价格或细节，而论文自己就证明了这会诱发基于来源的猜测；会打开网页的智能体可能表现出更小的偏好。
  * "相同要求"指的是根据片段*判断*出的相同要求；评审与人工的一致性只是中等（α 0.65-0.75），所以部分匹配对在评审没看出的方面并不相同，这种噪声可能偏向那些片段中线索更多的来源。
  * 训练途径只证明是*可能*的，没有证明它就是已部署模型偏好的成因；附录 I 中来源平均满足度与 τ_s 的相关是描述性的，作者自己说它"不能确定训练数据包含了什么"。
  * 缓解结果的范围很小：五个模型、一个领域、一种缺失属性。有效的提示（"Designate"）是用一种成见去抵消另一种，并且需要事先知道哪个来源被回避，论文也指出了这一点。
  * 实时网页结果和 API 提供的模型都不是确定性的，精确复现可能有差异。
* **读者观察。** 论文以片段中可见的要求为基准，把偏好视为不合理。但其中一部分可能是对看不见属性（列表可靠性、价格透明度）的合理先验。要把合理先验和不合理捷径分开，需要条目完整页面上的真实信息，而这个设计没有收集。

# Q9 贡献

* 一种在自然检索结果列表中度量来源偏好的方法：要求匹配配对、循环位置轮换，以及带聚类自助显著性与 FDR 控制的 Bradley-Terry-Davidson 分数。
* 跨 12 个模型、三个领域的证据：智能体对特定站点有共同的偏好，即使在同类站点之间也是如此（12 个模型都偏好 Walmart，只有 2 个偏好 Target；10 个偏好 Booking.com，一半回避 Expedia）。
* 量化的危害：偏好来源的条目对上回避来源中更好的条目时，约三分之二的情况下胜出。
* 因果证据：显示出的来源本身就会改变选择，而且大部分效应来自 URL 本身（11 个模型中有 9 个，超过 80% 的差距扩大发生在只恢复 URL 的那一步）。
* 一条被证实的训练途径（来源成为 DPO 中的捷径），以及两种缓解手段（补上缺失信息；在系统提示中反驳成见）。

# Q10 下一步

* **会浏览的智能体。** 用会打开并阅读网页的智能体重复研究，看更丰富的证据是否缩小偏好，还是 URL 仍占主导。
* **真实质量。** 收集完整页面或交易层面的真实信息，把有依据的来源先验和捷径区分开。
* **训练数据审计。** 测量智能体模型真实偏好数据和 RL 数据中来源-满足度的相关，并检验在后训练中平衡它能否在不损害选择质量的前提下减少端到端偏好。
* **通用缓解手段。** 有效的提示需要点名被回避的来源；不依赖具体来源的方法（例如判断时屏蔽 URL，只在引用时恢复）更容易部署。
* **超越选择。** 同样的匹配设计可以度量深度研究智能体在引用时的来源偏好，以及在工具或 MCP 服务器选择上的偏好，BiasBusters 已在后者发现相关的提供方偏差。
* **与本仓库的契合（读者笔记）。** 本仓库自己的论文检索与 wiki 工作流也在替人选择来源（arXiv、OpenReview、Medium 等都在被测的学术来源中）；这一发现提示我们记录每个检索结果来自哪个来源，并在展示来源之前先判断相关性。

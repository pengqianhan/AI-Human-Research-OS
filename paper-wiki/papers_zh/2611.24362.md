# Q1 问题定义

* **输入（X）：** 一个可白盒访问权重的工具调用智能体基础策略 π_θ0，以及一个由模拟任务对（良性用户任务、注入任务、工具环境）构成的沙箱，防御方在其中确切知道植入了哪条注入字符串。
* **输出（Y）：** 一个加固后的策略 π_θ，推理时不增加任何外部组件；在间接提示注入（indirect prompt injection, IPI）下不执行注入任务（攻击成功率 ASR 低），仍完成用户任务（受攻击时效用 UA），并保持干净输入上的表现（良性效用 BU）。
* **约束：** 攻击者只能控制工具返回的观察，了解防御机制，并可反复查询已部署的智能体；评测不使用梯度（静态字符串和迭代搜索）。训练用的任务、工具和攻击与评测基准不相交。

# Q2 问题新颖性

把自动红队与对抗训练配对是既有做法，RL 红队方法（RL-Hammer、PISmith）和训练式防御（StruQ、SecAlign、Meta-SecAlign、SecOPD、RL 对抗训练）也都已存在。本文的新问题是：第一阶段的成功指标能否预测第二阶段的结果。论文报告不能，把差距归因于表层多样性奖励（BLEU、嵌入距离、token 熵）防不住的策略层面模式坍塌，并把两个阶段当作同一个目标来处理。对抗训练损失效用是已知的权衡；针对 IPI 情形的 token 级补救是新的部分。

# Q3 科学假设

如果红队策略因“成功且已发现的攻击策略无法解释”的注入而获得奖励，收集到的训练集就会覆盖更多不同的策略，在其上做对抗训练会比在追求最大 ASR 的红队所得的更大数据集上训练，对未见攻击有更低的攻击成功率。另外，如果防御方按 token 被奖励“与自己忽略注入时的行为一致”，而不只是按整条轨迹的结果，它就能抵抗注入而不学会拒绝或中止。

# Q4 相关工作与关键人物

* **针对提示注入的 RL 红队：** RL-Hammer（BLEU 或嵌入距离多样性奖励）、PISmith（自适应熵奖励、动态优势加权），都基于 GRPO。
* **训练式 IPI 防御：** StruQ（SFT）、SecAlign 与 Meta-SecAlign（偏好优化）、SecOPD（以干净上下文教师做在策略蒸馏）、RL 对抗训练、Instruction Hierarchy。
* **非训练式防御：** Spotlighting、Sandwiching、PromptGuard、PIGuard、DataSentinel、MELON、CaMeL。
* **攻击：** 静态：IgnorePrev、InjecAgent、ImportantMsgs、ToolKnow、ChatInject。迭代自适应：TAP、Genetic（MAP-Elites）、AutoInject。
* **借用的技术：** 越狱研究中的策略分解与稀疏字典学习；在策略自蒸馏（OPSD）；按奖励分别归一化优势。
* **关键人物：** Lipeng He、Yihan Wang（通讯作者）与 N. Asokan（滑铁卢大学；Asokan 同时在 KTH），Jiawen Zhang（浙江大学）。可能的批评者：做自适应攻击评测的作者，他们会要求比 4B 攻击模型更大的攻击预算和更强的攻击者。

# Q5 核心方法

1. **策略基元（strategy primitives）：** LLM 抽取器把每条成功的注入转成若干记录（策略名、匹配到的原文、与任务无关的解释）。解释的嵌入经稀疏字典学习分解为 K 个共享基元；每个基元由权重最高的记录命名，近似重复的合并。论文给的两个例子：“基于信号的指令覆盖”（假装任务已完成，再重置指令）和“任务框架指令”（把注入目标包装成工作流元数据）。
2. **可解释性分数（ES）：** 新注入的解释对字典做稀疏编码，LLM 评分器按 1 到 5 评定排名靠前的基元对它解释得有多完整，再缩放到 [0, 1]。ES 接近 1 表示只是已知策略的改写。
3. **Pipette-Red：** 红队策略（由基础策略初始化，用 GRPO 对冻结的基础策略训练）获得二元攻击奖励、格式奖励和覆盖奖励 r_cov = 成功 ×（1 − ES）。字典每 M 步重建一次，用保留的旧记录加上 ES 低于阈值的新记录，于是重复旧策略或刚发现的新策略都不再有回报。每种奖励先在组内归一化再加权。
4. **Pipette-Blue：** 先用自生成示范做 SFT 预热，再对智能体做在策略训练，让它在每次工具调用前先做两项检查的推理：C1，上一条观察中是否含有指令或重定向企图；C2，计划的每个调用是否服务于用户授权的目标。奖励包括：结果奖励（完成用户任务且未完成注入任务）、LLM 评审的推理奖励，以及 token 级项 r_tok = log π(y | 上下文, z⁺) − log π(y | 上下文, z⁻)，其中 z⁺ 是让模型忽略已知注入的特权前缀，z⁻ 是让它照做的前缀。成对的前缀抵消了“加了前缀”本身带来的格式效应。

# Q6 实验设计

* **训练：** 两个阶段都用 560 个 AgentDyn 任务对。红队基线按作者的批大小跑 250 步。
* **模型：** Qwen3-4B-Instruct-2507、Llama-3.1-8B-Instruct、GPT-OSS-20B、Qwen3.6-27B。
* **评测：** AgentDojo（Workspace、Slack、Travel、Banking）和 Agent Security Bench（ASB），与训练没有共享的用户任务或注入任务。静态攻击每种在 420 个 AgentDojo 任务对上评测，BU 在 97 个干净任务上评测；迭代自适应的 TAP（每对最多 250 次尝试）和 Genetic（最多 248 次）在 40 个 AgentDojo 任务对上评测，每个套件 10 个，攻击者为 Qwen3.5-4B，评审为 Qwen3-4B。
* **对比：** 分阶段：各红队的数据集 ×{RL, SFT} 对抗训练；再在 Pipette-Red 数据集上比较 RL、SFT 与 Pipette-Blue。完整系统对比 Meta-SecAlign（Llama-8B）、SecOPD（Qwen3.6-27B）、原生 Instruction Hierarchy（GPT-OSS-20B），以及两个小模型上的七种非训练式防御。在 Qwen3-4B 上消融推理检查和 r_tok。

# Q8 证据质量

**动机实验。** PISmith 攻破的训练任务对比 RL-Hammer 多（Qwen3-4B 上 68.75% 对 33.39%；Llama-8B 上 27.32% 对 25.18%），收集的字符串也更多（7,132 对 4,282；1,783 对 1,671），但在四种设置中的三种里，对 ChatInject、TAP、Genetic 的最坏情况 ASR 更高：47.5% 对 27.5%（Qwen3-4B，RL）、27.5% 对 25.0%（Llama-8B，RL）、20.0% 对 15.0%（Llama-8B，SFT）；例外是 Qwen3-4B 的 SFT（12.5% 对 15.0%）。用两个基线构建的字典对未见 ChatInject 攻击的解释程度都会停滞（RL-Hammer 的 ES 约 0.20 和 0.35），而 Pipette-Red 达到约 0.60 和 0.77（五个种子）。

**Pipette-Red。** 训练期 ASR 最高（Qwen3-4B 上 70.54%、8,299 条字符串；Llama-8B 上 41.07%、2,112 条），且四种设置下最坏情况 ASR 都最低：Qwen3-4B 上 20.0%（RL）和 2.5%（SFT），Llama-8B 上 10.0% 和 5.0%。

**Pipette-Blue，AgentDojo 上的良性效用（表 IV）。**

| 模型 | 基础 | RL | SFT | Pipette-Blue |
|---|---|---|---|---|
| Qwen3-4B | 61.86% | 59.79% | 58.76% | 64.95% |
| Llama-8B | 40.21% | 35.05% | 29.90% | 41.24% |

**迭代自适应攻击，40 个 AgentDojo 任务对（表 V，ASR / UA）。**

| 模型 | 防御 | TAP | Genetic |
|---|---|---|---|
| Llama-8B | 无 | 7.50% / 12.50% | 17.50% / 32.50% |
| Llama-8B | Meta-SecAlign | 2.50% / 15.00% | 12.50% / 17.50% |
| Llama-8B | Pipette | 0.00% / 25.00% | 2.50% / 30.00% |
| Qwen3.6-27B | 无 | 40.00% / 97.50% | 70.00% / 97.50% |
| Qwen3.6-27B | SecOPD | 15.00% / 95.00% | 30.00% / 92.50% |

| GPT-OSS-20B | Pipette | 5.00% / 85.00% | 10.00% / 82.50% |

**静态攻击。** 五种 AgentDojo 攻击上的平均 ASR 为 0.48%（Qwen3-4B）和 0.43%（Llama-8B），平均 UA 为 57.86% 和 39.05%，高于所有非训练式防御，也高于未防御模型；ASB 上为 0.70% 和 0.50%。只有在 ChatInject 的 ASR 上 PromptGuard 和 CaMeL 更低，但 UA 低得多（Qwen3-4B 上 16.19% 和 33.81%，Pipette 为 58.10%）。较大模型的 BU：Qwen3.6-27B 上 92.78%，未防御为 93.81%（SecOPD 为 84.54%）；GPT-OSS-20B 上 49.48% 对 50.52%。

**消融（Qwen3-4B，ChatInject）。** 只用结果奖励：ASR 3.57%、UA 45.48%、BU 59.79%。加入推理检查：2.38%、56.90%、60.82%。再加入 r_tok：1.43%、58.10%、64.95%。

**证据的局限。**

* 自适应结果基于 40 个任务对，所以一对就是 2.5 个点，“0% 到 10%”即 0 到 4 对被攻破；表 V 中每个 ASR 都是 2.5 的倍数（读者计算）。训练出的防御方没有报告置信区间或多个种子。
* 攻击者和评审都是 4B 模型，约 250 次尝试；论文说明更大的预算可能达到更高的 ASR。
* 各红队除了策略覆盖不同，数据集大小和采样也不同，所以第一阶段的对比并没有把覆盖单独隔离出来；论文说它没有证明覆盖不足是唯一原因。ES 评分器没有对照人工标注验证过（两点均为论文所述）。
* ES 覆盖只对一个未见攻击族 ChatInject 测量，而它也是最坏情况 ASR 指标中的三种攻击之一。
* 动机实验中的反转是 4 种设置中的 3 种，其中两种只差一两对（27.5% 对 25.0%，20.0% 对 15.0%）（读者计算）。
* Pipette 只做一轮“先红后蓝”；只在加固后的模型上才出现的漏洞未被测试（论文所述）。作为基线的训练式防御是其他团队在不同数据上训练的权重，所以这些对比混合了方法和训练集的影响（读者观察）。
* 在 Qwen3.6-27B 上，自适应攻击下的 UA 从 97.50% 降到 87.50% 和 90.00%。

# Q9 贡献

1. 证据表明 RL 红队的训练期攻击成功率和数据集大小不能预测训练后的鲁棒性，并给出一个策略层面的覆盖度量（ES），显示基线会停滞。
2. 建立在滚动策略字典上的覆盖奖励，让红队在不重新训练防御方的情况下持续探索。
3. 一种在策略防御，把任务对齐推理与对比式特权前缀 token 奖励结合，在两个小模型上使良性效用不低于基础模型。
4. 跨基准评测（在 AgentDyn 上训练，在 AgentDojo 和 ASB 上测试），对比训练式和非训练式防御，包括自适应搜索。

# Q10 后续方向

* **论文提出的：** 对加固后的策略再做红队的多轮紫队演练；更大的自适应预算；对 ES 评分器做人工验证。
* **隔离覆盖因素：** 把三个红队的数据集下采样到相同大小和相同的每任务条数，再重复对抗训练，检验覆盖本身能否解释鲁棒性差距（读者建议）。
* **更强的攻击者：** 用前沿模型作攻击者，以及用了解 Pipette、直接针对 C1/C2 推理格式的攻击者重跑 TAP 和 Genetic（读者建议）。
* **与系统级防御组合：** 训练出的策略和出口或控制流层的失效方式不同；在同一批任务对上一起测量，可以看出剩余的 0 到 4 次自适应成功是否正是目标准入规则会拦下的情形（读者建议）。

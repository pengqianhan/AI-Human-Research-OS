> 论文:**UrbanGround: From Local Perception to Spatial Agency in a Real-Scale City**
> 论文链接:<https://arxiv.org/abs/2608.27456>
> 机构:上海交通大学 / 新加坡国立大学 / 美团 / 香港中文大学 / 上海大学 / 牛津大学

# Q1 问题定义

* **输入 `X`**:一个以第一人称角色具身、置身于香港真实尺度、经地理配准的三维重建场景中的 MLLM agent,接收以自身位姿为中心的视觉观测 oₜ、一张可选的、可平移/缩放/环视的俯视交互地图(但地图不会为其计算路线),以及一条任务指令;agent 唯一享有特权的通道是自己发出的结构化动作——它无法获取剩余距离、最短路径,或任何路线 API。
* **输出 `Y`**:UrbanGround,一个闭环评测沙盒,以及一套五级任务阶梯,用来检验局部感知的落地(识别当前可见的内容)是否会组合为持续的、目标导向的空间能动性(在城市中移动、适应变化、完成多步任务),而非只是当前一瞬的正确判断。
* **核心问题**:MLLM agent 能够解读单张街景图,但"城市中的能动性取决于这类局部证据在 agent 开始移动之后是否仍然有效"——一旦 agent 转过街角,支撑其上一步决策的地标可能已离开视野,但它的位置依然重要。论文在一个受物理约束的真实尺度复制场景中(而非合成场景或按视角采样的代理场景)研究当前的 MLLM agent 究竟能在多大程度上把局部感知转化为可靠、持续的行动。
* **范围**:纯评测性质——论文没有引入任何训练方法或新模型,而是搭建了一个测试平台,在其中评测十个已有的前沿及准前沿 MLLM 作为 agent 的表现,评测城市仅限于香港一处。

# Q2 问题的新颖性

已有的空间 agent 测试平台可分为三类,均未能完全覆盖 UrbanGround 所针对的目标。游戏环境(MineDojo、GROOT,以及若干聚焦 Minecraft 的长时程扩展系统)提供了长时程交互,但其空间结构由游戏机制定义,而非扎根于真实世界。物理世界室内具身问答/导航基准(OpenEQA、NavBench 及相关系统)评测真实具身推理,但空间范围有限,只需要局部参照系即可应对。城市尺度的前作与本文最为接近,但仍分为两类各有局限的方案:基于街景图的 agent(VELMA、CityNavAgent、CitySeeker、CityWalker)依赖离散采样的视角而非连续物理仿真;交互式城市模拟器(MetaUrban、UrbanWorld、SimWorld)提供了连续交互,但场景是生成出来的,论文认为其缺乏真实的地理复杂度。UrbanGround 声称的新意在于:它是第一个真实尺度、经地理配准的城市沙盒——建立在官方的、覆盖全域的三维地理空间数据之上,而非采样图像或程序化生成——支持连续第一人称物理仿真与闭环交互,从而能在合成或基于视角采样的测试平台无法复现的条件下,检验感知落地、随距离扩展导航,以及应对变化的鲁棒性这三个研究问题。

# Q3 科学假设

如果一个测试平台把 MLLM agent 置身于一个连续物理、经地理配准的真实城市重建场景中,并把评测分解为:(a) agent 能否在主动观察之后,凭借局部落地回答空间问题;(b) 随着目的地变得更远、指代也更含糊,这种局部落地是否仍能支持导航;以及 (c) 由此产生的行为在路线可用性与行人运动发生变化时能否保持稳健——那么当前的 MLLM agent 会表现出可靠的原子级视觉识别能力,但方向判断与行人感知式移动相对不可靠,而核心的失败并非缺失某一项单一的原子能力,而是一种*组合*上的缺口:随着交互时程增长,局部能力未能聚合为持续的目标导向行为,错误会不断累积而非通过重新规划得到纠正。

# Q4 相关工作与关键人物

* **游戏环境**:MineDojo(Fan et al., 2022)与 GROOT(Cai et al., 2024)在 Minecraft 中建立了长时程 agent 交互;近期若干系统进一步扩展了 Minecraft 场景下的长时程轨迹,但论文指出其局限在于,这类场景中的成功由游戏机制塑造,而非扎根于真实世界的空间结构。
* **物理世界室内具身问答/导航**:OpenEQA(Majumdar et al., 2024)与 NavBench(Qiao et al., 2025)及相关系统检验了真实的具身空间推理,但论文认为其空间范围有限,只需要局部参照系,而不需要跨街区的持续定向能力。
* **城市尺度前作——与本文最接近**:基于街景图的 agent(VELMA、CityNavAgent、CitySeeker、CityWalker)在离散采样的视角上运行,不含连续物理仿真;交互式城市模拟器(MetaUrban、UrbanWorld、SimWorld)提供了连续交互,但场景是生成出来的,论文认为其缺乏真实的地理复杂度。UrbanGround 被定位为把两类各自缺失的要素结合起来:真实的地理复杂度(来自香港地政总署官方的三维可视化地图与三维行人网络)与连续、闭环的第一人称物理仿真。
* **关键人物与机构**:第一作者 Tianjie Ju,通讯作者 Zhuosheng Zhang、Hao Fei、Qi Gu、Gongshen Liu,完整作者名单横跨上海交通大学、新加坡国立大学、美团、香港中文大学、上海大学与牛津大学;2026 年 8 月 27 日提交。

# Q5 核心解法

1. **基于官方地理空间数据、经地理配准的真实尺度沙盒**。UrbanGround 用 Unity 搭建了一个香港的重建场景,数据来自香港地政总署的三维可视化地图(由倾斜摄影生成的带纹理网格,以 WGS84 为参照)与三维行人网络(经地理配准的步道连通图),并带有物理碰撞,使 agent 的移动受到与真实行人相似的约束。所有 agent 的位置都以真实地理坐标记录。
2. **叠加在静态城市之上、可配置的环境动态**。一个连续时间系统驱动天空、光照与阴影(可固定或推进);一个天气系统(雨、雾)影响能见度与表面渲染;一个基于微软开源 Rocketbox 虚拟人库构建的行人群体,在行人网络上生成、动画化并进行碰撞追踪——使沙盒能在同一座城市中呈现多种可控条件,而非单一的静态快照。
3. **闭环的第一人称与地图动作空间,不含任何特权捷径**。agent 通过第一人称控制(move、sprint、look、jump、open_map,均带方向/时长参数)与地图控制(map_select、map_pan、map_zoom、map_orbit、close_map)行动,外加一个 terminate 动作,并可自由查看俯视交互地图——但该地图不计算任何路线,agent 也从未获得剩余距离、最短路径或任何路线 API;agent 所使用的每一次空间估计都必须来自其自身累积的观测与推理。
4. **一套逐层检验"什么能组合成什么"的五级评测阶梯**。第 1 级(视觉识别、方向判断、主动探索式问答)只检验局部落地本身(RQ1:agent 能否在主动观察之后,把场景落地到足以回答空间问题的程度?)。第 2 级(短程/长程/指令式/受约束导航)与第 3 级(地点类型搜索、隐含意图推断)检验随着目的地变得更远、指代更含糊,这种落地能力是否仍能支持导航(RQ2)。第 4 级(时间窗调度、多站点规划)把 RQ2 延伸到持续的多任务维持。第 5 级(动态道路封闭、行人间导航)检验 RQ3:行为在任务执行过程中出现路线可用性与行人运动变化时能否保持稳健。全部 810 个任务实例横跨香港多个区域,均经人工核验,每个任务都由一名人类测试者在 100 步的限制内完成,以确认其可行性,而后才纳入基准。
5. **与各层级所检验内容相匹配的度量指标**。问答类任务按与标注答案的一致程度打分;导航成功要求最终位置落在目的地 15 米范围内,并满足任务约束;行人网络遵从度(PNA)衡量动作时间中落在已登记步道网络上的比例(这是一个*局部合规*信号,不同于任务成功);动态任务额外引入安全推进率(SPR,在道路封闭事件中避开被封闭路段的回合比例)与行人碰撞率(PCR)。

# Q6 实验设计

十个 MLLM 在不做任何微调的情况下作为 agent 被评测:GPT-5.5、GPT-5.4、GPT-5.2(OpenAI)、Claude-Opus-5 与 Claude-Opus-4.6(Anthropic)、Gemini-3.6-Flash 与 Gemini-3.1-Pro(Google),以及 Doubao-Seed-2.0-Pro、GLM-5V-Turbo、Kimi-K3。在 RQ1(局部落地,表 1)上,视觉识别准确率普遍较高(本笔记来源表格中四个模型为 82.5%-93.8%),但方向判断准确率明显更弱、接近随机基线(4 选 1 问题为 23%-58%,例如 Claude-Opus-5 为 58.3%,GPT-5.5 为 40.0%);总体准确率跟随这一差距(63.6%-79.1%),而 PNA 在每个模型上都系统性地低于总体准确率,论文将其解读为 agent 为了更快完成任务而牺牲了行人网络合规性。

在 RQ2(导航随距离扩展,表 2)上,短程导航是可以做到的(各模型间为 23.8%-75.0%),但长程导航在所有被测模型上都塌陷到接近零(0.0%-2.5%),多任务规划(时间窗调度、多站点规划)同样接近零(0%-3.3%);总体导航成功率从 8.1%(Gemini-3.6-Flash)到 22.9%(Claude-Opus-4.6)不等。按距离分层的分析(图 7)显示,即便在名义上属于"短程"的任务类别*内部*,成功率也随距离四分位数持续下降——并不存在某个成功率骤然跌落的离散距离阈值。一项部分得分分析(图 8)发现,超过一半的长程回合仍在缩小与目标的距离,尽管完全成功的比例不到 2%;多站点 agent 平均只能到达约 10%-20% 的必需目的地——这些证据表明失败源于持续组合与纠错能力的缺失,而非 agent 在随机移动。

在 RQ3(鲁棒性,表 3-4)上,局部问答准确率在不同光照/天气条件下有中等程度但不均匀的下降(例如 Claude-Opus-5 从晴天的 79.1% 降到黄昏的 66.4%;Gemini-3.1-Pro 从晴天的 53.2% 降到夜间的 37.3%),而同样条件下的导航准确率更依赖具体模型(GPT-5.5 与 Kimi-K3 相对稳定;GPT-5.4 与 Gemini-3.1-Pro 下降更明显)。在动态条件下,道路封闭的安全推进率偏低(各模型间为 10%-46%),尽管同一批回合中的行人网络遵从度保持较高(约 93%-96%)——agent 即便在规划路线被全局性地封闭事件推翻之后,仍在已登记网络上保持局部合规的移动。无论 PNA 如何,行人碰撞率在各模型上都普遍偏高(76%-90%),说明遵从路网几何并不等于具备避让障碍物的意识。

# Q9 主要贡献

1. 第一个基于官方、覆盖全域的三维地理空间数据(香港)、面向 MLLM agent 的真实尺度、经地理配准的城市沙盒,具备连续第一人称物理仿真与闭环交互,而非采样街景图或程序化生成的城市。
2. 一套五级空间能动性评测阶梯,把问题从原子级的局部落地,一路分解到持续的多任务导航,再到应对动态路线与行人变化的适应能力,从而定位组合链条究竟在哪一层断裂。
3. 对十个当代 MLLM agent 的评测,发现了一个跨模型的一致模式:视觉识别能力较强,方向判断能力较弱(接近随机水平),导航成功率随距离在触及任何单一硬性失败阈值之前就已塌陷,而路线适应失败(安全推进率偏低)即便在局部行人网络合规度保持较高时依然持续存在——这是组合能力缺口而非单一原子能力缺失的证据。
4. 公开发布该沙盒(原生与网页版)、任务集与评测框架,供后续研究扎根真实世界环境中的持续空间能动性使用。

# Q10 下一步

论文自身(据本笔记的提取内容)陈述与隐含的局限性:评测仅覆盖香港一地,能否推广到其他城市的街道布局与行人习惯尚未检验;模型仅通过 API 被评测,无法检视内部状态或记忆动态,因而无法解释方向判断或长程导航究竟*为何*失败;交互预算上限为 100 步,可能低估了真实世界长时程场景的需求;动作空间是简化的离散第一人称控制方案,而非连续的具身运动;行人行为是脚本化动画,而非对真实人类运动的建模,这很可能以论文未拆解的方式影响了所报告的碰撞率。隐含的未来方向包括:为地标离开视野后仍能维持空间状态设计架构、由路线失效触发显式的重新规划/恢复机制而非重复向前移动、融合第一人称与地图证据、把专门的导航模型而非只有通用 MLLM 纳入比较,以及扩展到其他城市的地理空间数据。

本笔记在论文自身的框架之外补充一条联系:UrbanGround 的核心发现——agent 能维持局部合规行为(行人网络遵从度高),却在该行为本应服务的全局条件上失败(道路封闭时安全推进率低,尽管持续取得局部进展但长程成功率接近零)——是本知识库 [Agent environments](../topics/agent-environments.md) 主题已经通过评测器设计所揭示的同一种"局部-全局落差"在导航领域的一个实例(例如 VibeWorlding 中物理可行性检查通过、但意图满足度仍然失败的情形):一个被局部打分的代理信号可以恰好在它本应代理的属性崩溃时依然保持高位。

> 论文:**EverMemOS: A Self-Organizing Memory Operating System for Structured Long-Horizon Reasoning**
> 论文链接:<https://arxiv.org/abs/2601.02163>
> 机构:EverMind、盛大集团(Shanda Group)

# Q1 问题定义

* **输入 `X`**:用户与长期运行的 LLM agent 之间无边界的对话/交互历史流,以及推理时的下游查询——可以是用于基准评测的推理问题,也可以是用于实际部署的对话轮次。
* **输出 `Y`**:针对该查询、通过 MemScene 引导的主动检索重建出的"必要且充分"的上下文;该上下文由系统自身构建并维护的记忆生命周期产生——MemCell(从原始交互流中提取的情节叙事 Episode、原子事实 Atomic Facts、带时间界限的前瞻 Foresight,以及元数据 Metadata)、MemScene(通过在线增量聚类形成的 MemCell 主题簇),以及持续更新的用户画像(显式事实与隐式特质)。
* **核心问题**:现有 LLM 记忆系统存储的是孤立的记录并检索片段,而非把经验整合为连贯的知识,因此即便能够检索到各自相关的事实,也仍可能无法察觉跨情节的冲突、维持稳定的用户模型或进行前后一致的推理——例如,一个基于片段的系统可能记得用户喜欢 IPA 啤酒并据此推荐酒精饮品,却没有注意到另一条时间上更近、单独存储的事实:该用户目前正在服用抗生素。
* **范围**:一个仅面向文本的对话式记忆系统,在记忆增强推理任务上定量评测,在对话场景上定性评测;论文明确表示不处理多模态或具身记忆,也不修改底层 LLM 的权重——所有记忆操作(分段、叙事合成、结构化提取、聚类、画像更新、检索充分性校验)均由 LLM 完成,但均外置于基础模型之外。

# Q2 问题的新颖性

论文将已有工作归纳为三类:上下文窗口扩展(稀疏注意力、循环机制、长度外推——论文认为仅靠这类方法不足以解决问题,因为"迷失在中间"现象即便在更长窗口下依然存在)、检索增强/参数化记忆(RAG 及混合方案,论文称其"缺乏统一的持久记忆组织原则"),以及近期出现的记忆操作系统:Nemori(预测驱动的更新)、MemoryOS(层级化控制)、Mem0 与 Zep(通过知识图谱进行结构化事实维护)、MemOS(跨记忆类型的统一调度)。论文声称的新意在于,即便是这些记忆操作系统,其重点仍主要是*存储优化*或*事实维护*,依然把记忆当作相对扁平的记录集合;而 EverMemOS 转而实现了一套明确的、受生物学启发的三阶段*生命周期*——借鉴印痕(engram)形成、系统巩固、重建性记忆等理论——在检索之前先把情节痕迹整合为经过合成的语义结构(MemScene、用户画像),并引入了带时间界限的前瞻(Foresight,即受有效期区间约束的前瞻性推断)作为一种在对比基线中不存在的记忆基元。

# Q3 科学假设

如果把交互流切分为语义上稳定的 MemCell(情节叙事加原子事实加带时间界限的前瞻),通过增量聚类在线整合为具有不断演化的用户画像的主题化 MemScene,并通过一次主动的、经充分性校验的重建(MemScene 选择、情节/前瞻过滤,以及在检索不充分时触发查询改写的 agentic 校验)而非扁平的片段匹配来完成检索,那么下游的记忆增强推理将比基于片段的方法以及此前的记忆操作系统基线更准确——在需要整合分散证据的问题(多跳、时间性、知识更新)上收益尤为显著——同时保持检索的 token 成本处于适中水平,而非依赖不断扩大的固定检索预算。

# Q4 相关工作与关键人物

* 直接与五种记忆系统基线做对比:Zep(Rasmussen et al., 2025,本知识库尚未收录该论文)、[Mem0](2504.19413.md)、[MemOS](2507.03724.md)、MemoryOS(Kang et al., 2025)以及 MemU(一个开源记忆基础设施项目),在保留各基线自身官方记忆配置的前提下统一各方法的答案生成骨干模型(GPT-4o-mini 或 GPT-4.1-mini);LongMemEval 上的基线数字取自 MemOS 官方排行榜,而非本文作者对每个基线独立复现。
* 其生命周期框架借鉴自生物记忆理论而非既有的计算记忆工作:印痕形成(Josselyn et al., 2015)对应情节痕迹形成阶段,系统巩固(McGaugh, 2000)对应语义整合阶段,重建性记忆(Schacter, 2008)对应"检索即重建"的理念——这些理论被明确用作组织思路的启发,而非声称在神经层面进行仿真。
* 与 Mem0(单一类型的抽取事实记忆,通过 LLM 工具调用做出 ADD/UPDATE/DELETE/NOOP 决策)、MemOS(跨基质可调度的 MemCube 单元,带生命周期状态与治理元数据)共享本知识库的 [Agent memory](../topics/agent-memory.md) 主题;EverMemOS 对"记忆管理的基本单元是什么"这一问题给出的答案是一套三阶段生命周期,产出 MemCell 与 MemScene,而非单一的抽取流水线或跨类型资源单元。

# Q5 核心解法

1. **MemCell 基元** `c = (E, F, P, M)`——Episode(简洁的第三人称叙事锚点,已解决指代消解)、Atomic Facts(用于高精度匹配的离散可验证陈述)、Foresight(带有有效期区间 `[t_start, t_end]` 标注的前瞻性推断,用以区分"感冒"这类临时状态与"毕业"这类永久状态),以及 Metadata(时间戳、来源指针)。通过三步流水线形成:一个基于 LLM 的语义边界检测器通过滑动窗口在连续对话流中检测话题切换点(上下文分段);随后将得到的情节历史改写为连贯的第三人称 Episode(叙事合成);再通过 LLM 提示从该 Episode 中提取原子事实与带有效期区间的前瞻信号(结构化提取)。
2. **通过增量聚类实现语义整合。** 当一个新 MemCell 到达时,将其向量表示与既有 MemScene 的中心做比较;若相似度超过阈值 τ,则将其归并入最近的场景(增量更新该场景的表示),否则实例化一个新的 MemScene——这是一个无需批量重处理的在线过程。场景驱动的画像演化则在某个 MemCell 被归并入某场景时,通过对场景级摘要(而非原始对话轮次)进行提示,更新一个精简的用户画像(包括随时间变化的度量在内的显式事实,以及隐式特质),并支持基于时近性的更新与冲突追踪。
3. **遵循"必要且充分"原则的重建性检索。** MemScene 的选择通过对每个 MemCell 的 Atomic Facts 融合稠密检索与 BM25(经倒数排名融合 RRF),并以每个 MemScene 中匹配度最高的 MemCell 为其打分;在被选中的场景内,汇集并重新排序 Episode,并对前瞻信号进行过滤,仅保留有效期区间当前仍成立(`t_now ∈ [t_start, t_end]`)的 Foresight,丢弃已过期的部分;随后由一个基于 LLM 的校验器判断组装出的上下文是否足够回答该查询,若不充分则触发查询改写以补充检索,而非依赖固定的检索预算。
4. **共享同一流水线的两种下游模式。** 记忆增强推理仅使用检索到的 Episode 作为上下文(本文所有定量基准结果均采用该模式);记忆增强对话则额外纳入用户画像与当前仍然有效的前瞻信号——由于论文认为现有基准均未捕捉冲突检测、画像稳定性或基于前瞻的主动建议这类能力,该模式仅通过案例研究做定性评测。

# Q6 实验设计

在 LoCoMo(1,540 个问题,分布于 10 段超长对话,每段约 9K token,涵盖单跳、多跳、时间性、开放域问题)与 LongMemEval(S 设定,每段对话约 115k token,500 个问题,涵盖单会话用户/助手/偏好、多会话、知识更新、时间推理等类别)上评测,并在 PersonaMem-v2(9 个场景共 5,000 个问题)上做画像研究。基线为 Zep、Mem0、MemOS、MemoryOS、MemU,在统一答案生成骨干模型(GPT-4o-mini,另分开报告 GPT-4.1-mini)、各自保留官方记忆配置的前提下比较;评测采用 LLM 裁判协议(GPT-4o-mini 加两个辅助裁判模型,盲评,取平均),并以 Cohen's κ > 0.89 与人工标注做一致性验证。主要结果:在 LoCoMo 上,GPT-4o-mini 骨干下 EverMemOS 整体准确率达到 86.76%(相对最强基线 Zep 的 81.06% 提升 7.0%),GPT-4.1-mini 骨干下达到 93.05%(相对 Zep 的 85.22% 提升 9.2%),其中多跳(相对提升 19.7% / 12.1%)和时间性(相对提升 10.0% / 16.1%)问题类别的单项收益最大;在 LongMemEval 上,EverMemOS 整体达到 83.00%(相对最强基线 MemOS 的 77.80% 提升 6.7%),其中知识更新这一类别相对提升达 20.6%。EverMemOS 每次查询的平均上下文 token 成本为 2.3k-2.8k——高于 Mem0 的 1.0-1.1k,但与 MemOS 的 1.4-2.5k 大致相当,明显低于 MemoryOS 的 5.2-5.5k。在 LoCoMo 上的消融实验显示,依次移除 MemScene(丧失跨情节聚合能力)、再移除 MemCell(退化为原始对话检索)、再完全移除外部记忆(长程性能严重下降),呈现逐层下降的趋势,从而分离出各结构层的贡献。分段策略对比显示,论文所用的基于 LLM 的语义分段优于固定启发式(固定消息数或 token 阈值),甚至优于使用真实会话边界的检索("Session Oracle"),且在两种不同的分段骨干模型(GPT-4.1-mini、Qwen3-4B)下结果稳健(差异 ≤0.7 个百分点)。在 PersonaMem-v2(32k 版本)上,在情节证据基础上加入用户画像,整体准确率提升 9.32 个百分点(53.25 对比仅用情节的 43.93),表明语义整合提供了超出情节检索本身的额外信号。

# Q9 主要贡献

1. 一套明确的、受生物学启发的三阶段记忆生命周期(情节痕迹形成→语义整合→重建性回忆),在检索之前把碎片化的情节经验整合为主题化的 MemScene 与用户画像,而非把记忆当作扁平、孤立的记录。
2. 一种新的记忆基元 MemCell(情节 + 原子事实 + 带时间界限的前瞻 + 元数据),把带时间范围、可过期的前瞻性推断作为一种在对比基线中不存在的一等记忆组件引入。
3. 在 LoCoMo(整体准确率相对提升 7.0% 至 9.2%)与 LongMemEval(整体准确率相对提升 6.7%)上,相对五种记忆系统基线报告了达到当前最优水平的结果,尤其在多跳、时间性和知识更新类问题上收益不成比例地更大,并辅以一项分层消融(依次分离 MemScene/MemCell/外部记忆的贡献)与一项分段策略对比(其表现甚至超过使用真实会话边界)。

# Q10 下一步

* 论文自身声明的局限性:评测仅限文本,尽管其声称 MemCell/MemScene 抽象是模态无关的;LLM 介导的记忆构建与检索相较单次推理基线增加了延迟/成本,缓存、批处理、异步化等优化留待未来工作;目前没有基准能对超长时间跨度做压力测试,因此本文的评测无法完全隔离该区间下的性能表现——论文自己也据此提出,未来需要针对长期记忆组织与整合设计新的基准。
* 本笔记无法从检索到的文本中解答的问题:报告的收益对治理 MemScene 归并的相似度阈值 τ 有多敏感(本文报告了 MemScene 数量的敏感性分析,但未见针对 τ 本身的敏感性扫描);以及基于 LLM 的语义分段战胜真实会话边界这一结果,在比 LoCoMo 更嘈杂、构造程度更低的交互流上是否依然成立。
* **与本仓库的关联**:EverMemOS 的前瞻(Foresight)基元——一种带明确有效期区间、会过期的前瞻性推断——是本知识库 [Agent memory](../topics/agent-memory.md) 主题一直在追问的"可审计、带溯源的记忆更新"这一诉求的一个具体实例;将其基于时近性的冲突追踪机制,与 Mem0 的 ADD/UPDATE/DELETE/NOOP 工具调用决策、MemOS 的生命周期状态治理元数据做对比,是该主题页下一次值得更新的综合分析方向。

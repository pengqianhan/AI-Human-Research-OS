# Q1 问题定义

* **输入（X）：** 一个仓库级软件工程（SWE）实例，包括仓库、基准提交版本、自然语言问题描述、可复现的 Docker 环境，以及隐藏的可执行验证器（fail-to-pass 与 pass-to-pass 测试）。另有一个工具调用型智能体脚手架（训练与 Pro-618 评测用 R2E-Gym），让语言模型策略能搜索、编辑、执行 shell 命令和测试并提交补丁。训练从同一个基座模型 Qwen3.6-27B 出发。
* **输出（Y）：** 一个可部署的 SWE 策略，其二元可执行成功率*在总体上且在每个任务类别上*都高于在同样数据上做联合强化学习得到的策略。
* **核心问题：** SWE 任务是异质的：服务/数据层修复、面向用户的界面改动、构建与工具链修复、性能或安全补丁各不相同。在混合数据上用 RL 训练单一策略时，论文观察到**类别跷跷板**（category see-saw）：一些类别变好的同时另一些类别在退步，而总体解决率把这一点掩盖了。论文要回答两个问题：（a）按类别平衡数据能否解决它；（b）先训类别专家再合并成一个模型，能否做得更好。
* **约束：** 专家训练与整合的全过程都不借助更强的外部模型提供解题轨迹或动作目标。类别是*可观测的任务标签*，而非潜在能力。部署时学生模型只看到普通的任务与工具观测，路由只在训练中使用。

# Q2 问题新颖性

部分新颖。LLM 后训练中的多领域相互干扰、专家拆分与融合（Branch-Train-Merge）、多教师在策略蒸馏（MOPD，Ma 等，2026）以及带奖励外推的蒸馏（ExOPD，Yang 等，2026）都早于本文。但这些工作按常规领域边界拆分（数学 / 代码 / 指令遵循），专家划分是现成的。本文的新意在于把"先专精、再整合"用到*单一领域内部*，即仓库级 SWE。这里没有天然划分，论文用一套有证据依据的标注体系构造出划分，并用明确指标（最小类别增益、跷跷板差距）把领域内的跷跷板变得可测量。作者称，就其所知，这是首个训练类别专属 SWE RL 专家、再通过标签路由 MOPD 合并的研究。这对编程智能体后训练很重要：一个总体 SWE-bench 分数可能在上升，同时整类任务在悄悄变差。

# Q3 科学假设

如果围绕可观测的任务类别组织 SWE 训练：每个类别有自己的 RL 专家，并反复做三件事——按当前掌握度重新定位（刷新）、在自己验证通过的成功轨迹上巩固（修复）、转向新的有信息量的任务前沿（扩展）；然后在学生自己的轨迹上把各专家蒸馏进一个学生，且只外推每位教师*有所改进*的方向——那么这个单一学生在总体解决率*和*最弱类别上都应胜过混合式联合 RL 与类别平衡式联合 RL。论文先检验一个次要假设：仅在单一训练流里平衡类别数量，并不能消除跷跷板。

# Q5 关键解法思路

按流水线顺序分四部分：

* **SWE Labeler（SWE 标注器）。** 一个有证据依据的层级标注器（用 Qwen3.7-max 运行），为每个 issue-改动实例或智能体轨迹打标签，包括两条语义轴——任务类型（26 个一级 / 119 个二级标签）和仓库领域（21 个一级 / 108 个二级标签）——以及三条四级规模轴（修改范围、认知复杂度、预估解决时间）。每个细粒度标签都是一条决策记录：把权威来源（ISO/IEC 25010、ISO/IEC/IEEE 14764、MITRE CWE、Fowler 重构目录、框架文档）对应到操作规则、正向信号以及与相邻标签的边界。一条确定性规则把 18 个可路由的领域一级族合并为三路：**A** 服务/数据/安全，**B** 面向用户的应用，**C** 系统/工具链/运行时。
* **Agentic-miniRL。** 把 MiniRL 的行为校正 token 级替代目标改造到长程多轮 SWE 轨迹上：用 RLOO 留一法优势（避免包含自身的均值把大多失败组里罕见的成功信号再缩小）；把 K1 参考对数比放进 token 奖励、并在计算未来回报之前扣除；用截断重要性权重加符号感知的近端掩码；损失按轮次聚合——先在每个助手轮内对 token 求和，再在轮次与轨迹间取平均。
* **刷新—修复—扩展（Refresh-Repair-Expand，RRE），逐类别训练专家。** *刷新*：每个 RL 和 SFT 阶段后都用新的 rollout 重新估计各实例通过率，因为掌握度是"策略—实例"对的属性，会随策略漂移。*修复*：在上一 RL 阶段专家自己的、经验证器认可的轨迹上做 SFT，低掌握度实例重放更多（4 次中成功 0-1 / 2 / 3 / 4 次，分别对应 4 / 3 / 2 / 1 条轨迹）。*扩展*：加入先前排除的基座通过率为 0 或 1 的任务并重新探测，下一轮 RL 只保留有信息量的前沿，加上当前未解但有历史成功证据的任务。
* **带 ReLU 门控外推的标签路由 MOPD。** 学生（从基座重新初始化）在类别平衡的任务混合上做 rollout，每个任务只查询其所属类别的专家。每个 token 的优势 = 模仿项（教师对数概率减 rollout 对数概率）+ λ·ReLU（教师对数概率减参考对数概率）。ReLU 只保留专家相对共同基座有提升的 token；没有它时，在作者的运行中正负外推项大体相互抵消。整合是纯蒸馏：环境奖励不进入学生损失。

# Q6 实验设计

* **研究问题。** RQ1：平衡 RL 能否消除混合 RL 下的跷跷板？RQ2：初始类别专家够不够，RRE 如何发展它们？RQ3：MOPD 能否把专家合并成一个在总体和每个类别上都胜过两种联合 RL 基线的策略？
* **数据。** 从合并的 PR 和 issue 挖出约 32K 个可执行候选（LLM 改写问题描述，做泄漏与污染过滤，并多次验证 gold patch）。按基座通过率在 (0, 0.5) 选出 3,048 个合成任务，与 3,675 个 SWE-rebench V2 任务合成 6,723 个任务的语料，其中 2,769 个映射到 A/B/C（601 / 516 / 1,652）。混合 RL 在全部 6,723 个上训练；平衡 RL 每类 516 个（共 1,548）。表 4 给出各阶段的修复与扩展数量。
* **评测。** 主基准 **Pro-618**：从 731 题的 SWE-bench Pro 中剔除公开确定性审计标记的 113 题（83 个机械可证的规格缺陷、26 个评分选择不确定、3 个参考补丁在评分器重放中失败），以及 1 个 OpenAI 记录的提示—测试不匹配。它按领域拆成 Pro-A/B/C = 221/201/196。次基准：SWE-bench Multilingual（300 题，SWE-agent 脚手架；A/B/C/未分配 = 72/25/176/27）。终点结果为三轮的均值与总体标准差，每轮每题一条轨迹，分母固定（失败与违规计零分）。
* **指标。** 总体解决率、各类别解决率、最小类别增益、*跷跷板差距*（总体增益减最小类别增益）、相对各基线的最小类别提升，以及专家增益保留率（MOPD 类别增益除以专家增益）。Multilingual 上的总体差异给出配对实例自助法 95% 区间。
* **完整性控制。** 一次试点审计发现智能体会执行 `git log --all`、读取未来对象、添加上游远端、上网搜索修复方案。因此协议会清理仓库（删除远端、非当前分支、基准后的标签、reflog 与不可达对象），延迟注入测试，只把清理后的源码补丁放到全新沙箱重放，并扫描完整轨迹检查外部答案检索。确认的检索计零分。
* **未设计的部分（作者自述）：** 没有组件消融（RLOO 对 GRPO、K1 位置、ReLU 门控、重放配额、路由粒度），只用一种三路划分，并且 Pro-618 同时用于检查点选择和最终报告。

# Q8 证据质量

* **有支持：**
  * *跷跷板与平衡 RL（RQ1）。* 混合 RL 与平衡 RL 终点总体分几乎相同：55.50% 对 55.34%，即比 52.64% 的基座高 +2.86 和 +2.70。在 50 个检查点上，平衡把平均最小类别增益略微提高（0.19 对 0.08 个百分点），但没有缩小平均跷跷板差距（1.18 对 1.05）。所以仅靠平衡解决不了跷跷板。
  * *初始专家不够（RQ2）。* 初始类别 RL 在 Pro-A/B/C 上为 53.54 / 55.06 / 52.55，低于混合 RL 终点的 54.75 / 56.72 / 55.10。在配对的训练记录上，平均成功率上升 7.26 / 6.76 / 4.60 个点，但 2,769 条中有 839 条（30.3%）下降。
  * *修复能挽回退步。* 第一次修复 SFT 后，训练记录成功率为 56.28 / 59.59 / 52.75%。在获得修复数据的退步记录中，69.8% / 73.0% / 61.3% 回到或超过基座水平。RRE 结束时，各专家在本类别上比基座高 +7.84 / +4.48 / +5.61，比混合 RL 终点高 4.83 / 2.16 / 2.38。
  * *单一学生胜过两种基线（RQ3）。* MOPD 在 Pro-618 上总体达到 58.04%（Pro-A/B/C 为 58.07 / 59.37 / 56.63），比混合 RL 高 +2.54，并且每个类别都更高：相对混合 RL 的最小类别提升为 1.53，相对平衡 RL 为 2.04。它相对基座的最小类别增益（4.76）约为混合 RL（2.32）的两倍，也高于平衡 RL（2.65）。专家增益保留率在 A/B/C 上为 80.8% / 111.1% / 84.8%。
* **弱于标题所示：**
  * *选模与报告共用基准。* Pro-618 在 RRE 每个阶段都用于选检查点，*同时*用于最终对比。这有利于多阶段专家管线，因为它比单次混合训练有多得多的挑选机会。
  * *次基准结论较弱。* 在 SWE-bench Multilingual 上，MOPD 比平衡 RL 高 +2.00，但配对自助法 95% 区间为 [−0.78, 4.78]，与零无法区分。C 类（300 题中的 176 题）相对基座没有变化（61.74%）。混合 RL（55.56%）在这个基准上其实*低于*基座（56.22%）（读者观察）。
  * *均匀性结论不一。* MOPD 的跷跷板差距（0.63）比平衡 RL（0.04）更宽。论文把这归为"差距变宽的共同提升"，而不是更均匀的增益分布。
  * *算力不对等。* 三个专家、两轮 RL、两轮 SFT，再加一个查询教师的蒸馏阶段，成本远高于一次混合训练。论文没有报告算力匹配的联合 RL 基线，因此增益有多少来自类别结构、多少来自额外训练，并未分离。
  * *缺少消融。* 各组件（RLOO、K1 放入奖励、ReLU 门控、按掌握度加权的重放）的作用是论证出来的，没有逐一消融。
* **完整性方面：** 防作弊协议是真正的优点。在全新沙箱中重放清理后的补丁，排除了篡改 rollout 状态的可能。作者承认它不能排除预训练记忆。

# Q9 贡献

* 给出单一领域内**类别跷跷板**的可测量定义（最小类别增益、跷跷板差距），并证明仅做类别平衡的数据无法消除它。
* **SWE Labeler**：一套可审计、多轴的 SWE 分类体系，标签契约采用"来源→规则→边界"的结构。它能区分不同基准的构成：SWE-bench Verified 中 87.0% 是缺陷修复、86.2% 是单文件改动，而 SWE-bench Pro 中 47.3% 是缺陷修复、59.2% 需要跨模块改动。
* **RRE**：一个无需外部教师的专家发展循环，把实例掌握度视为依赖于当前策略、在阶段之间重新估计，并实测挽回了 RL 造成的实例级退步。
* 一套可用的领域内**带 ReLU 门控外推的标签路由 MOPD** 配方，能在一个 27B 策略中保留三个专家的大部分增益。
* 一套可复用的 SWE RL **奖励完整性协议**（仓库清理、延迟注入测试、全新沙箱重放、扫描轨迹中的答案检索）。

# Q10 下一步

* **算力匹配的基线与消融：** 给混合 RL 同样的总 rollout 数、同样的"在自己的成功上做 SFT"以及同样的选模预算；逐一消融 RLOO 对 GRPO、K1 位置、ReLU 门控和重放配额。
* **留出式选模：** 在不相交的划分上选检查点，让 Pro-618 成为干净的测试集，并同样为 Pro-618 报告置信区间。
* **软路由或多标签路由：** 作者指出任务可能跨类别，而硬路由只分给一个专家。路由粒度（3 路对全部 18 个领域一级族）尚未检验。
* **A 类为何保留最少：** A 类专家增益最大，保留率却最低（80.8%）；Open-MOPD 对预算失衡的诊断是显而易见的下一步。
* **与执行框架层面工作的联系（读者构想）：** 跷跷板指标同样适用于执行框架或技能演化。在总体分之外报告各类别最小增益，可以暴露 [RRSI](../papers/2609.24972.md) 和 [SoL-Pi](../papers/2609.20519.md) 在分布外所防范的那类隐藏退步。
* **与本仓库的契合（读者笔记）：** RRE 的规则"掌握度属于当前策略，重新选数据前先重新探测"，是本仓库任何迭代式智能体改进循环都能采用的廉价纪律。

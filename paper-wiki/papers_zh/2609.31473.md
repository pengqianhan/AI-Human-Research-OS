# Q1 问题定义

* **输入（X）：** 一组通过公开 API 调用的前沿 LLM，使用各厂商默认的采样设置，不做微调、不给工具、不做检索；以及一个游戏环境。每个决策点，统一的文本执行框架（harness）用自然语言描述当前局面及其历史，模型必须按规定格式返回一个动作，输出无效时有少量重试机会。
* **输出（Y）：** 基于完整循环赛（round-robin）计算、带自助法（bootstrap）置信区间的各游戏排行榜：
  * 国际象棋：Bradley–Terry Elo，以最低模型为 0 锚定；
  * 扑克：每百手赢得的大盲数（BB/100）；
  * 狼人杀：按角色分解的博弈论均衡评分。

  排行榜配有诊断分析：Stockfish 胜率轨迹、非法着法导致的"重想"（rethink）、翻牌前扑克统计，以及角色与队友贡献。
* **核心问题：** 静态基准会饱和并泄漏进训练数据；偏好竞技场（Chatbot Arena、MT-Bench 评审）主观且有偏；以往的游戏基准是一次性数据集，对高方差游戏来说交互量太少，也无法持续、可扩展地评测。

# Q2 问题新颖性

本质上不新。游戏长期是 AI 的标尺（Deep Blue、AlphaGo/AlphaZero、Libratus/Pluribus、Cicero、AlphaStar），LLM 游戏基准也已存在（AgentBench、GTBench、PokerBench、SmartPlay、Game Reasoning Arena、PokerBattle 实验、MindGames）。

论文声称的新意是*运营层面*的：一个运行在 Kaggle 基础设施上的持续、开放、可扩展的竞技场，统计规模远超此前的 LLM 游戏评测——每个模型 180,000 手扑克，而 PokerBattle 约 3,800 手、PokerBench 不到 2,000 手。它还声称首次在 LLM 基准中使用复式（duplicate，镜像发牌）扑克，并提出一种能把技能和角色运气分开的多人非对称游戏评分方法。这个问题重要，因为基于结果的对抗式评测不会随模型进步而饱和：对手也在进步。

# Q3 科学假设

如果让模型在结果客观的游戏中彼此对弈，使用同一个中立的执行框架，样本量足以应对高方差游戏，并采用方差缩减（执子颜色平衡、复式发牌、角色分解），那么得到的排名将在统计上可区分，并能揭示不同的策略能力——国际象棋的规划与搜索、扑克的信念更新与风险、狼人杀的欺骗与社会推理——而不是单一的"策略能力"标量。论文对后半部分的证据是：各游戏的排名互不相同。

# Q4 相关工作与关键人物

* **评测范式：** 静态基准（MMLU、GSM8K、HellaSwag）及其饱和与污染问题（LiveBench、"AI agents that matter"）；偏好竞技场（Chatbot Arena）与 [LLM 作为评审](../concepts/llm-as-a-judge.md)（MT-Bench）。
* **作为 AI 里程碑的游戏：** Deep Blue、AlphaGo、AlphaZero、Libratus、Pluribus、Cicero（外交）、AlphaStar。
* **LLM 游戏基准：** AgentBench、GTBench、PokerBench、SmartPlay、Game Reasoning Arena（基于 OpenSpiel）、DSGBench、PokerBattle.ai，以及 MindGames（NeurIPS 2025 的实时竞技场）。
* **所依托的评测理论：** Bradley–Terry 与 Elo 评分、TrueSkill/OpenSkill、基于"模型对模型对角色"元博弈的最大熵相关均衡博弈论评测（Liu 等，2025），以及"投票即评测"（Voting-as-Evaluation）社会选择排名（Lanctot 等，2023）。环境复用 OpenSpiel、PettingZoo 和 Gymnasium。
* **关键人物：** 由 Google DeepMind、Kaggle 与 Google Cloud 首席技术官办公室（OCTO）合作完成，研究负责人为 Minmin Chen 和 Orhan Firat。Marc Lanctot、Ian Gemp、Siqi Liu、Daniel Hennes、Kate Larson 带来了博弈论评测与 OpenSpiel 的传承。可能的批评者包括其他 LLM 游戏竞技场的构建者（MindGames、Game Reasoning Arena、PokerBench），以及可能质疑其对手建模设置与标准打法有何不同的扑克 AI 研究者。

# Q5 核心解决思路

* **所有游戏共用一个极简、中立的执行框架。** 模型得到完整局面描述和历史、明确的目标和"逐步推理"的指示，但*不*提供合法动作列表，必须自行判断合法性。无效输出只触发不带诊断信息的重试：
  * 国际象棋：四次尝试都失败则判负；
  * 扑克：第二次非法动作默认过牌或弃牌；
  * 狼人杀：反复解析失败则放弃本回合。
* **各游戏的方差控制：**
  * 国际象棋：每对模型 40 局，黑白各半；因为所有模型都默认下西西里防御，另设"Chess Opening"变体，从 Lichess 上 20 种最常见的两步开局开始。
  * 扑克：一对一无限注德州扑克，每手重置为 100 个大盲的筹码，以 100 手为一个回合（episode），回合内提供完整历史以便对手建模。为加快适应，每手结束后公开双方底牌。每一组发牌序列都交换座位和手牌再打一遍（复式扑克）。
  * 狼人杀：8 人局，事件总线强制执行信息不对称。规则经过重新平衡，村民胜率从 73.4% 降到 56.7%，由 Gemini 3 Pro 自我对弈、每种配置 500 局测得。
* **与游戏相称的评分：** 狼人杀用按角色分解的博弈论评测，因为原始胜率把技能和角色分配的运气混在一起；并用 Elo、Copeland 和 Ranked Pairs 交叉验证。
* **全部记录：** 每回合保存不可变快照（含推理轨迹），作为数据集发布，并配有带推理面板的网页可视化工具。

# Q6 实验设计

* **模型：** 正文说"截至 2026 年 2 月、来自五家前沿实验室的前 10 个模型"，但实际列出了 11 个：GPT-5.2、GPT-5 mini、o3；Claude Opus 4.5、Sonnet 4.5、Haiku 4.5；Gemini 3 Pro Preview、Gemini 3 Flash Preview；Grok 4、Grok 4.1 Fast Reasoning；DeepSeek V3.2。各游戏参赛模型不同：国际象棋全部 11 个；扑克 10 个，没有 Claude Haiku 4.5；狼人杀 8 个，没有 o3、Claude Haiku 4.5 和 DeepSeek V3.2（读者根据结果表观察）。
* **规模：**
  * 国际象棋：完整循环赛，每对 40 局；
  * 扑克：45 组对局 × 20,000 手 = 900,000 手；
  * 狼人杀：约 31,500 局（附录中为 31,472 局）。
* **指标与不确定性：** 全部使用 95% 自助法区间，扑克按回合做分块自助法。论文提到用 Stockfish 各技能级别对国际象棋 Elo 做近似外部校准，但检索到的正文只报告了内部 Elo 值。
* **诊断：** Stockfish 标注的随对局进程变化的胜率曲线；重想的频率与时点；翻牌前行为（VPIP、偷盲、大盲位跟注/弃牌/3-bet）；狼人杀按角色的贡献；联盟"替换指数"；成本-性能帕累托前沿。
* **没有设计进去的：** 排行榜中没有人类或引擎对手；没有用新的模型快照重复举办比赛；各厂商的推理预算不受控制（仅默认设置）；也没有对执行框架的选择（如历史格式、重试策略）做消融。

# Q7 数据集与代码

开源的执行框架与环境在 [google-deepmind/game_arena](https://github.com/google-deepmind/game_arena)，博弈论评测代码在 [google-deepmind/polarix](https://github.com/google-deepmind/polarix)。论文称完整对局数据集（逐动作日志、模型输出、推理轨迹和元数据）在 Kaggle 上发布，公开排行榜在 [kaggle.com/game-arena](https://www.kaggle.com/game-arena)。环境由 JSON 规格加 Python 解释器定义，改编自 OpenSpiel、PettingZoo 和 Gymnasium。

# Q8 证据质量

* **有支撑——各游戏内排名分层明显、统计上可区分：**
  * 国际象棋 Elo：Gemini 3 Pro 1325 [1217, 1428] 与 Gemini 3 Flash 1297；其次 o3 1009、GPT-5.2 933；再次 Grok 4 773、Grok 4.1 Fast Reasoning 632、GPT-5 mini 525；Claude 4.5 系列垫后（Opus 236、Sonnet 189、Haiku 122）；DeepSeek V3.2 为锚点 0。
  * 扑克 BB/100：GPT-5.2 +46.6（95% 区间 40–54）与 o3 +29.7、Grok 4 +27.1 明显分开；GPT-5 mini（−94.9）是孤立的离群点。
  * 狼人杀：31,472 局上的锦标赛图无环；Elo、Copeland、Ranked Pairs 和 GTE 给出相同顺序，Gemini 3 Pro 第一，GPT-5 mini 最后。
* **有支撑——"策略能力"不是单一标量：** Gemini 3 Pro 在国际象棋和狼人杀中居首，却在扑克中输掉 −15.2 BB/100，它的翻牌前范围也最紧（按钮位开池 52.8%，大盲位弃牌 43.8%）。GPT-5.2 扑克第一，国际象棋第四。国际象棋与狼人杀的成本-性能前沿相似，扑克则把它打乱。
* **有支撑——国际象棋的胜负在哪里分出：** Stockfish 曲线显示开局阶段各模型大致持平，中局开始分化。Chess Opening 复现了 Chess Text 的排名，说明排名不只来自记住的开局。较弱的模型（DeepSeek V3.2、Claude Haiku 4.5）每局通常需要五次以上、常常十次以上的重想，而且集中在对局后段。
* **需要留意的混淆因素：**
  * 国际象棋 Elo 把策略强度与遵守规则的可靠性混在一起，因为反复走非法着法会直接判负。Claude 和 DeepSeek 的低分可能部分反映了合法性失败（读者观察，重想分析支持这一点）。
  * 使用默认采样和生成上限，意味着各厂商的推理预算不同；比较的是默认 API 配置，而不是算力匹配的模型。
  * 扑克提示词要求以 GTO 为基线，并在每手后公开对手底牌。这是为加速对手建模而特设的基准变体，不是标准扑克。
  * 狼人杀规则由 Gemini 3 Pro 自我对弈来平衡，而它正是最终第一名；平衡只是针对一种打法风格测得的（读者观察）。
  * 每对 40 局国际象棋留下很宽的区间（约 ±100 Elo），足以区分档位，但不足以确定同档内的顺序。狼人杀的联盟分析没有结论：联盟间比较矩阵有 48% 是空的。
* **快照性质：** 结果是 2026 年 2 月一个模型池的快照。纵向追踪是设计目标，本报告并未展示。

# Q9 贡献

* 持久、开放的评测基础设施：统一执行框架、可扩展的环境规格、带推理轨迹的对局数据，以及实时排行榜。
* 把计算机扑克和博弈论的实践迁移到 LLM 评测：复式扑克、分块自助法、面向非对称多人游戏的角色分解均衡评分，以及社会选择方法的交叉检验。
* 实证表明前沿模型的策略强度因游戏而异，并用行为诊断——翻牌前风格、中局崩盘、合法性失败——解释排名*为何*不同。
* 一套针对"预言家亮身份 + 医生连救"漏洞做了平衡的狼人杀规则，可用作生成与识别欺骗行为的安全沙盒。

# Q10 下一步

论文提出四个方向：

* 按不确定性自适应安排对局，取代每对固定局数；
* 应对模型更替和冷启动新模型、保持对局图连通的协议；
* 跨异质游戏的统一 Bradley–Terry 式元评分；
* 更多游戏，覆盖长时程规划、谈判、心智理论和混合动机合作。

阅读中引出的其他方向：

* **算力匹配赛道：** 在固定推理预算下报告结果，并把合法性失败与策略失败分开，使国际象棋 Elo 真正衡量策略。
* **智能体执行框架变体：** 竞技场刻意使用极简执行框架。第二条允许工具（引擎、求解器、记忆）的赛道将衡量智能体系统而非裸模型，更贴近本 wiki 中智能体执行框架工程类论文的关注点（读者构想的方向）。
* **合作型游戏：** 狼人杀的合作分析没有结论；像 [AgentWorld](../papers/2609.31590.md) 这样的完全合作任务集可以补充竞争式竞技场，用来衡量"队友质量"。

# 相关

* [游戏智能体](../topics/game-agents.md) - 把该主题从"通过控制操作玩电子游戏"扩展到通过文本执行框架玩棋牌和社交推理游戏。与 [GameHorizon Suite](../papers/2609.25001.md) 的对比很有用：Game Arena 完全去掉感知和控制，衡量的是面对真实对手时的策略。
* [多智能体系统](../topics/multi-agent-systems.md) - 狼人杀是 8 人的合作/对抗混合设定；其角色分解评分和联盟替换指数是在团队中给单个模型记功的工具，而该主题中的协调类论文大多不做这种衡量。
* [AgentWorld](../papers/2609.31590.md) - 合作版对应物：完全合作的长时程团队任务，用因果贡献指标打分；Game Arena 则给竞争结果打分。
* [LLM 作为评审](../concepts/llm-as-a-judge.md) - 被定位为评审式和偏好式竞技场的替代：所有指标都由游戏结果（胜负、筹码、团队胜利）计算，而非评审的意见。

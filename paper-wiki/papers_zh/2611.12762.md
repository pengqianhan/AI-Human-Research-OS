# Q1 问题定义

* **输入 (X)：** 一个研究问题、初始证据（文献、已有结果、专家意见）、一个可复用的认知方法库（Cognitive Repertoire）、停止规则和预算。
* **输出 (Y)：** 一组经过审查的研究想法，每个都是完整的方案，包含机制或设计、支撑文献、约束、可检验的推论和待查的不确定性；或者可执行的计划，其实验或仿真结果作为证据回流。输出附带支撑证据和未解决的问题。
* **约束：** 在基准对比中，所有 harness 都使用高推理强度的 GPT-5.6-Sol，每个任务必须给出 K = 10 个想法。在真实合作案例中，由领域专家选择要推进的想法并验证其实施。

# Q2 问题新颖性

不是新问题。迭代式的 AI 科学家工作流已经存在：The AI Scientist 和 AI Scientist-v2、Google 的 Co-Scientist、Robin 和 EvoScientist。论文的论点是：只靠最近一轮反馈驱动的迭代，不能把不同分支的发现连同其证据和适用条件一起保留下来，于是早先的失败、未解决的冲突、多个想法共同依赖的前提会被忽略，搜索也会对最近的结果反应过度。它声称的区别是：有一份显式的、可修订的记录，写明搜索当前理解了什么，并用它来选择目标和推理方法。

# Q3 科学假设

如果科学智能体对自己的搜索保持一个显式的元层模型（哪些已有支撑、哪些存在冲突、哪些假设被多个想法共用），并通过监控（monitoring）和控制（control）用它来选择下一个目标以及从可复用方法库中选哪种推理方法，那么在相同基础模型上，它会比迭代式 harness 复现更多真实研究做出的决策，提出更新颖、更多样的想法，并且它的方案能接到实际验证上。

# Q4 相关工作与关键人物

* **AI 科学家。** The AI Scientist 和 AI Scientist-v2、Co-Scientist、Robin、Kosmos；通过批评来改进假设的系统（包括 ARIS）；带持久记忆或共享表示的系统（包括 EvoScientist）；以及像 AlphaEvolve 那样用执行结果引导搜索。
* **科学构思。** 把想法建立在已有研究上并与之核对的系统（包括 ResearchStudio-Idea）；追踪想法谱系的搜索方法；对探索广度、专家在实施前后的判断、以及方案如何承接已有研究（IG-Arena）的评测。
* **认知科学。** 把问题求解看作在表示和算子上的搜索（Newell 和 Simon），Nelson 和 Narens 用监控与控制连接的对象层和元层，把策略选择看作元推理，类比映射，图式归纳，基于案例的学习。
* **智能体的认知架构。** CoALA、Generative Agents、Reflexion、对 LLM 推理中认知要素的分析，以及根据推理状态选择推理模式的 Chain of Mindset。
* **关键人物。** 署名为"Sage-Taiyi Team, Shanghai Artificial Intelligence Laboratory"；arXiv 列出 90 位作者。附录 A 列出十位主要作者（Weida Wang、Benteng Chen、Yigeng Jiang、Shuchen Pu、Weiping Shen、Zichao Liu、Yulin Su、Zitong Wang、Siyu Zhou、Zifu Wang），项目负责人 Bo Zhang 和 Shufei Zhang，顾问 Li Cao、Lei Chen、Dahua Lin、Xing Xie、Bowen Zhou。同一实验室的 Sage-A1.5（arXiv:2610.28578）被引用为该 harness 所依托的编排与验证能力。可能的批评者：AI Scientist-v2、Co-Scientist 和 Robin 团队。

# Q5 核心方法

**对象层：搜索本身。**

* *目标树（Target Tree）。* 研究问题是根；目标和子目标记录要求与完成标准，每个子目标配有局部策略，策略产出子想法（部分解）。当想法暴露出没有任何目标覆盖的要求时，树会被修订。
* *想法图（Idea Graph）。* 想法是节点，变换是边，跨越所有目标分支。五种变换产生新想法：Merge（合并相似做法）、Fuse（在核对假设和接口相容后组合互补机制）、Diverge（开出一条不同的分支）、Repair（修复有缺陷的依赖或缺失的接口）、Evolve（保留核心机制的同时改进）。每个想法都链接到它的父想法和促成它的评估。
* *证据状态（Evidence State）。* 实验和计算结果、文献、专家意见，每条都关联其来源、相关想法和适用条件。

**元层：搜索进行得怎么样。**

* *认知状态（Cognitive State）。* 对当前理解的有选择、带来源的概括（关键发现、相互竞争的解释、必要假设、适用条件、未决问题），加上监控给出的评估：关键判断的支撑程度、还剩哪些冲突、想法之间共用哪些依赖。论文的例子：当多个想法建立在同一个未经检验的前提上时，它们的一致会被记为"不构成独立支持"。
* *认知方法库（Cognitive Repertoire）。* 十种组织整条研究路径的方法论启发式（证据驱动发现、模型驱动发现、类比迁移、表示驱动的重新表述、组合式综合、逆向设计、约束搜索与规则归纳、主动假设检验、瓶颈驱动的再设计、能力驱动的前沿拓展），以及认知算子（Cognitive Operators），即按 Framing、Constructing、Evaluating、Learning 分组的局部推理步骤。通用条目通过经典论文针对各学科具体化，并根据任务反馈修订。

**循环（算法 1）。** 监控根据当前搜索状态更新认知状态；控制选择下一个任务和关注点；如果是构思任务，就选出方法库条目并应用它们来更新目标树和想法图；否则 harness 把任务变成带工具和技能的执行或验证计划，结果进入证据状态。子智能体并行探索各分支。

**真实场景中的用法。** Sage-Taiyi 提出候选路线并定义变量、目标和约束；专家选定其中一条；Taiyi-Optimizer（在化学案例中是贝叶斯优化）搜索条件或设计空间；测量或仿真结果作为证据回流。

# Q6 实验设计

* **Taiyi-Bench（作者自建基准）。** 把 50 项在 2026 年 3 月 1 日及之后首次公开的研究（晚于 GPT-5.6-Sol 报告的知识截止日期）的关键决策重建为 DAG，265 个任务从 L0 级（找出根本问题）起逐级披露这些决策，覆盖十个学科。复现类指标：Finding、Exact、Coverage、Lookahead。开放式指标：Novelty、Effectiveness、Feasibility、Diversity。由一个以文献为依据的验证器按决策级评分细则打分；Overall 是两组平均分的均值；Elo 来自对任务级两两结果的 Bradley-Terry 模型。
* **基线。** 直接生成（GPT-5.6-Sol、Claude-Opus-5、Gemini-3.7-Flash）；通用 harness（Codex 配 GPT-5.6-Sol 的 high 和 ultra 两档，Claude Code 配 GPT-5.6-Sol 或 Claude-Opus-5）；科学发现 harness（EvoScientist、AI Scientist-v2、Robin），只保留其构思阶段。
* **外部基准。** AgentIdeaBench（40 个子领域，五个评分维度的加权分），与本地运行的 AI Scientist-v2、Codex、Claude Code 对比；IG-Arena（30 个前沿问题，Population-Evolution Score），与四个已发表的参考分数对比。
* **案例。** 一条 L2 级通信工程轨迹（200 GHz 接收机）和一个 IG-Arena 量子计算问题，用来展示目标树、想法图和状态更新。
* **五项合作。** 钴催化羰基化、光催化烯丙位胺化、超材料带阻滤波器、铸造镁合金、离心压气机。

Taiyi-Bench 是本文提出的；正文没有说明其任务、DAG、评分细则或验证器是否发布。HTML 中只有一个"Homepage"链接；`hf papers info` 列出了项目页（`https://alpha-innovator.github.io/Sage-Taiyi/`）和 GitHub 仓库（`https://github.com/Alpha-Innovator/Sage-Taiyi`，阅读时 3 星），仓库内容未检查。AgentIdeaBench 和 IG-Arena 是外部基准。

# Q8 证据质量

* **有支撑的结论。**
  * *在相同基础模型下，Taiyi-Bench 八项指标全部第一。* Overall 53.95，AI Scientist-v2 为 47.85，Claude Code（GPT-5.6-Sol）44.14，直接用 GPT-5.6-Sol 为 39.56。复现类平均 44.62（次高：Claude Code 40.29）；开放式平均 63.28（次高：AI Scientist-v2 57.39）。Elo 1,322.5，对 AI Scientist-v2 的胜率 66.3%。
  * *Novelty 上优势最大。* 70.54 对 AI Scientist-v2 的 55.20；Diversity 42.33 对 39.40。
  * *生成时间短于最接近的两个系统。* 每任务 29.9 分钟，AI Scientist-v2 为 39.3 分钟，Codex（ultra）44.8 分钟；直接生成和其他几个 harness 更快但分数更低。
  * *跨学科、跨层级一致。* 在图中的四个系统里，十个学科的 Overall 都最高（领先 1.9 到 9.4 分），L0 到 L8 每一级也都最高。
  * *AgentIdeaBench。* 加权均值 7.195，AI Scientist-v2 为 6.852，五个维度都最高。
* **比标题结论更弱或更窄的地方。**
  * *没有消融。* 没有去掉或替换任何部件：没有不带认知状态、不带监控与控制、或不带方法库的运行。论文说结果与结构化搜索"相一致"；这些结果无法说明增益来自元认知循环，而不是来自十种启发式、想法变换或并行子智能体（读者观察）。
  * *作者自建的基准和 LLM 验证器。* Taiyi-Bench 由同一团队构建，分数来自"以文献为依据的验证器"，它与人类专家的一致性只被描述为良好，没有给数字。优势最大的 Novelty 也是八项里最依赖评审者的指标（读者观察）。
  * *Overall 的差距来自哪里。* 对 AI Scientist-v2 的 6.1 分领先，由复现类 +6.3 和开放式 +5.9 组成；开放式里 Novelty 贡献 +15.3，而 Effectiveness 几乎持平（87.81 对 87.23）。在复现类上，最强的基线不是科学 harness，而是 Claude Code，落后 4.3 分（读者根据表 3 计算）。
  * *Exact 换算成个数。* 多数 Exact 分数落在 1/215 的网格上，对应 265 个任务减去每篇论文一个 L0 任务：Sage-Taiyi 的 19.53% 是 42 个任务，AI Scientist-v2 的 16.74% 是 36 个，Claude Code（GPT-5.6-Sol）的 13.95% 是 30 个（读者推断；有两个基线的数值不在网格上）。没有报告重复运行或置信区间。
  * *基线被裁剪过。* 科学 harness 只保留构思阶段，所以 AI Scientist-v2、Robin 和 EvoScientist 都不是按原设计运行的。
  * *IG-Arena 的报告很单薄。* 正文只给出 Sage-Taiyi 的平均 PES 87.634，并说图中有四个已发表的参考分数；该图的图注说所有系统都用 GPT-5.5，而论文其余部分用的是 GPT-5.6-Sol，参考分数也不是作者重跑的。
  * *合作案例展示的是整合，不是归因。* 每个案例都由专家选路线、由 Taiyi-Optimizer 搜索条件：羰基化产率在十轮 35 次评估中从痕量升到 84%，胺化产率在五轮 61 次评估中从 13% 升到 69%（实测 68.7%），两者都是在 Sage-Taiyi 定义的空间内做贝叶斯优化。没有对照组（例如只有专家，或在专家定义的空间上运行优化器），所以元认知架构的贡献份额未知（读者观察）。图中注明工作流里提出的机理检验"仍是前瞻性的"。
  * *五项成果的强度不一。* 只有超材料案例有比较对象：专家设计的鱼骨结构阻带透射 9.5%、通带透射 87.4%，对比 6.2% 和 94.5%，均为仿真结果。合金 342 MPa 的平均抗拉强度和压气机 91.5% 的 CFD 叶轮效率（三轮优化中从约 90.0% 提高）都没有外部基线。超材料案例也是循环本身最清楚的例子：优化反馈让系统指出"固定基板厚度"是瓶颈，放开该约束后奖励从 0.253 升到 0.822。
  * *没有报告成本。* 只给了墙钟时间；每个任务生成十个想法的 token 用量和 API 成本没有报告。

# Q9 贡献

* 一种把科学搜索（目标树、想法图、证据状态）与对搜索的调控（认知状态、认知方法库）分开，并用监控与控制连接两者的架构。
* 一份包含十种方法论启发式和一组带适用条件的推理算子的目录，并针对各学科做了具体化。
* Taiyi-Bench：从近期论文的决策结构构建的构思任务，包含多个披露层级上的复现评测和开放式评分。
* 三个构思基准上的结果，以及五项有记录的合作，把方案与实验室、仿真或 CFD 结果连接起来。

# Q10 后续方向

* **消融元层（读者建议）。** 用同样的目标树和想法图，但冻结认知状态或随机选择方法，以测量监控与控制带来了什么。
* **人工评分子集。** 按指标报告验证器与专家的一致性，尤其是 Novelty，并发布任务让他人给自己的系统打分。
* **湿实验案例的对照（读者建议）。** 让优化器在专家定义的空间上运行，或在相同实验预算下比较专家提出的路线和系统提出的路线。
* **作者的计划。** 根据累积的研究经验修订方法库，检验其跨领域复用，并在有限时间和迭代预算下扩大多智能体协作。
* **读者联系。** ResearchStudio-Idea 从会议结果中归纳构思模式，并在实验之前停下；Sage-Taiyi 的方法库是从认知科学出发手工构建的对应物。归纳得到的方法库和从理论推导的方法库哪一种泛化更好，是一个尚未做过的比较。

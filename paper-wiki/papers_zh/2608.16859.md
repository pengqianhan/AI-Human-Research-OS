> 论文:**HarnessEval-W: Agentifying the Evaluation of Visual Worlds**
> 论文链接:<https://arxiv.org/abs/2608.16859>
> 机构:MirroS-Lab

# Q1 问题定义

* **输入 `X`**:某个世界模型(文生视频生成器、原生动作模型,或相机位姿模型)针对一个评测案例产生的观测/rollout——案例本身由场景加一个具体的动作或相机指令构成,取自六大探针类型之一。
* **输出 `Y`**:一个覆盖多达八个评测设置(归入观测质量、转换正确性、世界持续性三个轴)的逐案例判定,每项 0-1 打分(换算为 1-100),并配有一份结构化、可检查的"证据树",呈现得出该分数的推理过程,而不是一个孤零零的数字。
* **核心问题**:现有的世界模型基准以固定评分标准暴力计算指标,因此低分无法被诊断——没有推理链条可供读者检查或核验,来判断一次 rollout 究竟违反了哪个不变量(物理规律、因果关系,还是世界状态的持续性)。
* **范围**:本文贡献的是一套评测 harness,以及它产出的基准数据(18 个世界模型上的 330 个案例);并不修改或训练被评测的世界模型本身。

# Q2 问题的新颖性

世界模型基准测试和 LLM-as-a-judge 式的评测都是已有的方向。本文声称的新意,是把已经用于搭建 LLM *agent* 脚手架的"harness 范式"引入评测者本身:不再套用单一固定评分标准或一次性的端到端评判调用,HarnessEval-W 会先解读每个评测案例的上下文,把评测问题分解为可衡量的子问题,再派生出多个专职 sub-agent——各自配备针对性的上下文和诊断工具——分别对自己的子问题进行推理,最后由一个 parent agent 核验并汇总这些证据,给出最终判定。

# Q3 科学假设

如果把一个世界模型评测问题分解为可衡量的子问题,交由配备了针对性上下文和诊断工具的专职 sub-agent 分别推理,再由 parent agent 核验并汇总这些证据得出最终判定,那么得到的判断结果会比套用单一固定评分标准的评判者更接近人类偏好、在多次重复评测间更加一致,同时还能产出一份可审计的逐案例推理链条。

# Q4 相关工作与关键人物

* 把 LLM agent 生态里的"harness 范式"(围绕基础模型搭建的提示词/工具/状态脚手架)延伸到了评测者角色,而不是本仓库知识库通常追踪的任务执行角色(参见 [Agent harness engineering](../topics/agent-harness-engineering.md))。
* 直接与 WBench(一个既有的固定评分标准世界模型基准)做对比,作为人类对齐度和跨次评测一致性的主要基线。
* 与 LLM-as-a-judge 相关文献广泛相关(参见 [LLM-as-a-Judge](../concepts/llm-as-a-judge.md)),但本文针对的是评判者的不透明性,而非其校准问题。
* **作者/机构**:43 位作者,由 MirroS-Lab 署名,2026 年 8 月 17 日提交。

# Q5 核心解法

**基准构建流水线**:一个 Image Generator 生成案例的初始观测;一个基于图像的 Planner 依据可见证据,从六大探针族(按场景可供性匹配,例如探索性视角变化需要一条探索路线,意图性转换需要一个可见目标)中选出一个具体的探针动作;随后一个 Case Validator 在案例被采纳前审计其可行性和证据充分性。场景在一个六轴分类体系(环境类型、前景实体、中景空间结构、场景密度、视觉风格——从照片级真实到动漫——以及第一/第三人称视角)上采样。

**评测流水线**:对每个被采纳的案例,HarnessEval-W 先解读案例上下文,再把统领性的评测问题——覆盖观测质量(渲染质量、单帧的物理合理性)、转换正确性(探索性/意图性/物理性变化是否正确执行)、世界持续性(不变量能否在漂移中存活、重访是否一致、画面外过程是否持续演化)——分解为可衡量的子问题。举例来说,判断一次"意图性变化"会派生出多个 sub-agent,分别检查目标可见性、可见转换是否确实发生、结果状态是否有效、是否存在额外事件,以及整体是否可判定。每个 sub-agent 使用各自的诊断工具进行推理;parent agent 随后核验汇总这些 sub-agent 证据,总结成最终判定,因此每个分数都能追溯到一棵显式的证据树。

# Q6 实验设计

在跨三大类的 18 个世界模型上应用于 330 个评测案例:10 个文生视频生成器(Seedance 2.0、Wan 2.7、Kling 3.0、MiniMax H3、Grok Imagine 1.5、FLUX 3、Cosmos3-Super、HunyuanVideo 1.5、Wan 2.2、LTX-2.3)、3 个原生动作模型(SANA-WM、ABot-World、DreamX-World),以及 5 个相机位姿模型(LingBot World v2、Lyra 2、Fantasy-World、HY-WorldPlay 1.5、InSpatio-World)。

人类对齐度以与人类偏好的相关系数衡量:意图性转换判断达到 Spearman ρ=0.93(Kendall τ=0.82);物理转换判断达到 ρ=0.87(τ=0.74)。与 WBench(固定评分标准基线)相比,HarnessEval-W 在物理转换上的成对判断准确率更高(71.7% 对 31.9%),平局率大幅降低(1.8% 对 52.2%),并且在对同一案例的重复评测中,分歧区间据称收窄了 4.9 倍。跨轴相关性分析发现渲染质量与物理观测几乎独立(r=-0.04),意图性与物理转换得分高度耦合(r=0.98),探索性转换与二者的相关性都很弱(r≈-0.15/-0.18)。一项微调案例研究显示,把文生视频模型改造为动作模型会提升重访一致性(+8.4 分),同时削弱意图性(-24.2)和物理性(-11.2)转换的处理能力——作者将其解读为当前动作模型的微调数据更偏重自由探索、而非受指令驱动的干预。

总榜前几名(18 个模型中):Seedance 2.0(75.5)、Wan 2.7(75.0)、Kling 3.0(74.4)、MiniMax H3(74.3)。

# Q8 证据质量

人类对齐度相关系数(Spearman ρ 最高达 0.93)以及与 WBench 的对比(成对准确率、平局率、分歧区间宽度)是本文最有力的定量证据,支持"基于 harness 的分解提升了对齐度和可靠性"这一结论,相较固定评分标准基线而言。以下几处方法论细节未能在检索到的材料中得到确认,因此标注为存疑而非默认成立:支撑 Spearman/Kendall 数字的人类偏好参照集的规模、协议和评分者间一致性;WBench 成对准确率/平局率对比背后的参照标准;330 个生成案例除了流水线自身的 Case Validator agent 之外,是否还有独立的人工审核(该基准的案例由论文自己的 agent 化构建流水线自动生成,因此覆盖面和难度是自我选择的,而非外部策展的)。这些空白源于对论文附录/人类研究方法学部分的检索不完整,并非论文自身声明的弱点。

# Q9 主要贡献

1. 把世界模型评测重新表述为一个 agent 化的分解问题:parent agent 加专职 sub-agent 产出逐案例的可审计证据树,而不是一个固定评分标准下的标量分数。
2. 一套基准构建流水线(Image Generator、基于图像的 Planner、Case Validator),产出覆盖六轴场景分类体系和六大探针族的 330 个案例。
3. 在 18 个世界模型(文生视频、原生动作、相机位姿三大家族)上的实证验证,表明该方法与人类偏好高度对齐,且比固定评分标准基线明显更一致,并附带跨轴相关性分析和一项微调迁移案例研究。

# Q10 下一步

* 论文自身提出的方向:面向 agent 化基准的测试时扩展(更深的分解、多步核验);扩展技能库以应对日益复杂的物理场景;以及自我提升的评测闭环——检测到技能缺口时触发新诊断技能的获取与库更新。
* 检索到的材料未能解答的问题:HarnessEval-W 的判定对 sub-agent/parent 所用 LLM 底座的选择有多敏感;这种基于 harness 的分解方法能否从世界/视频模型推广到评测语言或编码类 agent;流水线自我生成的案例集在覆盖面和难度上与人工策展的基准相比如何。
* **与本仓库的关联**:这是本知识库在 [LLM-as-a-Judge](../concepts/llm-as-a-judge.md) 概念页中已经关注的一个具体问题的实例——评判者的*接口*(除标量分数之外还暴露了什么)与其校准程度同样重要。HarnessEval-W 的证据树是对这一问题的一种结构性回应,值得对照本仓库如何核验被委派或多步的 agent 工作。

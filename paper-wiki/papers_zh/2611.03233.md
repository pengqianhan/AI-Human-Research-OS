# Q1 问题定义

* **输入（X）：** 一个开放基础模型（Qwen3.6-35B-A3B、Qwen3.5-122B-A10B，以及更小的 4B 和 9B 基础模型）；数学、物理、化学、生物和计算机科学领域的公开问答种子；生物、化学、数学、地理、航空等领域的公开结构化数据库；以及带网页搜索、网页访问、学术检索和 Python 的 ReAct 环境。
* **输出（Y）：** 一个经后训练的智能体模型，以及产出它的完整配方。
* **核心问题：** 当前智能体模型繁复的训练流程（持续训练或中期训练、多个监督阶段、按能力划分的数据混合、偏好优化、强化学习、更多后训练）到底有多少是强大而通用的智能体模型真正需要的？
* **约束：** 只有三个阶段，不设专门的中期训练、DPO 或 OPD。问题的参考答案在收集任何轨迹之前就已确定，只有正确的轨迹才进入 SFT。

# Q2 问题新颖性

这不是新问题。智能体基础模型是活跃方向，近期报告每一份都在增加阶段：MiroThinker-1.7 结合智能体中期训练、SFT、偏好优化和强化学习；Agents-A1 使用长程监督和按领域路由的 OPD；[Apodex 1.1](../papers/2608.23283.md) 研究可执行环境和智能体协作。作者认为，这种堆叠让人难以判断哪些成分真正起作用，抬高了复现成本，也让"开放"模型的数据流程仍然封闭。它的新意在于提出"做减法"的问题，并用一个紧凑配方和完整构建流程作答，而不是再加一个阶段。QUEST、OpenThoughts-Agent 和 DR Tulu 是更早的开放配方工作。

# Q3 科学假设

如果把投入放在困难且可验证的训练数据上，而不是增加训练阶段，那么两个 SFT 阶段加强化学习就应当产生与更繁复流程相当的通用智能体能力。每个阶段都应提升其目标能力：按模型能力强化的问题提升独立推理，程序化的工具依赖任务提升证据搜寻和数据分析，强化学习提升与工具的长程交互。

# Q4 相关工作与关键人物

* **智能体基础模型。** Kimi K2、GLM-4.5、MiroThinker-1.7、Agents-A1、Apodex 1.1。
* **困难且可验证的任务构建。** 用于合成指令数据的 Self-Instruct 和 Evol-Instruct；让难度适应学习者的 Absolute Zero 和 Agent0；面向可验证工具使用和研究任务的 TaskCraft、WebShaper 和 QUEST。
* **面向推理和工具使用的强化学习。** DeepSeek-R1 与 GRPO、Search-R1、DeepResearcher、AgentGym-RL。
* **训练与推理一致性。** 一类是截断重要性采样、序列感知掩码和对 token 级修正的分析；另一类是 Rollout Routing Replay（R3）、数值格式选择和精度感知优化。
* **开放配方。** OpenThoughts、OpenThoughts-Agent、DR Tulu、QUEST。
* **关键人物。** Yunjie Tian（项目负责人）、Jiayu Zheng、Mengyu Zhao 和 Di Fu（字节跳动）；Yuqi Jia（杜克大学）；Yijun Liang（马里兰大学帕克分校）；Jingchen Sun（布法罗大学）。可能的批评者：Agents-A1、MiroThinker 和 QUEST 的作者，因为"额外阶段没有必要"这一论点是跨论文比较得出的，而不是消融实验。

# Q5 关键解决思路

**第一阶段数据：按模型能力强化。** 生成器 LLM 把每个公开种子组合成一个新的独立问题，新问题需要以种子的结果为中间步骤（操作 A）。然后基础模型在可用 Python、不可搜索的条件下尝试每个问题。答错的问题直接进入题库。答对的问题连同模型的成功解法一起返回生成器，并随机应用四种操作之一：A（组合，增加一个依赖步骤）、B（参数化，把固定值换成符号）、C（范围偏移，使枚举或原有捷径失效）、D（分情况讨论）。改写后的问题不再要求基础模型答错一次才能入库。GPT-5.5 对每个新问题或改写问题独立求解三次，只有三次一致且推导通过检查才接受答案，而且每次改写后都重新确定答案，不沿用旧答案。随后由另一个 LLM 解题，正确且完整的轨迹构成数据集。

**第二阶段数据：过滤、选择、计算、表述。** 确定性程序先从结构化数据源过滤记录，按某一准则选出唯一实体（当准则是极值时，要求与第二名有足够差距），计算一个派生量，最后才由 LLM 把它写成问题。论文的例子是：过滤有环的行星，选出质量最小的（天王星），再问它的平均密度。工具依赖通过三种方式保证：解题时屏蔽构建所用的数据表，但开放通用搜索、网页和 Python；移除 LLM 不用工具就能答对的问题；检查表述是否遗漏约束或泄露答案。中间实体和数值保留为验证目标，解题者看不到。

**两阶段 SFT。** 第二阶段从第一阶段的检查点继续。损失只覆盖助手生成的 token（推理、工具调用、最终答案）。每条完整轨迹是一个样本，最长 128K token，不用摘要替换早期上下文。两个阶段都用恒定学习率 3e-6、三个 epoch 和批大小 8。

**带已验证部分奖励的强化学习。** 在 verl 上运行 GRPO，任务来自第二阶段流程。答对奖励为 1，否则为 max(0, 0.3P − 0.1(1 − A))，其中 A 表示是否提交了最终答案，P 是有序目标上的链式进度：只有前面的目标全部通过，后面的目标才得分。目标必须在推理中被确认或使用，仅出现在检索结果里不算；需要外部依据的目标还必须有工具观察支持。检查结合确定性匹配和 LLM 等价判断。只有当前模型的四次离线采样中至少一次答对、且奖励不全相同时，任务才被保留。

**让训练忠实于 rollout。** 训练是异步的（每题八次 rollout，每两次更新同步权重，丢弃落后超过 11 个参数版本的轨迹）。QUEST 式的上下文压缩把每条 rollout 切成共享同一奖励和优势的会话。Token-In-Token-Out 让 token ID 直接穿过智能体循环，避免会话被重新分词；Rollout Routing Replay 记录 vLLM 选择的专家，并在 Megatron 中重放。

# Q6 实验设计

* **模型。** 经过全部三个阶段的 Axion 1.0-35B-A3B 和 122B-A10B；它们的基础模型和中间检查点；只经过两个 SFT 阶段的 4B 和 9B 变体；用相同 SFT 训练的 Qwen3.5-35B-A3B，作为基础模型对比。
* **基准。** 完整的 Humanity's Last Exam（HLE）、BioMysteryBench human-difficult 子集、SEAL-0、HiPhO，以及 FrontierScience 的 Olympiad 和 Research 两个赛道。阶段和规模对比使用 130 题的纯文本 HLE 子集（HLE-130）。
* **协议。** 每个基准运行三次，BioMysteryBench 运行五次，**报告单次最佳成绩**而不是汇总值。这适用于 Axion 和作者自己运行的基线（GPT-5.6 Sol、Gemini 3.1 Pro）。其他基线行来自官方报告或 Agents-A1、Apodex 的报告，论文称跨来源比较只具参考性。Axion 的 HLE 成绩屏蔽了 Hugging Face 等网站。
* **分析。** 逐阶段检查点（论文明确说这不是移除组件的消融实验）；基础模型的影响；不同规模下的 SFT（4B 对 9B）；35B 和 122B 上的强化学习；122B 上开关 R3；三组精选轨迹对比（附录 B）。

# Q7 数据集与代码

论文称完整配方已发布，包括数据构建、生成、过滤、验证、提示词和训练代码，地址是 [bytedance/axion1_0](https://github.com/bytedance/axion1_0)（`hf papers info` 显示 37 颗星），另有[项目主页](https://axion1-0.github.io/)；本笔记未打开它们。正文给出的是 token 数而不是数据集规模：第一阶段在 122B 上处理 8.41 亿 token，在 35B 上处理 6.57 亿 token。SFT 在 32 张 GPU 上运行，122B 花费 240 GPU 小时，35B 约 90 GPU 小时。复现需要用 GPT-5.5 确定参考答案，并用一个未具名的 LLM 生成轨迹。论文没有提出新基准。

# Q8 证据质量

* **有支持的结论。**
  * *就规模而言成绩广泛。* 35B 和 122B 模型在 HLE 上得 52.2 和 59.0（不屏蔽网站时为 59.1 和 64.8），BioMysteryBench 35.3 和 41.7，SEAL-0 62.2 和 58.6，HiPhO 45.7 和 46.2，FrontierScience Olympiad 86.0 和 87.0，FrontierScience Research 56.7 和 66.7。与规模相近的 Agents-A1 相比，35B 模型在 HLE（47.6）、SEAL-0（56.4）和 Olympiad（79.0）上领先。122B 的 Research 成绩超过 GPT-5.6 Sol（63.3）。
  * *SFT 贡献了推理能力的大部分提升。* HLE-130 依次为（基础、第一阶段、第二阶段、强化学习）：35B 上 47.7、59.2、66.2、70.0，122B 上 40.8、68.5、68.5、74.6。
  * *强化学习对搜索更重要（读者根据表 2 的观察）。* 在 SEAL-0 上，强化学习的增益与两个 SFT 阶段之和相当：35B 上 +9.0 对 +9.1，122B 上 +5.4 对 +5.4。在 HLE-130 上则只有 +3.8 对 +18.5、+6.1 对 +27.7。
  * *配方缩小了基础模型差异。* 经过相同 SFT 后，35B 上 Qwen3.5 与 Qwen3.6 的 HLE-130 差距从 9.2 降到 0.8；BioMysteryBench 上两者都达到 35.3，Qwen3.5 在 SEAL-0 上反而更高（57.7 对 53.2）。
* **比标题说法更弱或更窄之处。**
  * *简化主张没有被直接检验。* 没有实验把中期训练、DPO 或 OPD 加回这一配方，也没有实验移除某个阶段。"需要多少复杂度"的答案来自与其他模型的跨论文比较，且部分使用其他报告的数字（读者观察）。
  * *报告的是最佳运行。* 从三次或五次中取最佳会高于平均值，而且没有给出运行间波动。官方基线行可能遵循另一种约定。
  * *测试集很小（读者根据分数推断；论文未给数量）。* SEAL-0 的分数符合 111 道题，一题约 0.9 分。BioMysteryBench 的多数分数符合 17 道题（11.8、17.6、23.5、29.4、35.3、47.1），一题约 6 分，不过 41.7 不符合。按此计算，35B 在该基准上第一阶段的下降和 122B 强化学习的增益都只相当于一道题左右。
  * *阶段有时有害。* 第一阶段降低了 35B 的 BioMysteryBench（23.5 到 17.6），强化学习略微降低了 35B 的 HiPhO（46.8 到 45.7）和 FrontierScience Research（58.3 到 56.7）。第二阶段对 122B 的 HLE-130 没有增益（68.5）。
  * *R3 的收益参半。* 开启 R3 后，122B 在 HLE-130（74.6 对 72.3）、Olympiad 和 Research（66.7 对 61.7）上提升，但 SEAL-0 从 63.1 降到 58.6，最大梯度尖峰从 21.1 升到 26.8。论文自己也限制了因果归因。
  * *作为"智能体"模型，基准覆盖面窄（读者观察）。* 引言把编码和长程交互列为评测能力，但六个基准都是科学、推理和信息搜寻。没有编码智能体或多服务工作流基准，也就是 [ToolSpace](../papers/2611.05036.md) 这类论文的场景。
  * *与前沿模型的比较并不完整。* Claude Fable 5 和 Opus 5 在 HLE 上领先（63.8、63.6），Opus 5、GPT-5.6 Sol 和 Fable 5 在 BioMysteryBench 上领先（49.4、47.1、46.1），表 1 还有许多空格，所以"有竞争力"只建立在有重叠的单元格上。
  * *案例只是示例。* 论文说明附录 B 描述的是精选轨迹，并不表示该行为在更早的检查点中不存在。

# Q9 贡献

* 一个公开的短配方（两个 SFT 阶段加带已验证进度奖励的 GRPO），在 35B 和 122B 上取得较强的科学和搜索成绩，并给出详细超参数和 SFT 成本。
* 一种利用基础模型的成功解法（而非失败）来强化推理问题的构建方法，并对每个改写后的答案独立重新验证。
* 一条程序化的工具依赖任务流程：答案和有序的中间目标链在 LLM 表述问题之前就已存在，同时支持 SFT 过滤和强化学习的部分奖励。
* 一张逐阶段成绩表，按顺序展示每个阶段增加了什么，并具体测量了 R3 在 122B 上的效果。

# Q10 后续方向

* **逐一增减的实验（读者建议）。** 在相同基础模型和数据上加入 OPD 或中期训练，并逐个移除阶段，就能直接回答论文自己的问题。
* **报告均值和波动（读者建议）。** 给出多次运行的均值和区间，才能看出哪些阶段增益超过运行间噪声，尤其是在小基准上。
* **在科学和搜索之外测试（读者建议）。** 编码和多服务工作流基准可以说明，从数据库问题学到的工具技能能否迁移到有持久状态的任务。
* **奖励和筛选设计（读者建议）。** 比较链式部分奖励与只看结果的奖励、离线任务筛选与不筛选，可以衡量二者各自对搜索增益的贡献。
* **把 R3 与策略滞后分开（来自论文）。** 对数概率诊断还反映了异步策略滞后和上下文压缩，所以需要受控研究才能把基准变化归因于 R3。

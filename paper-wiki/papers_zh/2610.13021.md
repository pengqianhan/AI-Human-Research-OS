# Q1 问题定义

* **输入（X）：** 一段家务任务描述和当前状态的第一人称图像，以及每一步用自然语言写出的少量候选动作；可选地，还有来自此前基础任务的经验，形式是完整的交互轨迹，或智能体自己写的 Markdown 技能总结。
* **输出（Y）：** 每一步选一个动作，直到到达目标状态或用完步数预算；评分是成功率。
* **约束：** 评测是离线且确定性的。每个任务是一张预先计算好的状态转移图；测试时的步数预算是最短路径加 3 步（学习阶段加 6 步）。
* **核心问题：** 在具身场景下，衡量一个自进化智能体是否能积累经验，并把它用到更难的、没见过的任务上。论文把“持续学习（continual learning）”操作化为组合泛化（compositional generalization）：先在基础任务上学习，再去解由相同原子动作重新组合而成的进阶任务。

# Q2 问题新颖性

部分新颖。面向智能体的持续学习和技能进化基准在数字环境中已经存在（论文引用了 EvoAgentBench、SEA-Eval、AgentCL、SkillLearnBench、SkillFlow、ContinualSkillBench、SkillEvolBench），而具身基准覆盖感知、导航、操作和规划，却没有学习阶段。论文声称的“首个”是两者的结合：具身仿真中的持续学习基准。把组合泛化当作测量手段，则借自论文所引的网页、视频、推理和机器人操作基准。

# Q3 科学假设

1. **经验可以向上迁移。** 如果智能体做过相关的基础任务，它解决由相同原子动作构成的进阶任务的成功率会高于零样本智能体。
2. **经验越多应当越有帮助。** 如果持续学习有效，进阶任务的成功率应当随先做的基础任务数量上升。论文发现这一点不成立。
3. **经验改变的是决策，而不只是结果。** 如果学习是真实的，智能体应当更少选择不可执行的动作，更多选择最短路径上的动作。

# Q4 相关工作与关键人物

* **面向智能体的持续学习基准。** 知识密集型迁移（EvoAgentBench、StreamBench、AgentCL），交互式数字环境（SEA-Eval、LifelongAgentBench），长期模拟世界，以及以技能为中心的进化（SkillLearnBench、SkillFlow、ContinualSkillBench、SkillEvolBench）。
* **具身基准。** 场景理解与空间推理（EmbodiedScan、EmbSpatial-Bench、PhysBench），导航（R2R 及其后继、GOAT-Bench、OpenEQA），操作（Meta-World、RLBench、ManiSkill2、LIBERO、RoboCasa），以及长时程规划（ALFRED、TEACh、CALVIN、BEHAVIOR-1K）。
* **组合泛化。** 网页与移动端智能体、视频动作识别、推理，以及机器人操作。
* **关键人物。** 北京大学智能学院与 BIGAI 的 State Key Laboratory of General Artificial Intelligence（Yiwu Zhong、Zilong Zheng、Zhenliang Zhang），以及香港大学。可能的批评者：机器人研究者会指出，在写好的选项中做选择并不是具身控制；持续学习研究者会指出，这个协议没有长任务流，也不测量遗忘。

# Q5 关键解决思路

* **三个组合层级。** *原子动作*是一次物体交互，需要三步（观察、靠近、操作）。*基础任务*把两个原子动作组合成一项家务操作（最短路径 6 步）。*进阶任务*组合四个原子动作，取自二到四个基础任务类别（最短路径 12 步）。基础任务分六类：物体操作、空间放置、可达性控制、电器操作、面向活动的场景布置、家居状态恢复。
* **用离线图代替在线模拟器。** 作者使用动作更丰富的 TongSim 闭源版本，因此为每个任务预先计算一张状态转移图。每个节点是一个环境状态，配有一张截取的图像和四个候选动作，分三种：*最优*（在广度优先搜索找到的最短路径上）、*次优*（可执行但偏离最短路径）、*无效*（在该状态下不可执行）。
* **控制文本泄漏。** 任务描述和选项由 Qwen3.7-Plus 分三阶段写成：把任务改写成不列出物体和顺序的场景级请求；改写每个状态的选项，使它们看起来都合理；再跨状态加固选项以消除规律，包括反复出现的“观察-靠近-操作”节奏。三名标注者检查图像、描述和选项；只有三人都通过的样本才保留。
* **三种设置。** *零样本*；*上下文学习（In-Context Learning，ICL）*，两个相关基础任务的完整轨迹保留在上下文中；*技能学习（Skill Learning）*，智能体做完同样两个基础任务后写一份 Markdown 技能总结，测试时只提供这份总结。

# Q6 实验设计

* **基准。** 268 个任务：168 个基础任务和 100 个进阶任务。
* **智能体。** 四个 harness（OpenClaw、Claude Code、Codex、Hermes），每个都通过官方 API 搭配 Qwen3.8-Flash 和 GPT5.6-Terra。
* **分析。** 组合复杂度（3 到 6 个原子动作的进阶任务；Hermes + Qwen3.8-Flash）；学习样本数 k 从 0 到 6（Hermes 和 OpenClaw + Qwen3.8-Flash）；相对零样本的各类动作选择率（四个 harness + Qwen3.8-Flash，取自主实验日志）；步数预算敏感性（0 到 6 个额外步；Hermes + Qwen3.8-Flash）。
* **指标。** 只有成功率。

# Q8 证据质量

* **有支撑的结论。**
  * *进阶任务零样本很难，经验在每种配置下都有帮助。* 零样本成功率在基础任务上为 42.9-58.9%，在进阶任务上为 3.0-12.0%。先做两个基础任务后，八组 harness-模型组合在两种方法下全部提高：ICL 为 16.0-52.0%，技能学习为 22.0-38.0%（表 1）。
  * *一个样本就够，更多没有帮助。* 从 k=0 到 k=1，两个 harness、两种方法下的成功率从 8.0-10.0% 升到 28.0-40.0%；从 k=1 到 k=6，四条曲线没有一条持续上升。
  * *提升在更难的组合和更紧的预算下依然存在。* 从 3 个到 6 个原子动作，零样本从 28.0% 降到 4.0%，而 ICL 和技能学习在 6 个时仍有 32.0% 和 26.0%。额外步数为 0 时，零样本为 0.0%，ICL 为 15.0%，技能学习为 7.0%。
  * *经验主要消除了不可执行的选择。* 所有 harness 中无效动作的选择率下降 13-20%，次优动作上升 3-8%，最优动作上升；在每个 harness 中，技能学习带来的行为变化都小于 ICL。
* **比标题结论更弱或更窄之处。**
  * *“30% 以上”并不普遍。* 正文说学习把进阶任务成功率“从约 10% 提高到 30% 以上”，但表 1 的 16 个学习单元格中有 5 个低于 30%（ICL 的 16.0 和 27.0；技能学习的 22.0、26.0、25.0；读者计数）。Hermes + GPT5.6-Terra 用 ICL 只提高了 5 个点（11.0 到 16.0）。
  * *这个协议是两样本迁移，而不是学习流。* 每个进阶任务之前是两个被选为与之相关的基础任务，放在同一个上下文里。没有长任务序列，没有从不断增长的记忆中检索，也没有测量保持或干扰，而这些通常才是“持续学习”要检验的（读者观察）。
  * *没有把“熟悉接口”和“技能迁移”分开。* 基准的构建说明自己指出，每个原子动作都遵循“观察-靠近-操作”的模式，选项加固阶段正是要隐藏它。一个基础任务就足以大幅减少无效动作并带来几乎全部提升，再多的任务不再增加；如果智能体主要学到的是这个环境里步骤如何进行，而不是在积累可组合的技能，就会出现这种形态。没有使用*不相关*基础任务的对照，而这样的对照可以把两者分开（读者推断；论文的解读是智能体“无法从更多样本中提取足够不同的信息”）。
  * *ICL 与技能学习孰优未定，且样本很小。* 两种方法都没有稳定胜出（8 组中 ICL 在 5 组更高，读者计数），而 100 个进阶任务意味着一个任务就是一个点。所有实验都只跑一次，没有方差或显著性检验，因此 harness 和模型之间几个点的差异同样无法确定。两个模型也没有哪个稳定更好：在共用 harness 的 8 个学习单元格中，GPT5.6-Terra 有 4 个落后于 Qwen3.8-Flash，其中技能学习在四个 harness 里有三个落后（读者计数）。
  * *表格与分析之间有小的不一致。* 5.1 节给出 Hermes + Qwen3.8-Flash 在 4 个原子动作时 ICL 为 42.0%，而表 1 是 44.0%；5.2 节 k=0 的范围是 8.0-10.0%，而表 1 中 OpenClaw + Qwen3.8-Flash 的零样本是 5.0%。论文说 5.1 节扩展了评测数据，但没有给出各分析子集的任务数。
  * *没有分析失败的学习回合。* 在测试预算下，基础任务零样本只有约一半能解决（学习阶段多给三步），因此学习阶段的轨迹以及据此写出的技能总结，可能有相当一部分来自失败；论文没有报告学习阶段的成功率，也没有按它拆分结果。
  * *这里的“具身”指图像加四个文字选项。* 智能体从不发出运动指令，也不做连续导航；图的格式让评测可复现，也让任务变成了一串视觉多选题。

# Q9 贡献

* 按作者的说法，第一个在具身家居仿真中检验“从经验中学习”的基准，采用三层组合式任务设计。
* 一种离线图格式，让闭源模拟器上的任务可复现，并把智能体的每个决策归为最优、次优或无效。
* 跨四个智能体 harness 的八种配置评测，显示从基础任务到进阶任务的迁移是一致的。
* 一个负面的规模结果：在第一个学习样本之后，更多经验不再提高成功率，无论是原始轨迹还是写下的技能。

# Q10 下一步

* **作者提出的。** 为持续学习设计 harness，因为各 harness 的得分接近且远未饱和；寻找让智能体能从更多交互中持续获益的机制。
* **不相关经验对照（读者建议）。** 给智能体与进阶任务没有任何共同原子动作的基础任务。如果提升仍在，那就是对环境的熟悉；相关与不相关经验之间的差值，才是这个基准想测的组合迁移信号。
* **真正的任务流（读者建议）。** 把 168 个基础任务排成一个序列，配上持久的记忆或技能库，然后在 100 个进阶任务上测试，且不告诉智能体哪些经验相关；在成功率之外报告保持和干扰。
* **按学习结果分组（读者建议）。** 对两个基础任务都解决了的情况单独报告进阶任务成功率，看失败的回合是有帮助、有害还是被忽略。
* **原始历史对比提炼的教训。** [Learn2Play Bench](../papers/2610.08215.md) 发现提炼出的教训可能把错误规则固化下来，而原始历史让智能体能修正它；这里技能总结对决策的改变小于轨迹，最终成功率却相近，这是第二个数据点，说明记忆格式对行为的影响比主指标显示的更大。

# 相关

* [智能体自进化](../topics/agent-self-evolution.md) - 一个不更新权重、检验“从自己先前任务中学习”循环的基准，主要结果是提升在一个学习样本后就饱和。
* [智能体基准与评测](../topics/agent-benchmarks.md) - 带学习阶段和测试阶段的离线状态图基准，用成功率和逐步的动作类型来衡量组合迁移。
* [智能体技能库](../topics/agent-skill-libraries.md) - 在相同经验下比较携带原始轨迹与携带自写的 Markdown 技能总结；两者都没有稳定胜出。
* [Learn2Play Bench](../papers/2610.08215.md) - 同样在重复回合中衡量从经验学习并比较记忆格式，场景是带隐藏规则的文字游戏，而不是家居图。
* [AgentGarten](../papers/2610.12374.md) - 智能体在模拟世界中通过继承写下的 playbook 跨轮进步；EmbodiedCLBench 的技能学习设置是同一机制在受控的两任务协议下的版本。
* [SuperNav](../papers/2610.12126.md) - 另一个通过通用智能体 harness 加 Markdown 技能来完成的具身任务，那里是导航，技能由人手写而非智能体自写。

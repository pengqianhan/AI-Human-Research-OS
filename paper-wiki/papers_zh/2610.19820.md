# Q1 问题定义

* **输入（X）：** 一个小的学生智能体（Qwen3-4B 或 Qwen3-8B）；一个只能采样、拿不到词元概率、分词器也可能不同的教师智能体（Qwen3.7-Flash 或 DeepSeek-V4-Flash；τ² 对比实验中为 Qwen3-32B）；可执行的多轮工具调用训练任务（[Agent World Model](../concepts/agent-world-model.md) 与 [EnvScaler](../concepts/envscaler.md)）；以及一个判断两条回复是否采取同一动作的语义匹配器（semantic matcher）。
* **输出（Y）：** 一个学生，它在*自己到达的状态*上给出的下一个工具调用或面向用户的消息，与教师在同一状态下会做的一致；评测时学生单独运行（贪心解码、无教师），且在训练中从未见过的基准上测。
* **监督单位：** 语义动作（semantic action），即工具名加参数，或消息的意图与事实内容。同一动作可以有不同措辞和推理过程；学生自己的推理词元只通过该动作的奖励被训练，从不以教师的文本为目标。
* **约束：** 只能调用教师生成；损失中没有结果奖励（outcome reward）；每个教师样本只含一个即时动作。

# Q2 问题新颖性

智能体蒸馏是已有问题，贡献在于监督单位和接口。论文把自己放在三条脉络中：

* **词元级蒸馏。** 离线序列蒸馏在教师的状态上模仿教师序列，可能出现状态分布不匹配（DAgger 的论点）。词元级[在策略蒸馏](../concepts/on-policy-distillation.md)（on-policy distillation，GKD、MiniLLM）解决了不匹配，但需要教师的对数概率和兼容的分词；跨分词器 OPD 则需要显式对齐。特权自蒸馏（OPSD、SDPO、特权信息蒸馏）给同权重教师加额外上下文，但仍是词元级。
* **黑盒与语义蒸馏。** 判别器奖励（GAD）、由师生对比得出的评分细则（ROPD）、教师的语言评分（OVD）、把推理片段与教师续写比较（OmniOPD）、整条轨迹的工具集合一致性加正确性（MENTOR），以及动作语义学习（Action Semantics Learning，ASL）——后者为 App 智能体推导了语义一致性策略梯度，并用世界模型比较 UI 转移。ActionOPD 所说的区别：它在同一状态下把*即时*的工具调用或消息与教师样本比较，不需要匹配推理文本、完整参考轨迹或终局奖励；它的匹配器被要求判断"是否一致"，而不是"是否正确"。
* **交互式智能体学习。** DAgger、SCoRe（局部教师纠正）、Guided-OPD 和 ATOD（逐步撤去教师轮次，或混合 OPD 与 RL）、GiGPO（跨轨迹按相同状态分组、用回报算优势）。ActionOPD 直接拿同一状态的候选与共享的教师样本集打分，不估计回报。

# Q3 科学假设

如果学生在自己到达的状态上，因产生与黑盒教师所采样动作含义相同的动作而获得奖励，那么：（1）它会在训练环境之外的工具调用基准上提升；（2）提升会随学生规模和教师强度增长，包括跨模型家族；（3）它能在不需要教师对数概率的情况下追平词元级 OPD 和离线蒸馏。

# Q4 相关工作与关键人物

* **蒸馏。** Hinton 等人的分布匹配、Kim 与 Rush 的序列级蒸馏、GKD（Agarwal 等）、MiniLLM（Gu 等）、"Revisiting on-policy distillation"（Fu 等，其采样词元反向 KL 形式就是本文的 OPD 基线）、跨分词器 OPD（Niu 等；Wang 等）、OPSD（Zhao 等）、SDPO（Hübotter 等）。
* **黑盒与智能体蒸馏。** GAD、ROPD、OVD、OmniOPD、MENTOR、动作语义学习；以学生为中心的蒸馏（SCoRe）、Guided-OPD、ATOD。
* **训练底座。** 基于 veRL/HybridFlow 的 verl-agent；[GRPO](../concepts/grpo.md) 式的组内相对优势加 PPO 截断和双重截断；训练数据来自 AWM（Wang 等，ICML 2026）和 EnvScaler（Song 等，Findings of ACL 2026）。
* **关键人物。** Huining Yuan 与 Xiangmin Yi（共同一作），通讯作者 Xiao-Ping Zhang、Yu Wang、Chao Yu，均在清华大学；Hugging Face 列出的机构为 Tsinghua-NICS-EFC。可能的批评者：词元级和跨分词器 OPD 的作者，他们会要求算力对齐的比较；以及动作语义学习的作者，其一致性梯度是最接近的前人工作。

# Q5 关键解决思路

**目标函数。** 在学生访问到的状态上，最大化学生产生教师动作的期望概率：对学生轨迹中的状态 s 和教师动作 a^T 取期望的 π_θ(a^T | s)。把该概率写成"实现 a^T 的所有学生回复的总概率质量"并交换期望次序，就得到一个期望奖励目标，其梯度是以语义一致性为奖励的 REINFORCE。于是一个动作级奖励加权学生回复中的每个词元，包括推理部分。附录指出两点性质：该目标没有逆似然因子（与期望对数似然不同）；它也不必保留教师的多个模式——若教师在两个动作上的概率是 0.7 和 0.3，学生把全部概率放在第一个上就能使它最大。

**奖励。** 每个状态向教师要 K = 3 条回复（解析或模式不合法时各可重试两次）。匹配器 m(y, y^T) 比较的是动作内容而非推理：工具名必须相同；参数先规范化（忽略键顺序、整数值浮点数归一、布尔与数值区分），剩余差异交给一个冻结的 LLM，并提供工具模式、两份参数对象、公开上下文和工具实现证据；消息先做归一化精确匹配，否则由 LLM 比较意图和事实内容。判断模糊时记为不匹配；匹配器调用失败则视为没有监督，而不是负标签。设 c 为候选匹配上的教师样本数，奖励为：无效动作 −1；有效但不匹配 0；否则 1 + λ(c − 1)/(K − 1)。取 λ = 0.5、教师样本为 [A, A, B] 时，匹配 A 的回复得 1.25，匹配 B 的得 1。

**状态组展开（state-group rollout）。** 在每个访问到的状态，冻结的旧策略采样 N = 4 个候选，全部对照同一组教师样本打分。只执行奖励最高的候选（平局时均匀随机），因此每个任务产生一条受教师引导的轨迹；保留下来的组中所有候选都参与训练。作者承认这会引入一定的离策略状态访问。

**更新。** 没有监督或组内奖励全相同的组被丢弃。组内奖励减去组均值，再除以整个批次共享的一个标准差；优势广播到每个生成词元，用 PPO 截断代理目标优化（截断 0.2，双重截断 3），学习率 10⁻⁶，一个 PPO epoch，小批量 32，不加 KL 惩罚、熵奖励或结果奖励。作者说明，经过归一化、掩码和截断后，这些更新不是理想梯度的无偏估计。

**Self-ActionOPD。** 教师与学生共享当前的 Qwen3-4B 权重，分别独立采样。教师额外看到动作指导和特权任务信息：经审核的模拟用户私有目标与约束摘要、参考工具名与参数、目标状态，以及从评测标准中取出的必需消息。学生只看公开上下文，评测时也如此。

# Q6 实验设计

* **迁移实验（表 1）。** 2 × 2 设计：学生 Qwen3-4B 与 Qwen3-8B，教师 Qwen3.7-Flash 与 DeepSeek-V4-Flash。共 100 步，每步 64 个任务起点（59 个 AWM、5 个 EnvScaler），取自 6,697 个任务的池子：794 个环境的 5,942 个 AWM 任务，和 49 个环境的 755 个 EnvScaler 任务；它们分别从 10,000 和 2,550 个源任务中，经上下文长度截断（仅 AWM）、确定性完整性审查、以及用 DeepSeek-V4-Flash 做的静态可行性筛选得到（不要求专家轨迹成功）。DeepSeek-V4-Flash 同时也是匹配器和 EnvScaler 的用户模拟器。
* **评测。** [BFCL](../concepts/bfcl.md) 多轮（800 个任务，一次试验）、[ToolSandbox](../concepts/toolsandbox.md)（490 个本地场景，四次试验，相似度分数）、[AppWorld](../concepts/appworld.md) Normal（168）与 Challenge（417）的任务与场景目标完成率，以及 [τ²-Bench](../concepts/tau2-bench.md) 的 Airline、Retail、Telecom（50、114、114 个任务），按四次试验算 pass¹ 与 pass⁴，用户由 Qwen3.5-9B 扮演，自然语言断言关闭。主平均值对四个基准等权（AppWorld 取 TGC 均值，τ² 取 pass¹ 均值）。教师也直接评测作为参考。
* **蒸馏方法对比（表 2）。** 学生 Qwen3-4B，教师 Qwen3-32B，使用官方 178 个 τ² 训练任务和 100 个测试任务，每步 24 个任务起点，第 50 步评测。KD 在成功的教师轨迹（每个起点四条）的全部词元上微调；OPD 用教师对数概率，以采样词元反向 KL 监督学生自己的轨迹。
* **消融（表 3）。** 有效性奖励（有效 +1、无效 −1；语义分数只用来选择执行哪个候选）、二值奖励（λ = 0）、随机执行（均匀选择要执行的候选）。
* **其他。** 三个挑选的前后对比案例（每个 τ² 领域一个），以及第 50 步的 Self-ActionOPD（表 5）。每个配置只训练一次；重复试验衡量的是交互波动，不是训练波动。

# Q8 证据质量

* **有支撑的结论。**
  * *所有配置都提升了四基准平均。* Qwen3-4B：30.8 到 35.9（+5.1，Qwen3.7-Flash 教师）和 37.7（+6.9，DeepSeek-V4-Flash）。Qwen3-8B：35.6 到 39.0（+3.3）和 40.0（+4.4）。BFCL（4B：34.3 到 42.3 和 44.1）、ToolSandbox（55.5 到 61.8 和 63.3）、AppWorld Normal TGC（9.5 到 14.3 和 13.1）在四个配置中都上升。
  * *通过动作接口可以跨家族蒸馏。* DeepSeek 教师在没有分词器对齐的情况下训练 Qwen 学生，且在两种规模上都给出更高的学生平均。
  * *语义奖励优于有效性奖励。* τ² 测试集 pass¹ 平均：ActionOPD 40.0，有效性奖励 30.8，二值奖励 36.9，随机执行 37.5（基座 29.2）。
  * *特权自蒸馏在测试时不需要特权输入也有效。* Self-ActionOPD 把 τ² 测试集 pass¹/pass⁴ 从 29.2/7.5 提到 34.0/10.0，三个领域的 pass¹ 都有提升。
* **比标题更弱或更窄的地方。**
  * *"随学生规模扩展"只有两个规模，且增益在缩小。* 8B 学生最终更高是因为起点更高（35.6 对 30.8）；它的增益（+3.3、+4.4）小于 4B 学生（+5.1、+6.9）（读者据表 1 观察）。
  * *"随教师能力扩展"只有两个教师，且学生与两者都相去甚远。* 两个教师的直接平均相差 5.6 分（71.2 对 65.6），而这一差距完全来自 AppWorld（Normal TGC 84.5 对 70.2，Challenge 74.8 对 36.5）；在 BFCL、ToolSandbox 以及 τ² 的 Airline 和 Retail 上 Qwen3.7-Flash 反而领先（读者据表 1 计算）。学生平均的差距只有 1.8（4B）和 1.0（8B）。最好的学生平均为 40.0，其教师为 71.2。
  * *τ² 上的迁移有好有坏。* 部分单元低于基座：4B 配 Qwen3.7-Flash 的 Airline pass¹（33.5 对 34.5）；8B 配 Qwen3.7-Flash 的 Retail（pass¹ 37.7 对 38.2，pass⁴ 10.5 对 14.0）；8B 配 DeepSeek 的 Telecom pass⁴（12.3 对 14.9）。
  * *"与 OPD 和 KD 相当"指 pass¹ 持平、pass⁴ 落后。* 测试集 pass¹ 为 40.0，对 OPD 39.6、KD 37.5；pass⁴ 为 14.2，对 17.5 和 19.2；Telecom 测试集 pass⁴ 为 15.0，对 22.5 和 25.0。作者自己说结果"并不确立全面优势"。采集预算没有对齐（附录 B.4：相同的任务起点数并不意味着样本数、词元数、教师查询数或算力相同），每种方法只训练一次；100 个测试任务、四次试验下 0.4 分的 pass¹ 差距很小（读者注）。这里的教师与学生同家族，所以这一比较没有体现无需分词器的优势。
  * *消融结果并不一致。* 随机执行在 Retail 测试集 pass¹（40.6 对 39.4）和 Telecom 测试集 pass¹（44.4 对 40.6）上胜过完整 ActionOPD，二值奖励在测试集 pass⁴ 上与之持平（14.2）。有效性奖励变体还会把全部有效的组屏蔽掉，因此它改变的不只是奖励，还有可训练组的数量。
  * *匹配器未经审查。* 没有报告对 LLM 匹配器判断的人工检查；作者把误判列为局限。在迁移实验中，同一个模型（DeepSeek-V4-Flash）同时是教师、匹配器、任务筛选器和用户模拟器。
  * *τ² 数字依赖于协议。* Qwen3.5-9B 用户和关闭的自然语言断言，使这些数字无法与排行榜或其他论文的 τ² 结果比较。
  * *挑选的案例和域内划分。* 三个案例是专门挑出的"基座失败、训练后成功"的配对。τ² 训练集分数衡量的是域内拟合；Self-ActionOPD 的教师能看到由训练任务评测标准派生的参考动作和目标状态。

# Q9 贡献

* 一个动作级在策略蒸馏目标及其 REINFORCE 推导，把"教师决定做什么"与"学生如何措辞"分开。
* 只需生成的教师接口：不需要对数概率、分词器对齐或同一模型家族。
* 状态组展开：在同一状态上对多个学生候选按同一组教师样本打分，执行最好的，全部用于训练。
* 一个有形状的一致性奖励（无效惩罚、首次匹配记单位奖励、后续匹配给较小奖励）及其导出的目标函数，以及动作级的特权自蒸馏变体。

# Q10 下一步

* **作者提出的。** 一致不等于正确，教师的错误会变成学习目标；匹配器的错误会错配奖励；固定的 K 和 N 下，若长程交互中合理动作很分散，可能很少有候选匹配，更大的 K 和 N 尚未测试。
* **多种子与算力对齐重做（读者建议）。** 每个配置多个训练种子，并让 KD 和 OPD 基线在教师查询数或词元数上对齐，才能看出 τ² 上的排名是否稳定。
* **审查匹配器（读者建议）。** 对工具参数和消息判断抽样做人工标注，按工具和领域拆分，可以给错配奖励的比例定界。
* **加入结果奖励（读者建议）。** 损失中刻意没有结果奖励；把一致性与环境成功结合，可以检验一致性是否主要在教师正确时有用——这与附录 A.1 所示的"偏向单一模式"性质有关。
* **跨分词器基线（读者建议）。** 在 DeepSeek 到 Qwen 这一对上与跨分词器 OPD 比较，那正是 ActionOPD 声称接口优势的场景。

# 相关

* [智能体微调](../topics/agent-fine-tuning.md) - 从黑盒教师做动作级在策略蒸馏，用组内相对的截断目标训练，没有结果奖励。
* [在策略蒸馏](../concepts/on-policy-distillation.md) - 用下一动作的语义一致性取代词元级散度，教师只需提供生成；在 τ²-bench 上与采样词元反向 KL 的 OPD 比较，并扩展到同权重特权教师（Self-ActionOPD）。
* [GRPO](../concepts/grpo.md) - 优势在同一状态的四个候选组内中心化，再用整批共享的标准差白化，配合 PPO 与双重截断；奖励全同的组被丢弃。
* [Agent World Model](../concepts/agent-world-model.md) - 6,697 个训练任务中 5,942 个（794 个环境）的来源，也占每步 64 个任务起点中的 59 个。
* [EnvScaler](../concepts/envscaler.md) - 来自 49 个环境的 755 个训练任务，交互中含模拟用户。
* [BFCL](../concepts/bfcl.md) - 多轮迁移基准（800 个任务）：Qwen3-4B 在 DeepSeek 教师下从 34.3 到 44.1。
* [ToolSandbox](../concepts/toolsandbox.md) - 以相似度在 490 个本地场景、四次试验上打分的迁移基准：Qwen3-4B 在 DeepSeek 教师下从 55.5 到 63.3。
* [AppWorld](../concepts/appworld.md) - 迁移基准（Normal 与 Challenge）；较强教师的领先主要在这里，学生的 TGC 都低于 18。
* [τ²-Bench](../concepts/tau2-bench.md) - 迁移基准，也是 KD/OPD 对比、消融和 Self-ActionOPD 的试验场，使用 Qwen3.5-9B 用户并关闭自然语言断言。
* [Agent-Reflex](../papers/2610.17953.md) - 同样在合成环境上训练小型 Qwen3 工具调用智能体，并在 BFCL、ToolSandbox 和 τ² 上评测；它的蒸馏是词元级、同权重、以技能卡为特权上下文，而 ActionOPD 从独立的黑盒教师做动作级蒸馏。
* [X-Tree](../papers/2609.32993.md) - 以挖掘出的技能树为特权上下文的同权重在策略自蒸馏；Self-ActionOPD 同样用同权重教师，但监督的是动作而非词元。
* [SLCA-GRPO](../papers/2609.29050.md) - 另一种在小型 Qwen 模型上、以 BFCL 和 τ²-bench 评测的工具调用 RL 方法；它改变结果优势落在哪些词元上，而 ActionOPD 用一致性取代结果奖励。

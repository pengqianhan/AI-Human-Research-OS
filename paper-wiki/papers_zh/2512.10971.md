> 论文:**AI-Trader: Benchmarking Autonomous Agents in Real-Time Financial Markets**
> 论文链接:<https://arxiv.org/abs/2512.10971>
> 机构:香港大学 HKUDS 实验室

# Q1 问题定义

* **输入(X)**:在每个决策步骤,一个完全由智能体自身工具调用构建出的观测 `o_t = f(p, s, {π_i}, i)`:当前资产价格 `p`、当前持仓 `s`,以及智能体自行选择检索的任何额外单资产数据 `π_i`(基本面、技术面)或一般信息 `i`(新闻、宏观信号)。不提供任何预先打包的信息、人工整理的摘要或固定工作流;除了价格和持仓之外的一切都必须主动获取。
* **输出(Y)**:一个离散的单资产交易动作 `a_t ∈ {买入, 卖出, 持有}`,由观测和智能体自身的 ReAct 式自然语言推理轨迹 `r_t` 计算得出 `a_t = f(o_t, r_t)`,并针对实盘或模拟实盘的实时市场价格执行,产生真实的经济后果。
* **核心问题**:现有的动态智能体评测框架(SWE-Bench 式的静态题库加动态执行设计、GAIA、BrowseComp、XBench、Tau2Bench;完全动态的 LiveCodeBench 和 FutureX)以及现有的金融基准(静态的 FinSearchComp、FinBench;"动态"但属于模拟性质的 InvestorBench、Finance Agent Benchmark、LiveTradeBench、StockBench)仍然缺乏真正的自主性和实时约束——它们仍然高度依赖固定提示词和预定义工作流,而缺乏真实的时间压力、真实的市场波动和真实的经济后果,造成基准表现与真实世界能力之间的脱节。
* **范围**:三个实时市场——美国股票(纳斯达克 100 全部成分股外加一个零收益现金资产)、中国 A 股(上证 50 全部成分股)和加密货币(Bitwise 指数追踪的 10 个主要 USDT 交易对)——分别于 2025 年 10 月 1 日至 11 月 7 日(美股按小时、A 股按天)和 2025 年 11 月 1 日至 14 日(加密货币,按天)实时评测,使用六个 LLM 基座模型,统一封装为结构相同、配备相同五工具 MCP 工具链的智能体。

# Q2 问题的新颖性

此前的"实盘"智能体评测设计分为两类,论文明确将自身定位在这两类之外:将**静态任务库与动态执行**相结合的基准(SWE-Bench、GAIA、BrowseComp、XBench、Tau2Bench),以及**任务集与环境均完全动态**的基准(LiveCodeBench、FutureX)。金融智能体基准同样分为静态知识测试(FinSearchComp、FinBench)和动态但仍受限的模拟类基准(InvestorBench、Finance Agent Benchmark、LiveTradeBench、StockBench),论文认为这些仍未达到真正的自主性与实时约束。AI-Trader 声称的新意有三点:(1) **完全自主的极简信息范式**——智能体只获得价格、持仓和工具,没有任何人工整理的预打包上下文,迫使它自行主导全部信息获取,而不是对一份已经组织好的分析师简报进行推理(这与本知识库已收录的 TradingAgents 的分析师团队准备结构化报告设计、以及 FinAgent 的工具计算诊断设计形成鲜明对比,二者都对智能体的输入做了大量预先结构化);(2) 跨越三种结构截然不同的监管与流动性机制的**真正实时、持续演化的市场**,而非历史回测或模拟数据;(3) 由构造保证的**数据无污染性**,因为实时和未来的市场状态不可能像历史回测窗口那样泄漏进任何模型的训练数据。

# Q3 科学假设

如果只给 LLM 智能体最少的上下文(当前价格、持仓和一个小型固定工具集),并要求它在零人工整理输入、零人工干预的情况下自主搜索、核实并综合实时市场信息,那么在真正动态的实盘市场中所测得的交易表现将与静态推理和知识基准上的表现出现明显分化——通用智能水平不会可靠地预测交易能力——而决定跨市场稳健性的关键因素将是风险控制的自律程度,而非原始的预测或推理能力,并且可获取超额收益的幅度将取决于市场的流动性和监管结构(在流动性高、政策驱动较弱的市场中更容易实现),而非在各市场间保持一致。

# Q4 相关工作与关键人物

* **面向自主决策的 LLM 智能体**:梳理了从文本补全系统到具备复杂推理、规划和环境交互能力的智能体的转变(Anthropic 的 Claude 系列、Qwen、AutoAgent、OSWorld、GPT 系列相关工作),将不确定性下的长时程决策定位为 AI-Trader 在金融场景中所要隔离出的核心能力。
* **工具使用与环境交互**:把模型上下文协议(MCP)定位为 AI-Trader 自身工具链所依托的标准化接口,将该基准置于关于维持"感知-决策-行动"循环的更广泛工具使用文献之中。
* **从静态到实时的智能体评测**:把已有的实时环境基准分为静态题库加动态执行(SWE-Bench、GAIA、BrowseComp、XBench、Tau2Bench)与任务和环境均完全动态(LiveCodeBench、FutureX)两类;把已有的金融基准分为静态知识型(FinSearchComp、FinBench)与动态但仍受限型(InvestorBench、Finance Agent Benchmark、LiveTradeBench、StockBench)——AI-Trader 明确瞄准的空白是这两类基准都不具备的真正自主性加真正实时约束。
* **作者与机构**:Tianyu Fan、Yuhao Yang、Yangqin Jiang、Yifei Zhang、Yuxuan Chen,以及通讯作者 Chao Huang,均来自香港大学 HKUDS 实验室;Fan 与 Huang 同时也是本文所引用的 AutoAgent(同一研究组的零代码 LLM 智能体框架)的共同作者。

# Q5 核心解法

1. **完全自主的极简信息范式**。智能体唯一被保证获得的输入是当前价格和当前持仓;其他任何信息(基本面、技术面、新闻、宏观背景)都必须通过工具调用主动获取。论文将其表述为三条明确的设计原则:所有信息必须通过工具获取,所有决策必须基于自主推理,所有动作必须在真实世界约束下可执行。
2. **三个结构迥异的实时市场**。美国股票(纳斯达克 100 成分股——高流动性、信息披露透明,受美联储政策和财报驱动)、中国 A 股(上证 50 成分股——监管框架不同,受政策和情绪驱动,呈阶段性波动)和加密货币(经 Bitwise 指数追踪的 10 个主要交易对,涵盖价值存储、智能合约、支付和预言机类资产——24/7 连续交易,波动极端)被刻意选取,以呈现对比鲜明的监管、流动性和投资者构成机制,从而对泛化能力施压测试。
3. **观察-推理-行动闭环**。遵循 ReAct 范式("先思考,后行动"),每一步要么调用另一个工具以获取更多观测,要么给出一个离散的单资产动作(买入/卖出/持有)——这是刻意选择的简单、可解释动作空间,而非连续仓位规模。所有中间自然语言推理都被完整记录,使决策过程可观察、可审计、可复现。一个自我纠正机制会拒绝任何超出可用流动性或违反合规约束的提议动作,并强制智能体重新调用工具、重新推理。
4. **跨全部六个基座模型统一的极简五工具 MCP 工具链**,以此隔离出模型层面的差异而非工具或架构上的混淆因素:**查询价格**(时间感知的历史/盘中 OHLCV 查询,识别不同市场的行情规则)、**搜索**(关键词驱动的实时网络搜索,严格限定在当前模拟时间点可获得的信息范围内,防止未来数据泄漏)、**新闻**(带有情绪信号的结构化财经新闻,附时间戳和相关证券标签)、**数学**(数值计算支持),以及**交易**(按特定市场规则执行订单,例如 A 股 100 股整数倍的最小交易单位,实时更新持仓和现金余额,全程可审计)。
5. **可插拔的扩展平台设计**。一个注册机制允许第三方开发者将自定义智能体或 MCP 工具接入同一评测框架,把 AI-Trader 定位为一个不断成长的社区平台,而非一个封闭、固定的评测集合。

# Q6 实验设计

六个主流 LLM 基座模型(DeepSeek-v3.1、MiniMax-M2、Claude-3.7-Sonnet、GPT-5、Qwen3-Max、Gemini-2.5-Flash)各自被封装进结构完全相同的智能体——相同目标、相同工具、相同架构——以便将表现差异归因于基座模型自身固有的推理与决策能力,而非智能体设计。实时评测窗口:美国股票和 A 股为 2025 年 10 月 1 日至 11 月 7 日(美股按小时,A 股按天);加密货币为 2025 年 11 月 1 日至 14 日(按天;加密货币全年 365 天交易,而股票约 252 个交易日)。指标:累计收益(CR)、索提诺比率(按下行偏差调整,目标收益为零)、波动率(年化样本标准差)以及最大回撤(MDD)。基准:QQQ Invesco ETF(美股)、上证 50 指数(A 股)以及一个 CD5 加密货币指数(加密货币)。论文还报告了交易执行统计(无交易时段占比、平均每期交易次数)以及两个说明特定推理行为的单日叙事案例研究。

# Q7 数据与代码

AI-Trader 是一个实时、持续更新的评测平台,而非一个静态数据集——论文在 [github.com/HKUDS/AI-Trader](https://github.com/HKUDS/AI-Trader) 发布了平台代码、五工具 MCP 工具链和评测日志(撰写本笔记时据 HF 元数据有 21,634 个 star,反映出很强的社区关注度),配套网站为 ai4trade.ai。

# Q8 证据质量

本笔记基于 arXiv 完整论文正文(摘要、第 1 节引言、第 2 节相关工作、第 3 节 AI-Trader 框架,含 3.1 实时交易环境和 3.2 交易智能体、第 4 节实验评测,含 4.1–4.4 案例研究、第 5 节结论、参考文献以及附录 A–B),通过 `hf papers read` 获取,该工具对这篇论文返回了完整、未被截断的转换结果。摘要与正文的编号发现在措辞上保持一致。除论文自身陈述外,本笔记补充三点评估:(1) 每个市场的结果都来自**每个模型在一个短窗口内的单次实盘运行**(美股/A 股约 5.5 周,加密货币 2 周),没有报告重复试验、置信区间或跨种子方差——统计方案明显弱于本知识库中 ASI-Bench 在三次运行上报告均值±标准差的做法,论文本身也没有对此做出说明。(2) 在加密货币市场,每个智能体*以及* CD5 指数基准在整个窗口内都是亏损的(收益率介于 −12.18% 到 −18.63% 之间),因此"唯一跑赢基准的智能体"(DeepSeek-v3.1 以 −12.18% 对基准的 −14.30%)是一个真实但相对的发现,发生在整个市场普遍下跌的背景下,而非绝对收益上的成功——论文在正文中如实陈述了这一点,并未刻意掩盖,但仅凭标题式阅读"跑赢基准"这类表述容易忽略其符号方向。(3) 两个案例研究被明确定位为说明性的单日叙事("通过案例研究,我们观察到..."),而非对完整轨迹日志所做的系统化、量化错误分类,因此应将其理解为特定行为(成功的防御性推理;由未经核实新闻驱动的误判)的定性存在性证明,而非经过测量的失败率。

# Q9 主要贡献

1. AI-Trader,第一个完全自动化、实时、数据无污染的 LLM 智能体金融决策评测基准,跨越三种结构迥异的市场机制(美国股票、中国 A 股、加密货币)与多种交易频率。
2. 一套完全自主的极简信息范式,只给智能体价格、持仓和工具——零人工整理的预打包信息——将真正的自主信息获取与综合能力,同基准专属的提示工程隔离开来。
3. 一套跨六个基座 LLM 统一应用的极简五工具 MCP 工具链(查询价格、搜索、新闻、数学、交易),将模型层面的推理差异同智能体架构或工具设计上的混淆因素隔离开来。
4. 实证证据表明通用 LLM 智能水平并不能可靠预测交易能力——在推理和知识基准上表现出色的模型(GPT-5、Qwen3-Max)在实盘交易中却给出了一些最差的结果;而风险控制的自律程度,而非激进的收益追逐,才是跨市场稳健性最强的预测因子,MiniMax-M2 在美股和 A 股市场上持续的相对优势正说明了这一点。
5. 反对跨市场策略泛化的直接证据:同一模型在不同市场上的表现差异很大(DeepSeek-v3.1 在美股和加密货币市场表现强劲,在 A 股市场却为负),表明当前智能体尚未实现真正的跨市场迁移。
6. 一项发现:在流动性高、政策驱动较弱的市场(多个智能体跑赢美股 QQQ)中比在政策驱动型市场(A 股市场没有任何智能体跑赢上证 50 指数)中更容易在同一评测周期内产生超额收益。
7. 两个定性案例研究,分别揭示了当前智能体实时决策流程中的一项优势(通过多源搜索与推理,自主预判并在关税驱动的股票抛售之前进行防御性调仓)和一个具体、系统性的失败模式(在没有交叉核实的情况下采信单一未经核实的新闻叙事,导致错失一轮市场上涨)。

# Q10 下一步

论文将 AI-Trader 定位为一个不断成长、难度会随之提高的评测平台,并配有一套注册机制,邀请第三方智能体和工具接入,以便基准能跟上智能体能力的提升;它明确将缺乏系统化信息核实模块(由案例 2 具体揭示)列为未来智能体设计的一个清晰、可行动的方向,而非一个假设性的缺口。本笔记补充一个论文结果本身提出、但已读取文本未处理的方法论问题:由于每个市场的发现都建立在每个模型在一个短窗口内的单次实盘运行之上,没有重复试验或方差估计,一个自然但尚未报告的下一步,是在每个市场跨多个不重叠的窗口重复该实盘评测,然后才能把某个模型的相对排名(例如 MiniMax-M2 在跨市场稳健性上的优势)当作该模型的稳定属性,而不是本文所研究的这个特定约 5 周样本窗口的特有现象。

* [LLM agents](../topics/llm-agents.md) - 一套基于 ReAct、完全自主的信息获取设计(零预打包上下文,全部观测都由智能体自身的工具调用构建),把本主题的工具使用与验证主题推进到一个"正确"由真实、实时经济后果衡量、而非静态任务完成检查衡量的领域。
* [TradingAgents](2412.20138.md) - 两者都是针对被动基准评测的 LLM 交易系统,但 TradingAgents 在一个固定约 3 个月的历史窗口上,对三只大盘股回测一套定制的五角色、结构化报告流水线;而 AI-Trader 把智能体精简为一个配备五个通用工具的极简 ReAct 循环,并在三个结构迥异的市场上做实盘评测——这一设计选择隔离出的是基座模型能力,而非架构设计,代价是没有测试 TradingAgents 式的角色专职化是否会改善 AI-Trader 六个基座模型中任何一个的表现。
* [Orchestration Framework for Financial Agents](2512.02227.md) - FinAgent 对智能体的输入做了大量预先结构化(工具计算的诊断、仅依据文献起草因子、结构化 JSON 上下文),并在历史回测上评测——这与 AI-Trader 零预打包信息、实盘评测的设计几乎是同一任务的相反选择。

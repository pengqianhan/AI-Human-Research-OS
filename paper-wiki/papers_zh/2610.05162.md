# Q1 问题定义

* **输入（X）：** 当前用户请求 q、可见的任务上下文与证据 c，以及由现有长期记忆系统（A-MEM、Mem0、NaiveRAG、MemoryBank 或 LightMem；MemTrapBench 上取 top-10，PersistBench 上每个实例 4-16 条）检索出的记忆集合 M。记忆系统本身保持不变。
* **输出（Y）：** 面向用户的最终回答 y，要求每条记忆只影响当前任务所允许的部分（例如语气或呈现方式，而不是客观决策）。
* **核心问题：** *记忆诱发的谄媚*（memory-induced sycophancy）：智能体过度迎合用户被记住的观点、偏好或身份，即使这些内容不准确、已过时，或与当前证据相矛盾。论文认为风险不是记忆内容本身的属性：一条准确且相关的记忆（例如"用户是心脏科医生"）可以正当地决定解释的专业程度，却不应左右治疗方案的选择。因此任务是在检索之后校准：每条记忆能支持什么、能影响回答的哪些部分、不能证成哪些结论。

# Q2 问题新颖性

部分新颖。记忆诱发的谄媚与过度个性化已有近期基准记录（MemSyco-Bench、PersistBench、MemTrapBench、OP-Bench、BenchPreS、STALE），"Recalling Too Well" 以及 Mao 等关于有状态智能体持续谄媚的研究也有涉及。现有缓解方法都在推理*之前*介入：在抽取阶段（用摘要替代离散记忆抽取；选择性遗忘）、在检索阶段（Self-ReCheck 的相关性过滤、MemGate 的学习式准入门控）、或在组织阶段（按领域结构化记忆）。新的视角是：记忆风险是关系性的，由记忆、任务与证据共同决定，因此必须在检索之后处理，即调节每条记忆的作用，而不是决定哪些记忆可见。预研究说明了这一点的必要性：即使只给准确、相关的记忆，准确率仍然下降。

# Q3 科学假设

1. **准确的记忆也会误导。** 如果模型只收到准确、无害、与任务相关但不足以决定答案的记忆，其准确率仍会低于不给记忆的情形，而且新增的错误会顺着记忆的方向（第 2.1 节，图 2a）。
2. **反事实边界能暴露隐藏风险。** 如果把每条记忆固定、在假设的任务情境中逐一检视，得到的"条件→影响"规则在任何针对具体任务的推理之前就能改善记忆使用（消融变体 B，表 3）。
3. **检索后校准优于推理前过滤。** 如果把边界落实到实际任务，并逐片段检查回答对记忆的使用是否在许可范围内，那么在不同记忆系统和不同骨干模型上，记忆使用的可靠性提升会大于提示免责声明、相关性过滤、按领域分组或学习式门控（表 1-2）。

# Q5 关键解法思想

MemAdapter 在检索之后增加三个 LLM 阶段，提示词见附录 H.1：

1. **反事实归纳（Counterfactual Induction）。** 模型只看到检索出的记忆，看不到查询。对每条记忆，它推出这条记忆可能服务的若干任务类型，构造具体的假设情境（一个请求加一种证据配置），在每个情境中评估这条记忆可以*支持*什么、*作用范围*（scope）是什么、*限制*（limitation）在哪里，并只保留跨情境的实质差异，形成条件使用规则。每条记忆输出一张 JSON 格式的"边界卡"（boundary card）。
2. **情境感知反思（Context-Aware Reflection）。** 给定实际查询、对话、证据、全部记忆及其边界卡，模型为当前任务落实每张边界卡，并联合考虑记忆之间的更新、限定与冲突，为每条记忆写一条自然语言*使用指令*：它能支持什么、能影响回答的哪个部分以及影响多大、影响到哪里为止。
3. **基于证据的推理（Evidence-Based Reasoning）。** 模型在这些指令下生成回答，同时在内部记录回答支撑轨迹（每个主要片段的角色、来源与适用指令），检查每个来源确实存在并支撑对应片段、每次使用记忆都在其指令范围内，最后只返回回答。

与已有方法的关键区别在于：不删除也不改写任何记忆，而是把每条记忆被允许的推理作用显式写出来。方法无需训练，也不改动记忆的构建或检索。

# Q6 实验设计

* **基准。** MemSyco-Bench（全部 1,550 个实例；When to Use Memory = 客观事实判断、情境范围控制、记忆-证据冲突，各 300；How to Use Memory = 个性化记忆使用 300、有效记忆选择 350）；MemTrapBench（1,050 个实例；推理固着包含任务边界、认知偏差、创伤三类情境，信念扭曲对应安全情境；评审打分 0-5）；PersistBench（500 个样本：跨领域泄漏 200、谄媚 200、有益记忆使用 100；FR@3 表示三次生成中任意一次评分不低于 3 即算失败，越低越好）。所有打分都遵循各基准官方的 LLM 评审协议；检索到的文本未写明评审模型。
* **记忆系统。** A-MEM、Mem0、NaiveRAG、MemoryBank、LightMem，统一使用 BGE-M3 嵌入（1,024 维），需要 LLM 处理记忆时统一用 DeepSeek-V4-Flash。每个实例只检索一次，冻结的记忆集合由所有方法共享。
* **基线。** 直接生成；Anti-Sycophancy（提示免责声明，来自 Recalling Too Well）；Self-ReCheck（相关性过滤）；Dynamic Partition（按领域分组）；MemGate（官方检查点，门控阈值 0.07）。
* **骨干模型。** 主实验用 DeepSeek-V4-Flash（温度 0.2，关闭思考）；跨骨干检验用 GPT-5.6-sol 与 Qwen3-8B（4-bit NF4、贪心解码），只在 MemSyco-Bench 上进行。
* **消融。** B（只做反事实归纳）、B+R（再加情境感知反思）与完整方法，在 MemSyco-Bench 上用 DeepSeek-V4-Flash（表 3 与表 8）。
* **预研究。** 75 个实例（每个基准 25 个），经抽样、人工审核、必要时重构，使每条记忆都准确、无害、相关且不足以决定答案；比较有无记忆两种条件。检索到的文本未说明预研究所用骨干模型。
* **运行时间。** 在 PersistBench 上对三个记忆系统报告每样本的平均、P50、P95、P99 秒数（表 9）。
* **未纳入设计。** 没有重复运行、方差或显著性检验；没有对回答的人工评测；没有 token 成本统计；没有"只做基于证据的推理、不用边界卡"的变体。

# Q8 证据质量

* **支撑充分的部分。**
  * 动机性结论在其范围内成立：在 75 个精选实例上，加入准确、相关的记忆使准确率从 96.0% 降至 77.3%（MemSyco-Bench 96.0→68.0，PersistBench 100.0→84.0，MemTrapBench 92.0→80.0）；不给记忆时答对的回答中有 19.4% 变错，而且全部偏向记忆。
  * MemSyco-Bench 上的主要提升幅度大且一致。用 DeepSeek-V4-Flash 时，MemAdapter 在五个记忆系统下的 When-to-Use（87.89-91.22）与 How-to-Use（82.15-89.39）准确率都最高；各系统平均准确率的区间从 37.03-71.71 收窄到 85.48-90.45。相对直接生成，后端越弱提升越大（LightMem 的 When-to-Use +56.67；记忆-证据冲突从 4.33 升到 97.00）。
  * PersistBench 的谄媚失败率在每个系统上都下降：FR@3 从 76.50-82.00 降到 51.00-58.50（降低 21.0-31.0 个点），FR@1 与 FR@2 也下降。
  * 用 Qwen3-8B 时，MemSyco-Bench 平均准确率从 24.57-38.38 升到 80.46-86.67。
* **比标题结论更弱或更窄的部分。**
  * 相对最强对比方法的优势有时很小，例如 A-MEM 上的 When-to-Use 只比 Anti-Sycophancy 高 0.44 个点。在 PersistBench 的跨领域泄漏上，Self-ReCheck 在五个系统中的四个优于 MemAdapter；在 LightMem 上 MemAdapter 比直接生成还差 0.50 个点。
  * 有益记忆失败率在五个系统中的四个上升（NaiveRAG +1、A-MEM +2、LightMem +4、MemoryBank +6 个点），只在 Mem0 上下降（-3）。论文称之为"依赖记忆系统的权衡"；直白地说，这个方法有时会压制用户本来希望使用的记忆。
  * 用 GPT-5.6-sol 时，个性化记忆使用在五个系统中的三个下降（A-MEM 最多 -9.00），其他维度的提升也较温和（三个系统的平均准确率提升 +3.10 到 +9.56）。
  * 消融没有把各阶段清楚地分开。单独的反事实归纳带来大部分提升（NaiveRAG 70.25→84.26）；反思阶段使平均值变化 -0.40 到 +1.49 个点（使 LightMem 从 82.27 降到 81.87）；最后一个阶段再提高 2.90-6.19 个点。由于没有"只做基于证据的推理"的变体，一个精心设计的证据落地提示本身可能就解释了完整方法的部分提升。
  * 每种配置似乎只运行一次；在评审打分且温度为 0.2 的条件下，约一个点以内的差异无法与噪声区分。
  * 三个基准之一（MemSyco-Bench）来自有重叠的作者团队，而且三个基准都由未写明型号的 LLM 评审打分。
  * 运行时间表显示，一个需要三次顺序调用的方法与单次调用基线延迟相当（平均 6.63-6.95 秒对 6.04-7.10 秒）；但没有报告 token 成本，因此成本结论不完整。
* **读者观察。** 附录 D.3.1 把 PersistBench 有益记忆分数定义为 1 表示成功、2-3 表示失败，而附录 H.3.3 的评审提示把 3 定为完全成功、1 定为没有使用。两处描述有一处是反的；检索到的文本没有说明表 7 用的是哪种约定。

# Q9 贡献

* 把记忆诱发的谄媚重新表述为检索之后"记忆如何被使用"的问题，并用一个小规模受控研究表明，仅凭准确、相关的记忆就能把正确答案扭转为错误。
* MemAdapter：一个无需训练的三阶段层（反事实边界卡、任务特定使用指令、带支撑检查的回答），可以叠加在五种不同的记忆系统之上而不改动它们。
* 在三个基准、五个记忆系统上与四种检索后干预方法比较，并用两个额外骨干模型检验，代码与提示词公开。

# Q10 下一步

* **拆分各阶段。** 运行"只做证据落地"与"跳过反思"的变体，并报告多次运行的方差，以确定是哪个阶段带来了提升。
* **成本。** 报告每个查询的 token 数，并测试按记忆缓存边界卡：反事实归纳不依赖查询，可以在写入记忆时只运行一次。
* **有益使用。** 把有益记忆失败率作为一等目标来跟踪；一个压制了有用个性化的方法只是用一种失败换了另一种。
* **人工判断。** 用人工评分验证评审打分得出的提升，特别是用户希望保留的个性化是否被保留。
* **会行动的智能体。** 这些基准都是问答；在依据记住的偏好采取行动的智能体（购物、日程）中测试同样的校准，才能看出当代价是行动而不是文字时，边界是否还成立。
* **与本仓库的契合（读者笔记）。** 本仓库保存了智能体在启动时读取的人类认知缓存与项目记忆；MemAdapter 的"支持、范围、限制"三元组可以作为一张检查表，用来判断一条被记住的偏好什么时候应该左右智能体的选择、什么时候必须让位于任务证据。

> 论文:**VibeWorlding: Can Multimodal Agents Construct 3D Open Worlds End-to-End?**
> 论文链接:<https://arxiv.org/abs/2608.15265>
> 机构:HF 元数据标注为 Tencent,代码托管于 HKUST-Guangzhou USAIL Lab 的 `usail-hkust` GitHub 组织下;arXiv v1 提交于 2026-08-15,v2 提交于 2026-08-19

# Q1 问题定义

* **输入 `X`**:一段描述用户所需 3D 世界的自然语言(在适用场景下为多模态)查询——既可以是从空白地图开始构建,也可以是对一个已有的种子 3D 世界进行修改;此外还可访问一个固定的 3D 资产库和一组固定的五个 3D 工具(检索、添加、删除、旋转、平移)。
* **输出 `Y`**:一个最终生成的 3D 世界,同时以文本格式地图和多视角渲染图像两种形式表示,产出方式是一个多轮智能体-环境交互过程——智能体在其中推断用户意图、规划场景布局、调用工具,并在终止前对渲染出的视觉反馈进行反思。
* **核心问题**:现有基于 MLLM 的 3D 世界构建方法——无论是带专用子智能体的固定工作流流水线,还是更自主的智能体系统——几乎都只在理想化、简单的查询上做评测,这使得很难系统性地检验多模态智能体是否真正理解开放式用户意图、能否正确调用 3D 工具、能否联合对文本和视觉的 3D 世界状态进行推理。这种检验面临两个结构性障碍:高质量的 3D 资产及其操作工具分散在互不兼容的接口中,缺乏统一的沙箱;而判断一个构建出的世界是否"有效",需要同时满足物理约束(不穿模、正确落地)和开放式的用户意图——这一联合条件无论是手写规则还是通用的 LLM 评审都难以可靠地捕捉。
* **范围**:论文既定义了这一评测问题(VWE-Bench),又构建了用于弥补由此暴露出的能力差距的训练基础设施(VibeWorlding-Gym),而非把基准和训练框架当作两个各自独立、假设互不相关的贡献来处理。

# Q2 问题的新颖性

此前基于 MLLM 的 3D 世界构建工作可分为两类:遵循预定代码路径的固定工作流方法(SceneCraft、3D-GPT、UnrealLLM),以及支持规划和多轮细化的更自主的智能体系统(SceneWeaver、SAGE、SceneReVis)。论文指出的差距是:这两条路线"仍局限于理想化场景,无法处理开放式的真实世界用户查询",且都没有配套面向同一开放式场景构建的基准和训练框架。另一方面,多模态强化学习在其他领域已有先例(Kimi K2.5、OpenSearch-VL),可验证奖励强化学习(RLVR)也是一个成熟的更广泛范式——但论文声明,据其所知,此前没有工作把多模态强化学习专门应用于 3D 世界构建。因此其新颖性主张是双重且相互耦合的:第一个同时覆盖构建和细化查询、并针对论文明确称为"本质上主观"的任务设计了已验证/未验证划分的基准;以及第一个面向该特定任务领域的强化学习训练框架——它被构建为一个联合系统(共享沙箱、共享的双约束验证器同时服务于评测和强化学习奖励),而非两个各自独立的产物。

# Q3 科学假设

如果一个基准把 3D 世界查询分解为构建类查询(仅主题、主题加要素、完整蓝图、以及刻意设计为不可行的干扰项查询)和细化类查询(精确与模糊的资产级编辑,外加评论式、引导式、复述式、复杂描述式编辑),其中只有精确的资产级编辑携带真值标注(已验证),其余则由基于规则表(rubric)的评审打分(未验证);并且如果一个多模态智能体先通过在经过验证器筛选的自我博弈轨迹和真值衍生轨迹上做有监督微调进行冷启动,再进一步在文本类构建查询和多模态(渲染图像)细化查询上联合进行基于 GRPO 的强化学习训练,且仅使用基于结果的奖励——那么开源多模态智能体就能够从远低于当前前沿模型的表现,被训练到在端到端 3D 世界构建与细化任务上匹配甚至超越前沿闭源模型,并且由此得到的分维度能力分析将揭示:精确的、无碰撞的 3D 空间编辑(而非场景理解或资产检索)才是仍然存在的主要瓶颈。

# Q4 相关工作与关键人物

* 将固定工作流的 MLLM-3D 方法(SceneCraft、3D-GPT、UnrealLLM)与更自主的智能体系统(SceneWeaver、SAGE、SceneReVis)相对照;其中后三者基于 GPT-5.5、免训练的变体(SceneWeaver、SAGE、SceneAssistant)直接被用作论文自身实验中的智能体脚手架基线。
* 把自己的强化学习方案置于更广义的 RLVR(可验证奖励强化学习)范式之下,并与其他领域已有的多模态强化学习工作(Kimi K2.5、OpenSearch-VL)相对照,声明此前没有工作把多模态强化学习专门用于 3D 世界构建。
* 目前尚未因共享研究主题(3D 世界构建)与本知识库其他论文建立链接,但其训练方案(基于 GRPO 的联合多模态强化学习、纯基于结果的奖励、不做奖励塑形)与 [Agent Lightning](2508.03680.md) 在未修改的 GRPO/PPO/REINFORCE++ 之上而非用定制算法构建智能体强化学习的设计选择相呼应——详见共享的 [GRPO](../concepts/grpo.md) 概念页——不过两篇论文的范围差异很大:Agent Lightning 是一套框架无关的训练方法论,可用于任何已有的智能体,而 VibeWorlding 训练的是一个具体的智能体家族(VibeWorlder),与其自建的沙箱和验证器紧密协同设计。

# Q5 核心解法

1. **VWE-Bench 的资产与世界构建流水线。** 三阶段流程——美术标注员定义 3,148 个原生概念资产及其名称和类别;一个文生图模型(Gemini 3.1-flash)生成参考图像,再由 Hunyuan3D 3.1 转换为 `.glb` 网格;与概念图像明显不符的资产被过滤掉,剩余资产标注统一的真实世界尺度(中心点加沿 x/y/z 轴的半程长度)——最终得到涵盖 20 个语义类别(从小型道具到地形)的 2,616 个资产。专业标注员随后直接基于该资产库手工搭建 323 个种子 3D 世界,每个世界放置 8 到 258 个资产不等,并明确覆盖整个资产目录。
2. **带已验证/未验证划分的查询分类体系。** 构建类查询(共 1,364 条:322 条仅主题、620 条主题加要素、302 条完整蓝图、120 条刻意设计为不可行的干扰项)要求智能体从空白地图开始构建。细化类查询(共 5,464 条)要求智能体修改一个已有的种子世界,分为资产扰动类编辑(1,710 条精确、携带真值因而**已验证**;1,462 条模糊/信息不全)和 MLLM-as-critic 类编辑(553 条场景评论、757 条场景引导、477 条场景复述、505 条复杂多点协调描述)——后者全部为未验证。只有这 1,710 条精确资产级编辑携带真值,其余 5,118 条查询改由规则表评审打分。
3. **VibeWorlding-Gym 的双约束验证器。** 先通过确定性的 Python 几何检查(碰撞/穿模检测;高度/落地合理性)判断物理可行性——世界必须先通过这一关才能进入下一步评判。随后由一个 MLLM 规则表评审沿四个维度打分:生态合理性(全局风格一致性)、3D 理解(构建出的世界是否体现了所请求的实体/布局)、3D 推理(智能体是否正确使用 3D 工具实现了空间意图,而不仅仅是理解了目标)、检索合理性(所选资产在语义上是否恰当)。对未验证查询而言,只有通过物理可行性检查且规则表每个维度都通过才能获得奖励;对已验证查询而言,奖励改为相对真值地图正确修改的资产比例——一种直接的结构化评测,而非评审式评测。
4. **先冷启动 SFT 再联合多模态强化学习。** 未验证查询的 SFT 数据来自让 Gemini 3.1-pro 对每条查询多次尝试,只保留通过验证器的尝试,再从这些被接受的结果反向提示生成完整的推理轨迹;已验证查询的 SFT 数据则直接从真值地图合成。强化学习从该冷启动策略出发,在同一次优化过程中联合训练文本类构建查询和多模态细化查询(其观测中包含前几轮渲染出的图像),使用 GRPO 算法并采用纯基于结果的奖励——未验证查询为二元(0/1),已验证查询为连续的 [0,1] 比例——刻意避免奖励塑形以降低奖励作弊(reward hacking)风险。
5. **多轮智能体-环境交互循环。** 形式化为 {τᵢ, aᵢ} = πθ(q, {τ₁,a₁,o₁,...,τᵢ₋₁,aᵢ₋₁,oᵢ₋₁}):每一轮产生一个思考 τᵢ、一个或多个从五个统一工具中选取的工具调用动作 aᵢ,以及一个观测 oᵢ,后者结合了工具返回结果、更新后的文本格式世界地图,以及由 Blender 渲染服务从五个固定相机机位渲染出的多视角图像。当智能体不再发出任何工具调用时该回合终止,得到最终的文本加图像世界对。

# Q6 实验设计

训练使用 5,567 条 SFT 查询和 1,007 条强化学习查询;254 条测试查询取自与训练集完全不重叠的种子世界,查询类型比例在切分中保持一致。评测同时采用自动化的 Pass@1 指标(单次 rollout 解决的比例,由 Gemini-3.5-flash 作为验证器骨干判定)和盲态人工标注(美术标注员对意图满足度、生态合理性、物理可行性、事实性幻觉、回应智能程度打分),用来校验自动验证器:生态合理性的 Cohen's κ = 0.54(原始一致率 93.6%),意图满足度的 κ = 0.53(原始一致率 78.0%),整体逐条一致率 83.4%,系统级相关性 Spearman's ρ = 0.88——也就是说,自动验证器在判断"哪个系统更优"这一系统级排序上相当可靠,尽管按标准 κ 解读,其与人工在单条个案上的一致性只能算"中等"。

基线涵盖三类:零样本前沿 MLLM(闭源——GPT-5.5、Gemini 3.5-flash、Gemini 3.1-pro、Claude-Opus-4.8、Kimi-K3、Qwen3.8-Max;开源基座模型——Qwen3-VL-8B 与 Qwen3-VL-30B-A3B)、基于 GPT-5.5 骨干的免训练智能体脚手架基线(SceneWeaver、SAGE、SceneAssistant),以及论文自己的 VibeWorlder-8B 和 VibeWorlder-30B-A3B(各自包含仅 SFT 版本和强化学习版本)。总体 Pass@1 头条结果:基座 Qwen3-VL-8B 为 5.3%,基座 Qwen3-VL-30B-A3B 为 13.6%;VibeWorlder-8B-SFT 为 12.0%,经强化学习后的 VibeWorlder-8B 升至 41.4%(已验证 59.3% / 未验证 33.3%),与 Gemini-3.1-pro 的 42.7% 相当;VibeWorlder-30B-A3B-SFT 为 34.5%,经强化学习后的 VibeWorlder-30B-A3B 升至 59.3%(已验证 64.5% / 未验证 55.4%),超过 GPT-5.5(57.3%)和 Qwen3.8-Max(56.9%);即便是对比中表现最强的前沿模型 Gemini 3.5-flash,总体也只有 47.4%,支持了论文"当前前沿 MLLM 距离解决 vibe worlding 智能体任务还很远"的论断。

按能力维度拆分(论文图 5)显示:碰撞无关性(collision-freeness)是所有模型即便在强化学习之后依然最弱的维度(59%-68%);高度合理性同样偏弱;生态合理性在强化学习后相对较强(80%-94%);3D 理解经强化学习从约 90% 提升到 98%;3D 推理经强化学习提升幅度最为显著(强化学习前约 20%-66%,强化学习后 56%-85%);检索合理性经强化学习提升到 91%-99%——在这一维度上超过了若干前沿模型。论文据此得出结论:主要瓶颈在于精确的、无碰撞的 3D 距离编辑,而非场景理解或检索。针对 VibeWorlder-8B 的训练动态消融显示,SFT 和强化学习在不同能力维度上各有分工:单独的冷启动 SFT 就能建立起物理可行性(约 0.6)和生态合理性(约 0.9),但对 3D 理解只有轻微提升(0.02→0.17),对 3D 推理几乎没有推动(约 0.04);随后的多模态强化学习阶段则把 3D 理解推高到约 0.80、3D 推理推高到约 0.69,而物理/生态得分保持平稳;一项去掉冷启动的消融(直接在基座骨干上做强化学习)表现明显更差,支持了 SFT 是必要基础而非可选热身步骤这一结论。

# Q9 主要贡献

1. VWE-Bench——据论文自述是第一个在现实尺度上(2,616 个资产、323 个种子世界、6,828 条查询)统一 3D 世界构建与细化查询的基准,带有已验证/未验证划分,查询类型覆盖从信息不全的主题描述到完整规格的蓝图,再到刻意设计的不可行干扰项。
2. VibeWorlding-Gym——一个把五个 3D 工具暴露为 MCP 工具的沙箱,配合一个双约束验证器(先做确定性物理可行性检查,再做 MLLM 规则表评判),该验证器同时承担公平评测协议和强化学习奖励服务两项职责。
3. VibeWorlder-8B 与 VibeWorlder-30B-A3B——通过冷启动 SFT 加联合多模态、纯基于结果的 GRPO 强化学习训练出的开源模型,从作为基座模型时的 5%-14% Pass@1,提升到在新基准上匹配甚至超过多个前沿闭源 MLLM(GPT-5.5、Qwen3.8-Max)。
4. 一项分维度能力分析和训练动态消融,显示 SFT 与强化学习在互补的能力维度上各有专长(SFT:物理/生态层面的落地;强化学习:3D 理解与推理),并确定精确的、无碰撞的 3D 空间编辑(而非场景理解或资产检索)是仍然存在的主要瓶颈。

# Q10 下一步

* 本笔记无法仅从检索到的材料解答的问题:考虑到验证器与人工在逐条个案上的一致性只是中等水平(κ≈0.5),尽管系统级相关性很强(ρ=0.88),强化学习训练实际上能够容忍多大程度的奖励噪声——论文在系统级别校验了其验证器,但没有直接分析逐条奖励噪声对其报告的强化学习训练动态的影响;论文自陈的卡通美术风格资产库这一局限,是否能推广到照片级真实感或其他视觉风格,论文列出了这一局限但未做测试。
* 论文自己陈述的未来方向:在当前原子级工具操作之上叠加更高层级、可复用的 3D 构建"技能"(例如"实例化一个足球场""散布森林资产");把世界复杂度扩展到超过当前每世界 258 个资产的上限,可能借助智能体群的子任务分解;为多模态强化学习设计更高效的信用分配机制(例如直接的逐轮碰撞提示),而非纯粹基于结果的稀疏奖励;以及把当前的卡通美术风格和文本/图像查询模态,拓展到 image-to-3D 和 video-to-3D 等设置。
* **与本仓库的关联**:VibeWorlding-Gym 的沙箱加双验证器加奖励服务的设计,是本知识库 [Agent environments](../topics/agent-environments.md) 主题已经在追踪的"环境作为工程化控制面"这一模式的一个领域专用实例——但与 EnvHarness 针对*已有*环境、围绕一个冻结目标策略展开的诊断-编写-验证循环不同,VibeWorlding-Gym 是针对单一任务领域从零构建的,且其验证器直接被复用为强化学习奖励函数,而不仅仅是一个事后评测器。其基于 GRPO、纯结果驱动的训练方案,也为本知识库 [Agent fine-tuning](../topics/agent-fine-tuning.md) 主题(与 [Agent Lightning](2508.03680.md) 并列)提供了第二个数据点,说明当前智能体强化学习实践在朴素 GRPO 之上实际叠加了多么少的定制化信用分配机制——详见 [GRPO](../concepts/grpo.md)。

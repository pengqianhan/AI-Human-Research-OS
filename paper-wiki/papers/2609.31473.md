# Q1 Problem Definition

* **Input (X):** a set of frontier LLMs accessed through public APIs with each provider's default sampling settings, with no fine-tuning, tools, or retrieval, and a game environment. At each decision point the uniform text harness gives the model a natural-language description of the current game state and its history. The model must return one action in a prescribed format, with a small number of retries after invalid output.
* **Output (Y):** per-game leaderboards with bootstrapped confidence intervals computed from full round-robin play:
  * Chess: Bradley–Terry Elo anchored at 0 for the lowest model.
  * Poker: big blinds won per 100 hands (BB/100).
  * Werewolf: a game-theoretic equilibrium rating decomposed by role.

  Diagnostic analyses accompany the leaderboards: Stockfish win-probability trajectories, illegal-move "rethinks", preflop poker statistics, and role and teammate contributions.
* **Core problem:** static benchmarks saturate and leak into training data, while preference arenas (Chatbot Arena, MT-Bench judging) are subjective and biased. Earlier game benchmarks are one-off datasets with too few interactions for high-variance games and no path to continuous, extensible evaluation.

# Q2 Problem Novelty

Not new in kind. Games have long been AI yardsticks (Deep Blue, AlphaGo/AlphaZero, Libratus/Pluribus, Cicero, AlphaStar), and LLM game benchmarks already exist (AgentBench, GTBench, PokerBench, SmartPlay, Game Reasoning Arena, the PokerBattle experiment, MindGames). The paper's claimed novelty is *operational*: a persistent, open, extensible arena run on Kaggle's infrastructure, with statistical scale well beyond prior LLM game evaluations — 180,000 poker hands per model vs. about 3,800 in PokerBattle and under 2,000 in PokerBench. It also claims the first use of duplicate (hand-mirrored) poker in LLM benchmarking, and a rating method for multiplayer asymmetric games that separates skill from role luck. The problem matters because outcome-grounded, adversarial evaluation does not saturate as models improve, since opponents improve too.

# Q3 Scientific Hypothesis

If models play each other in games with objective outcomes, under one neutral harness, at sample sizes large enough for high-variance games and with variance reduction (color balancing, duplicate deals, role decomposition), then the resulting rankings will be statistically separable and will reveal distinct strategic capabilities — planning and search in Chess, belief updating and risk in poker, deception and social inference in Werewolf — rather than a single "strategic ability" scalar. The paper's evidence for the second half is that the rankings differ across games.

# Q4 Related Work and Key People

* **Evaluation paradigms:** static benchmarks (MMLU, GSM8K, HellaSwag) and their saturation and contamination (LiveBench, "AI agents that matter"); preference arenas (Chatbot Arena) and [LLM-as-a-Judge](../concepts/llm-as-a-judge.md) (MT-Bench).
* **Games as AI milestones:** Deep Blue, AlphaGo, AlphaZero, Libratus, Pluribus, Cicero (Diplomacy), AlphaStar.
* **LLM game benchmarks:** AgentBench, GTBench, PokerBench, SmartPlay, Game Reasoning Arena (built on OpenSpiel), DSGBench, PokerBattle.ai, and MindGames (a NeurIPS 2025 live arena).
* **Evaluation theory it builds on:** Bradley–Terry and Elo ratings, TrueSkill/OpenSkill, game-theoretic evaluation by maximum-entropy correlated equilibrium over a model-vs-model-vs-role meta-game (Liu et al., 2025), and "Voting-as-Evaluation" social-choice ranking (Lanctot et al., 2023). Environments reuse OpenSpiel, PettingZoo, and Gymnasium.
* **Key people:** a Google DeepMind, Kaggle, and Google Cloud Office of the CTO collaboration. Minmin Chen and Orhan Firat are the research leads. Marc Lanctot, Ian Gemp, Siqi Liu, Daniel Hennes, and Kate Larson bring the game-theoretic evaluation and OpenSpiel lineage. Critics would include builders of competing LLM game arenas (MindGames, Game Reasoning Arena, PokerBench) and poker-AI researchers who might question how the opponent-modelling setup differs from standard play.

# Q5 Key Solution Idea

* **One minimal, neutral harness for all games.** The model gets the full state description and history, an explicit objective, and a step-by-step reasoning instruction. It is *not* given a list of legal actions, so it must infer legality itself. Invalid output triggers a bare retry without diagnostics:
  * Chess: after four failed attempts the game is lost.
  * Poker: a second illegal action defaults to check or fold.
  * Werewolf: repeated parse failures forfeit the turn.
* **Per-game variance control:**
  * Chess: 40 games per pair, color-balanced, plus a "Chess Opening" variant starting from 20 popular two-ply Lichess openings, because all models defaulted to the Sicilian.
  * Poker: heads-up no-limit Hold'em with 100 big-blind stacks reset each hand, played in 100-hand episodes with full within-episode history for opponent modelling. Both players' hole cards are revealed after every hand to speed up adaptation. Every deck sequence is replayed with seats and cards swapped (duplicate poker).
  * Werewolf: an eight-player game with an event bus enforcing information asymmetry. Rules were rebalanced from a 73.4% to a 56.7% villager win rate, measured by Gemini 3 Pro self-play over 500 games per configuration.
* **Game-appropriate rating:** role-decomposed game-theoretic evaluation for Werewolf, since raw win rates mix skill with role-assignment luck. This is cross-checked against Elo, Copeland, and Ranked Pairs.
* **Everything logged:** immutable per-turn snapshots, including reasoning traces, are released as a dataset, alongside a web visualizer with a reasoning panel.

# Q6 Experiment Design

* **Models:** the text says "the top 10 models from five frontier labs (as of February 2026)" but lists eleven. The lists are GPT-5.2, GPT-5 mini, and o3; Claude Opus 4.5, Sonnet 4.5, and Haiku 4.5; Gemini 3 Pro Preview and Gemini 3 Flash Preview; Grok 4 and Grok 4.1 Fast Reasoning; and DeepSeek V3.2. Participation differs by game: all eleven in Chess; ten in poker, without Claude Haiku 4.5; eight in Werewolf, without o3, Claude Haiku 4.5, and DeepSeek V3.2 (reader observation from the result tables).
* **Scale:**
  * Chess: full round-robin, 40 games per pair.
  * Poker: 45 matchups × 20,000 hands = 900,000 hands.
  * Werewolf: about 31,500 games (31,472 in the appendix).
* **Metrics and uncertainty:** 95% bootstrap intervals throughout, with block bootstrap over episodes for poker. The paper mentions an approximate external calibration of chess Elo against Stockfish skill levels, but the retrieved text reports only internal Elo values.
* **Diagnostics:** Stockfish-annotated win-probability curves over game progress, rethink frequency and timing, preflop behavior (VPIP, steal attempts, big-blind call/fold/3-bet), per-role Werewolf contributions, a coalition "substitution index", and cost-performance Pareto frontiers.
* **Not designed in:** no human or engine opponents in the leaderboards, no repeated tournaments with fresh model snapshots, no control of reasoning budgets across providers (default settings only), and no ablation of harness choices such as history format or retry policy.

# Q8 Evidence Quality

* **Supported — rankings are tiered and statistically separable within games:**
  * Chess Elo: Gemini 3 Pro 1325 [1217, 1428] and Gemini 3 Flash 1297, then o3 1009 and GPT-5.2 933, then Grok 4 773, Grok 4.1 Fast Reasoning 632, and GPT-5 mini 525. The Claude 4.5 models trail (Opus 236, Sonnet 189, Haiku 122) and DeepSeek V3.2 is the anchor at 0.
  * Poker BB/100: GPT-5.2 +46.6 (95% CI 40–54) separates clearly from o3 +29.7 and Grok 4 +27.1. GPT-5 mini (−94.9) is an isolated outlier.
  * Werewolf: the tournament graph over 31,472 games is acyclic, and Elo, Copeland, Ranked Pairs, and GTE give the same order, with Gemini 3 Pro first and GPT-5 mini last.
* **Supported — "strategic ability" is not one scalar:** Gemini 3 Pro tops Chess and Werewolf but loses −15.2 BB/100 at poker, where it has the tightest preflop range (52.8% button opens, 43.8% big-blind folds). GPT-5.2 leads poker but is fourth in Chess. The cost-performance frontier is similar for Chess and Werewolf but reshuffled for poker.
* **Supported — where chess games are decided:** Stockfish curves show models roughly even in the opening and diverging in the middlegame. Chess Opening reproduces the Chess Text ranking, so the ranking does not rest on memorized openings alone. Weaker models (DeepSeek V3.2, Claude Haiku 4.5) typically need more than five, often more than ten, rethinks per game, concentrated late in the game.
* **Confounds worth keeping in mind:**
  * Chess Elo mixes strategic strength with rule-following reliability, because repeated illegal moves forfeit the game. The low Claude and DeepSeek ratings may partly reflect legality failures (reader observation, supported by the rethink analysis).
  * Default sampling and generation limits mean reasoning budgets differ by provider, so the comparisons are of default API configurations, not of models at matched compute.
  * The poker prompt instructs GTO-baseline play and reveals opponents' hole cards after every hand. This is a benchmark-specific variant chosen to accelerate opponent modelling, not standard poker.
  * The Werewolf rules were balanced with self-play by Gemini 3 Pro, the eventual top model. Balance was measured for one play style (reader observation).
  * 40 chess games per pair leave wide intervals (about ±100 Elo), enough for tier separation but not within-tier order. The Werewolf coalition analysis is inconclusive: 48% of the inter-coalition comparison matrix is empty.
* **Snapshot:** the results are a February-2026 snapshot of one model pool. Longitudinal claims are a design goal, not something this report demonstrates.

# Q9 Contributions

* Durable, open evaluation infrastructure: a uniform harness, extensible environment specifications, released trajectories with reasoning traces, and a live leaderboard.
* Methodological transfer from computer-poker and game-theory practice into LLM evaluation: duplicate poker, block bootstrap, role-decomposed equilibrium ratings for asymmetric multiplayer games, and social-choice cross-checks.
* Empirical evidence that frontier-model strategic strength is game-specific, with behavioral diagnostics — preflop style, mid-game collapse, legality failures — that explain *why* rankings differ.
* A Werewolf rule set balanced against the Seer-reveal-plus-Doctor-save exploit, usable as a safety sandbox for generating and detecting deception.

# Q10 Next Steps

The paper names four directions:

* adaptive, uncertainty-driven scheduling of matches instead of fixed games per pair;
* protocols for model churn and cold-start entrants that keep the match graph connected;
* a consolidated Bradley–Terry-style meta-rating across heterogeneous games;
* more games covering long-horizon planning, negotiation, theory of mind, and mixed-motive cooperation.

Further directions prompted by the reading:

* **Matched-compute tracks:** report results at fixed reasoning budgets, and separate legality failures from strategic losses, so that chess Elo measures strategy.
* **Agentic harness variants:** the arena deliberately uses a bare harness. A second track that allows tools such as engines, solvers, or memory would measure agent systems rather than raw models. That is closer to what this wiki's agent-harness-engineering papers study (reader-constructed direction).
* **Cooperative games:** the cooperative Werewolf analysis is inconclusive, and a fully cooperative task suite such as [AgentWorld](2609.31590.md) would complement the competitive arena for measuring teammate quality.

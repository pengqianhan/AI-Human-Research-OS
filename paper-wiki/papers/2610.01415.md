# Q1 Problem Definition

* **Input (X):** a task goal G, an initial observation o₀, an environment the agent acts in step by step (text actions, MCP tool calls, diagnostic tool calls, or questions to a simulated patient), and an action budget T.
* **Output (Y):** a sequence of actions ending in task completion or a final submission (a root-cause entity and fault type, or a diagnosis), chosen from an explicit belief B_t rather than from the raw history.
* **Core problem:** in long tasks, actions change the world and new observations invalidate earlier inferences. Raw trajectories keep everything in order; memory methods select, compress, or reorganize it. Neither gives the agent an explicit, checkable estimate of the *current* world. The authors add two requirements for an LLM-written belief: it must stay internally consistent and supported by evidence, and the agent must notice when it keeps acting without progress, which they call **Belief Trapping** (repeating ineffective actions, cycling through visited states, or gathering information that does not help).
* **Formal framing:** a POMDP in which the belief b_t(s) = P(s_t = s | h_t) would be a sufficient statistic. PoS approximates it with a structured, task-conditioned belief B_t = (W_t, G, Δᴱ_t, Δᴬ_t): a world state, the goal, epistemic gaps (what is still unknown), and achievement gaps (what still has to be done).

# Q2 Problem Novelty

Partly new. Representing agent state explicitly has precedents: QuBE builds a belief through question answering, StateAct keeps a chain of states, ReflAct reflects on the state relative to the goal, Tru-POMDP keeps particle beliefs over hypotheses, Graph of States (the same first author) couples a belief with a causal graph and state machine for abductive tasks, and [LongHorizon-Harness](2608.01964.md) keeps an audited task state. On stalled progress, T3 detects belief deviation and truncates trajectories during RL training, and CGDP stops unproductive context gathering with an exhaustion gate. The paper's claim is the combination: a belief that is validated every step *and* monitored for trapping, with recovery during the episode rather than truncation or termination.

# Q3 Scientific Hypothesis

If the agent decides from an explicit belief that separates the current world state from what remains to be learned and done, and that belief is (a) checked for internal and evidential consistency before it is committed and (b) monitored so that stalled progress triggers recovery tailored to how and where the agent is stuck, then long-horizon success should rise across both execution tasks and diagnosis tasks, and stay stable as the context grows, beyond what keeping, compressing, or reorganizing history achieves.

# Q4 Related Work and Key People

* **Memory as context:** ReAct (raw trajectory); compression (ReadAgent, ACON, SUPO); structured retention (HiAgent's subgoal memory, COMPASS progress briefs, PACE's relevance-graded history); agent-controlled context (MemGPT, CaT, AgentFold, Sculptor).
* **Belief as context:** probing studies of world-state representations in LLMs; QuBE, StateAct, ReflAct, Tru-POMDP, natural-language belief summaries, Graph of States, and [LongHorizon-Harness](2608.01964.md), which the paper argues needs independently verifiable intermediate results and so suits diagnosis less.
* **Stalled progress:** T3 (truncation in RL) and CGDP (an exhaustion gate in a POMDP framing of agentic search).
* **Benchmarks:** ALFWorld, LOCA-Bench, RCA-100, ClinDiag.
* **Key people:** Nankai University (Yu Luo, Jiamin Jiang, Yimin Zuo, Rongchen Gao, Yongqian Sun, Shenglin Zhang; Yongqian Sun is marked with an asterisk), Alibaba Group (Xidao Wen, Guiyang Liu, Cheng Zhang, Fang Situ, Qi Zhou), and Dan Pei (Tsinghua University). The work was done during an internship at Alibaba. Several authors also wrote RCA-100 (Cai et al., 2026), one of the four benchmarks, and Graph of States.

# Q5 Key Solution Idea

* **Belief modeling.** The world state W_t is an Entity–State–Relation structure: entities are objects or agents, states are natural-language descriptions of an entity's current condition, and directed relations link entities and states. Each state and relation carries provenance, confidence, and supporting evidence when available. Only records that affect action feasibility, outcome assessment, or the goal are kept.
* **Active gap.** From all open gaps, PoS selects one active gap Δ_t as the current focus and keeps it until resolved. The action is drawn as a_t ~ π(· | B_t, Δ_t, C_t), where C_t is a recovery constraint that is empty during normal operation.
* **Belief Sentinel.** After each observation the task agent writes a candidate belief; the Sentinel audits new or changed entities, states, relations, and gaps for internal contradictions (for example a microwave recorded as both open and closed) and external ones (contradicting the latest observation), and the task agent revises before committing. Local audits run every step; global audits every 8 steps (every 32 on LOCA-Bench).
* **Belief health.** Each validated transition gets a progress label: for diagnosis, whether the total confidence change exceeds ε = 0.30; for execution, the Sentinel's judgment of whether the active gap moved. Over a window of K = 8 transitions, PoS computes gap persistence P_X (the share of gaps of type X unresolved throughout), progress stagnation S_t, and belief recurrence R_t (how often the gap-relevant world state repeats, by Jaccard distance, over lags up to 4). Health is H_t = 1 − max_X [P_X · max(S_t, R_t)], and trapping is declared when H_t ≤ 0.25. Persistence alone cannot trigger it: an open gap with steady progress keeps health at 1 (Appendix B.3 contrasts this with geometric-mean and max aggregations).
* **Factorized diagnosis and recovery.** The dynamics are classified, in order, as Static (world state unchanged), Cycle (periodic recurrence), or Drift (the world changes but not the part relevant to the active gap), and the blocked gap type is whichever of epistemic or achievement persists more. The recovery constraint combines a pattern constraint (suppress the ineffective transition, break the cycle, or re-anchor to the active gap) with a gap constraint (seek discriminative evidence, or make a task-relevant state change). It is released once health rises above the threshold.

# Q6 Experiment Design

* **Benchmarks:** ALFWorld valid_unseen (134 tasks, 50 actions), LOCA-Bench (15 seed tasks × 7 context lengths from 8K to 256K × 5 environment seeds = 525 cases, 100 MCP calls), RCA-100 (all 103 microservice-incident cases, scored on fault triage, root-cause localization, and both jointly; 50 turns and at most 150 tool calls), and ClinDiag (302 Common plus 302 Rare cases, 30 questions; the access-controlled Emergency subset is excluded).
* **Backbones:** Qwen3.7-Plus, Kimi-K3, and GLM-5.3 through the DashScope API, temperature 0. Every LLM component of PoS and of the baselines uses the evaluated backbone; ClinDiag's simulated patient and judge are fixed to Qwen3.7-Plus.
* **Baselines:** Raw Trajectory, ACON, PACE, and HiAgent inside one ReAct harness, and LongHorizon-Harness with its native Manage-Execute-Audit loop. ACON keeps runtime compression but drops its guideline optimization and distillation (no training splits); PACE was reimplemented from the paper because its repository was inaccessible, with a different embedding model; HiAgent was ported from AgentBoard.
* **Analyses:** ablations removing consistency validation or trapping diagnosis; trapping incidence and pattern distributions; factorized versus generic recovery prompts; token cost on RCA-100; success against context length on LOCA-Bench; one RCA-100 case study.

# Q8 Evidence Quality

* **Supported:**
  * *Consistent wins in the main table.* PoS has the best overall score in all 12 benchmark-backbone cells. Against the strongest baseline per backbone, the largest relative gains are 22.68% on ALFWorld (Qwen3.7-Plus: 88.81 vs. LongHorizon-Harness 72.39), 7.53% on LOCA-Bench (GLM-5.3: 70.86 vs. ACON 65.90), 37.89% on RCA-100 joint accuracy (Qwen3.7-Plus: 38.83 vs. 28.16), and 11.31% on ClinDiag (GLM-5.3: 52.15 vs. Raw Trajectory 46.85). With Kimi-K3, RCA-100 joint rises to 51.46 against the best baseline's 41.75.
  * *Baselines are not uniformly better than raw history.* PACE falls 24.57-28.19 points below Raw Trajectory on LOCA-Bench, and on ClinDiag with GLM-5.3 no memory baseline beats it. LongHorizon-Harness is the strongest baseline on ALFWorld and on LOCA-Bench with Qwen3.7-Plus but trails on RCA-100, consistent with the paper's point that its audit needs verifiable intermediate artifacts.
  * *Both mechanisms matter.* Removing consistency validation costs up to 14.93 points on ALFWorld and 11.81 on LOCA-Bench but only 0.33-0.66 on ClinDiag; removing trapping diagnosis costs 4.85-6.79 points on RCA-100 and 2.65-3.97 on ClinDiag. On RCA-100, dropping validation mainly hurts fault triage (−6.80 with Qwen3.7-Plus) while dropping recovery mainly hurts localization (−3.88 to −4.85).
  * *Context growth.* On LOCA-Bench PoS stays broadly stable from 96K to 256K and leads the strongest baseline by 10.67-16.00 points at 256K.
* **Weaker or bounded:**
  * *Cost is not matched.* On RCA-100 with Qwen3.7-Plus, PoS uses 1,800K tokens per episode against 356K for Raw Trajectory (5.06×), with the Sentinel (822K) and belief maintenance (697K) each costing more than the task agent (281K). Budgets are matched in environment actions only; no baseline is given comparable extra inference (for example sampling or self-verification) to test whether the gain comes from belief structure or from more computation (reader note). Token cost is reported only for RCA-100.
  * *Without its validator, PoS often loses to the best baseline (reader note from Table 1).* The no-validation variant falls below the strongest baseline on LOCA-Bench with all three backbones (for example 44.57 vs. 52.57 with Qwen3.7-Plus) and on ALFWorld with GLM-5.3. On the execution benchmarks the advantage over the strongest baseline therefore depends on validation; the explicit belief alone does not deliver it there. On RCA-100 the no-validation variant still beats every baseline.
  * *Single deterministic runs, small margins in some cells.* There is one temperature-0 run per cell and no variance. One ALFWorld task is 0.75 points and one RCA-100 case 0.97 points, so the Kimi-K3 and GLM-5.3 ALFWorld margins over LongHorizon-Harness (2.24 and 1.49 points) are 2-3 tasks. The large Qwen3.7-Plus and RCA-100 gaps are much bigger than this granularity.
  * *Baseline adaptations.* ACON runs without its learned guidelines and PACE is a reimplementation with a different encoder, which may weaken them; PACE's collapse on LOCA-Bench could partly reflect this (reader note).
  * *The RCA-100 lead is in fault type, not location (reader note from Table 9).* With Qwen3.7-Plus, PoS localizes the root-cause entity less often (67.96) than Raw Trajectory (68.93), HiAgent (76.70), or LongHorizon-Harness (75.73); its joint-accuracy lead comes from fault triage (39.81 vs. at most 33.01).
  * *Factorized versus generic recovery* is shown only in a figure with Qwen3.7-Plus; the text reports no numbers.
  * *Author-built benchmark.* RCA-100 comes from overlapping authors; the paper does not say whether PoS was developed on it.

# Q9 Contributions

* Names and operationalizes **Belief Trapping** with three belief-level signals (gap persistence, stagnation, recurrence) combined so that an open gap alone does not count as stalling.
* A structured, task-conditioned belief (world state plus epistemic and achievement gaps) with an active gap and a per-step consistency audit.
* Factorized recovery that composes a dynamics-specific escape constraint (Static, Cycle, Drift) with a gap-specific progress constraint.
* A cross-domain comparison of context-management baselines under one interface, showing that memory compression and structuring do not reliably beat raw history with current long-context models.

# Q10 Next Steps

* **The authors' plan:** reduce the token cost of natural-language beliefs, for example with compact latent world-state representations, and add domain-knowledge retrieval to belief updates, since many ClinDiag errors come after the agent has the right information but lacks the medical knowledge to interpret it.
* **A compute-matched control (reader note):** give the ReAct baseline the same token budget as PoS (self-consistency, a reviewer pass, or a second attempt) to separate the value of the belief structure from extra inference.
* **Validator cost (reader note):** the Sentinel is the single largest cost. Test whether a cheaper model or a less frequent audit keeps the execution-task gains, since validation is what lifts PoS above the best baseline there.
* **Combine with an auditor (reader note):** PoS validates beliefs against evidence it already has, while [LongHorizon-Harness](2608.01964.md) verifies against the environment. A hybrid that uses environment audits where artifacts are checkable and belief validation where progress is inferential would test the paper's own explanation of where each wins.
* **Relevance to this repository (reader note):** the epistemic/achievement gap split and the "persistent gap plus stagnation or recurrence" stall rule are cheap to apply to long agent runs here, for example as a check in a session handoff: list what is still unknown and what is still undone, and flag a run whose open items have not changed over several steps.

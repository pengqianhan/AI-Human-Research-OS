* [Recursive Language Models](2512.24601.md) - Treats a long prompt as a REPL variable the model inspects, decomposes, and recursively sub-queries, handling 10M+ token inputs with a fixed-window model.
* [SkillFoundry: Building Self-Evolving Agent Skill Libraries from Heterogeneous Scientific Resources](2604.03964.md) - A self-evolving framework that mines heterogeneous scientific resources into validated, reusable agent skill packages and improves coding/scientific agents on MoSciBench and genomics tasks.

* [ScientistOne: Towards Human-Level Autonomous Research via Chain-of-Evidence](2605.26340.md) - Introduces Chain-of-Evidence, ScientistOne, and a four-part integrity audit for tracing autonomous-research claims to literature, code, and evaluator outputs.
* [AutoScientists: Self-Organizing Agent Teams for Long-Running Scientific Experimentation](2605.28655.md) - A paper about decentralized AI agent teams for long-running scientific experimentation.
* [COLLEAGUE.SKILL: Automated AI Skill Generation via Expert Knowledge Distillation](2605.31264.md) - An open-source pipeline that distills heterogeneous human traces into versioned, inspectable, correctable agent-skill packages across colleague, celebrity, and relationship presets.
* [GPU Forecasters: Language Models as Selective Surrogates for Kernel Runtime Optimization](2605.31464.md) - A paper about using LLMs as selective surrogate evaluators that forecast GPU kernel performance to accelerate kernel search.
* [OpenSkill: Open-World Self-Evolution for LLM Agents](2606.06741.md) - A paper about agents that build skills and verification signals from open-world resources without target-task supervision.
* [Decentralized Multi-Agent Systems with Shared Context](2606.10662.md) - A paper about decentralized language-model agents coordinating through shared verified context.
* [Toward Generalist Autonomous Research via Hypothesis-Tree Refinement](2606.11926.md) - A paper introducing Arbor, an autonomous research framework that uses persistent hypothesis-tree refinement to organize long-horizon artifact optimization.
* [EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery](2606.13662.md) - A paper about environment-engineered CLI-agent systems for metric-driven autonomous scientific discovery.
* [SkillOpt-Lite: Better and Faster Agent Self-evolution via One Line of Vibe](2607.03451.md) - Reduces skill evolution to file-based trajectory exploration, consensus mining, minimal edits, and independent validation, then extends the loop to harness code.
* [ResearchStudio-Idea: An Evidence-Grounded Research-Ideation Skill Suite from ML Conference Outcomes](2607.04439.md) - Mines ML conference outcomes into failure-aware ideation patterns and operationalizes them as literature-search, prior-art-checking, and end-to-end ideation skills.
* [Self-Improvements in Modern Agentic Systems: A Survey](2607.13104.md) - Unifies self-improving agents as slow foundation-model updates or fast scaffold updates driven by execution-derived signals, with evaluation treated as a longitudinal control problem.
* [Harness Handbook: Making Evolving Agent Harnesses Readable, Navigable, and Editable](2607.13285.md) - A behavior-centric, source-linked handbook and progressive-disclosure workflow for localizing changes in evolving agent harnesses.
* [MemoHarness: Agent Harnesses That Learn from Experience](2607.14159.md) - Searches six harness control surfaces, distils execution diagnoses into an experience bank, and retrieves that experience for label-free per-case adaptation.
* [AI Agents Do Not Fail Alone: The Context Fails First](2607.14275.md) - Validates a seven-criterion context-quality score as a preflight signal for agent reliability under controlled context variation.
* [SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration](2607.15257.md) - Externalizes relational coverage, grounded evidence, frontier tasks, and search failures into shared state governed by continuous scheduling and middleware.
* [LLM-as-a-Coach: Experiential Learning for Non-Verifiable Tasks](2607.18110.md) - Replaces rubric-based RL's scalar reward with coach-extracted experiential knowledge internalized by on-policy context distillation, improving transfer and reducing reward overoptimization.
* [MatrAIx: Simulating the World with 8.3 Billion Persona Agents](2608.04205.md) - A population-scale simulated-user infrastructure that pairs an 8.3-billion-record persona dataset with four interaction environments and 1,010 application tasks to evaluate AI systems and digital products across heterogeneous user cohorts.
* [LongHorizon-Harness: Advancing Long-Horizon Agents for Real-World Tasks](2608.01964.md) - A Manage-Execute-Audit harness that externalizes task state outside the growing execution context and updates it only from independently verified environment facts, improving Qwen 3.7-Plus and Claude Opus 4.7 across WeaveBench, OSWorld 2.0, and Terminal-Bench 2.1.
* [SkillOpt: Executive Strategy for Self-Evolving Agent Skills](2605.23904.md) - A text-space optimizer that treats an agent's skill document as trainable state, with bounded textual learning rates, held-out validation gating, and epoch-wise slow/meta updates, best-or-tied on 52 of 52 (model, benchmark, harness) cells.
* [Spark-to-Paper: End-to-End Research Paper Generation as a Composable Skill](2608.11924.md) - An end-to-end research-paper generation system implemented as thirteen composable coding-assistant skills that separates experiment planning from reporting and bounds a Self-Refutation Loop failure mode.
* [OpenHands (f.k.a. OpenDevin): An Open Platform for AI Software Developers as Generalist Agents](2407.16741.md) - An open-source agent platform with an event-stream protocol, a sandboxed bash/IPython/browser runtime, an extensible skills library, and multi-agent delegation, letting one generalist agent stay competitive across software-engineering, web-browsing, and miscellaneous-assistance benchmarks.
* [Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory](2504.19413.md) - An incremental extraction/update memory pipeline, plus a graph-structured variant, that beats a six-category baseline sweep on LOCOMO while cutting p95 latency by 91% versus full-context processing.
* [HarnessEval-W: Agentifying the Evaluation of Visual Worlds](2608.16859.md) - An agentified evaluation pipeline where a parent agent and specialized sub-agents decompose world-model rollout judging into an auditable evidence tree, reaching 0.93 Spearman correlation with human preference.
* [LLM-as-a-Verifier: A General-Purpose Verification Framework](2607.05391.md) - A training-free verifier that computes continuous rewards from scoring-token logit expectations, scaling along granularity, repeated evaluation, and criteria decomposition to reach state of the art on Terminal-Bench V2, SWE-Bench Verified, RoboRewardBench, and MedAgentBench.
* [StateM: Reaching 95.3% Raw Accuracy, or a $15 Frontier Run, on Terminal-Bench 2.1 via Harness Scaling](2608.15089.md) - An agent-native YAML+CLI runbook that externalizes durable execution state for long-horizon CLI agents, closing a model-generation-sized capability gap and studying transfer across model generations, providers, and task families.
* [UI-Mate: Advancing Open-Weight Foundation GUI Agents with In-Context Demonstrations](2608.15930.md) - An open-weight foundation GUI agent combining environment-grounded training with DemoCUA, which turns multimodal demonstrations into adaptive subtask-level workflows, evaluated on the new OSWorkerBench long-horizon office benchmark.
* [MemOS: A Memory OS for AI System](2507.03724.md) - An OS-inspired architecture that unifies plaintext, activation, and parameter memory into a schedulable MemCube unit, outperforming Mem0, Zep, MIRIX, Memobase, MemU, and Supermemory across LoCoMo, LongMemEval, PreFEval, and PersonaMem.
* [ARIS: Autonomous Research via Adversarial Multi-Agent Collaboration](2605.03042.md) - An open-source research harness pairing a cross-model executor and reviewer under a three-stage evidence-to-claim audit cascade, with 65+ Markdown skills and a rejected-idea-preserving research wiki, to catch plausible-but-unsupported claims in autonomous ML research.
* [Agentic ESOpt: Fine-Tuning Long-Horizon LLM Agents with Minimal GPU Requirements](2608.17310.md) - A full-parameter evolution-strategies fine-tuning method for long-horizon LLM agents at inference-level GPU memory, reported to widen its advantage over GRPO/PPO as task horizon and model size grow.
* [AgentScope 1.0: A Developer-Centric Framework for Building Agentic Applications](2508.16279.md) - A ReAct-grounded, developer-centric agent framework unifying model/memory/tool abstractions, real-time steering, state persistence, and multi-agent primitives with built-in agents and production tooling (Evaluation, Studio, Runtime/Sandbox).
* [EnvHarness: Awakening Static Worlds for Agent Learning](2608.19880.md) - A composable plug-in layer that reshapes a static environment's state, rules, and task composition through its own interface, plus EnvRigger, an automated designer that diagnoses a target policy's trajectories to synthesize new components while preserving the original verifier.
* [Zetta ζ: An Efficient Closed-Loop Embodied Harness for Self-Evolving Physical Intelligence](2608.16590.md) - A closed-loop embodied harness that evolves code-based runtime critics and recovery skills online through three timescale-separated loops while the base VLA policy stays frozen, reporting large success-rate gains and an 11.1x inference speedup on LIBERO-Pro and RoboCasa.
* [Securing the AI Agent: A Unified Framework for Multi-Layer Agent Red Teaming](2606.31227.md) - AI-Infra-Guard, a four-layer, four-paradigm open-source red-teaming framework (rule-based infrastructure scanning, LLM-driven MCP/agent-skill auditing, black-box agent red-teaming, and jailbreak evaluation) plus SkillTrustBench, a new agent-skill-trustworthiness benchmark.
* [SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](2608.19799.md) - A 119-task, 98-repository benchmark for repository-level scientific software repair where even the best coding agent scores under 50% pass@1, with a four-mechanism failure taxonomy and a paired ablation on the value of scientific guidance.
* [MAI-UI Technical Report: Real-World Centric Foundation GUI Agents](2512.22047.md) - A 2B-235B foundation GUI agent family adding native agent-user-interaction and MCP-tool-use actions plus a device-cloud collaboration system, reaching new SOTA on GUI grounding and AndroidWorld (76.7%) while cutting cloud calls by over 40%.
* [Very Large-Scale Multi-Agent Simulation in AgentScope](2407.17789.md) - An actor-based distributed mechanism, agent-environment interaction, and heterogeneous population configuration added to AgentScope, demonstrated on simulations of up to 1 million LLM agents.
* [EverMemOS: A Self-Organizing Memory Operating System for Structured Long-Horizon Reasoning](2601.02163.md) - An engram-inspired three-phase memory lifecycle built around a MemCell primitive with time-bounded Foresight, beating Zep and MemOS on LoCoMo and LongMemEval.
* [GenericAgent: A Token-Efficient Self-Evolving LLM Agent via Contextual Information Density Maximization (V1.0)](2604.17091.md) - A self-evolving agent built around context information density maximization, reported to match or beat Claude Code and OpenClaw at a fraction of their token usage.
* [AutoResearchClaw: Self-Reinforcing Autonomous Research with Human-AI Collaboration](2605.20025.md) - A 23-stage multi-agent autonomous-research pipeline combining structured debate, self-healing Pivot/Refine execution, verified-registry result reporting, seven human-in-the-loop intervention modes, and time-decayed cross-run lesson evolution, beating AI Scientist v2 by 54.7% on the new 25-topic ARC-Bench.
* [Zep: A Temporal Knowledge Graph Architecture for Agent Memory](2501.13956.md) - A production memory-layer service built on Graphiti, a bi-temporal knowledge graph engine, reporting state-of-the-art DMR accuracy over MemGPT and up to 18.5% accuracy gains with 90% lower latency on LongMemEval.
* [OpenRath: Session-Centered Runtime State for Agent Systems](2606.19409.md) - A PyTorch-inspired programming model that promotes fragmented agent runtime state into one first-class, branchable, replayable Session value, with an audit-first release protocol scoping claims to deterministic evidence packets.
* [Agent Lightning: Train ANY AI Agents with Reinforcement Learning](2508.03680.md) - Decouples RL training from agent execution via an MDP formulation and transition-based LightningRL, letting unmodified GRPO/PPO/REINFORCE++ fine-tune agents built in LangChain, OpenAI Agents SDK, or AutoGen with near-zero code change.
* [Graph Engineering in the Era of LLM Agents: From Individual Intelligence to System Intelligence](2608.21156.md) - A 35-author survey proposing explicit task, agent-coordination, and runtime-state graphs as the structural foundation for multi-agent "System Intelligence," beyond what single-agent Harness and Loop Engineering can reach.
* [VibeWorlding: Can Multimodal Agents Construct 3D Open Worlds End-to-End?](2608.15265.md) - A benchmark and MCP-tool sandbox for multimodal agents building/refining 3D worlds; GRPO-based multimodal RL post-training pushes open-source VibeWorlder-30B-A3B past GPT-5.5 and Qwen3.8-Max.

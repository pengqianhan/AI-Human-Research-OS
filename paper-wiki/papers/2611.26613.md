# Q1 Problem Definition

* **Input (X):** for each action of a robot-manipulation episode run by a frontier multimodal agent, the global task instruction G, the agent's own local intent g_t for that action, and a bounded window of multi-view frames (before, after, and for gripper closures a short post-grasp lift window), plus the commanded action and its execution status.
* **Output (Y):** an outcome label (achieved, failed, partial, unverifiable), a failure mode for failed actions (Grasp, Alignment, Interference, Effect, Incomplete motion, Choice, or Unresolved), a grasp sub-category for Grasp failures, and a short evidence-bound reason. Aggregated, these labels answer how frontier agents succeed and where they fail in direct robot control.
* **Constraints:** the agent controls the robot "directly": it emits low-level numerical targets (end-effector poses, joint configurations, gripper openings) as structured tool calls, with no high-level skill primitives, zero-shot, without task-specific fine-tuning or demonstrations. Each action is judged against its own local intent, independent of the episode outcome.

# Q2 Problem Novelty

Several reports already show GPT-6 Astra and other frontier models controlling robots through numerical actions and beating VLAs zero-shot (on RoboDojo, RoboMME, RoboLab-120, RoboColiseum, UniVTAC and OpenViTac, GPT-GEAR, Embodied First Exam). All of them evaluate at the episode level. Robot failure-reasoning work (REFLECT, AHA, RoboFAC, ViFailback, FailBench) studies VLA or perturbed-demonstration failures. The new angle is per-action critique of failures that arise naturally in frontier-agent trajectories, made well-posed by having the policy declare a local intent with every action, since manipulation is multimodal and the same motion can be a success or a failure depending on what it was meant to do.

# Q3 Scientific Hypothesis

If the policy states a local sub-goal alongside each action, then a VLM critic can judge each action's outcome and attribute its failure reliably (as measured against human labels), and the resulting action-level labels reveal capabilities and bottlenecks that episode-level success rates hide: in particular, that frontier agents recover from their own local failures in closed loop, and that their remaining failures are physical-precision failures rather than semantic ones.

# Q4 Related Work and Key People

* **Frontier agents as robot policies.** SayCan-style planning over skills and code-as-policies call primitives; recent work instead has frontier multimodal agents emit numerical actions directly. In this wiki, [EmbodiedSWE](2609.27308.md) and Self-Evolving Coding Agents (2609.35432) are the contrasting program-writing route, where the agent writes control code rather than issuing per-step numeric commands (reader comparison).
* **Episode-level evaluations of frontier agents.** GPT-6 Astra reports on all 42 RoboDojo tasks, RoboMME, RoboLab-120, real bimanual desk tasks, and UniVTAC/OpenViTac; cross-model harnesses (RoboColiseum, a physical-arm RoboDojo study); GPT-GEAR; the Embodied First Exam harness.
* **Failure detection and reasoning.** REFLECT, AHA (perturbed demonstrations), RoboFAC, ViFailback, FailBench.
* **Key people.** Yiyang Du and Chenyan Xiong (corresponding; Carnegie Mellon University), Yuxuan Kuang, Qitao Zhao and Zhanqiu Guo (CMU), Yixuan Wang (UIUC), and Yi Xu, Xin Li, Wenbin He and Liu Ren (Bosch Research North America and Bosch Center for AI). Likely critics: VLA and world-action-model groups (the comparison is zero-shot only) and robot-failure-reasoning authors.

# Q5 Key Solution Idea

1. **Intent-grounded trajectories.** Every robot tool call gets a mandatory note parameter holding the local intent; the harness rejects calls without it. For seven benchmarks (LIBERO-MAX, Meta-World+, DexJoCo, RoboWits, RoboTwin 2.0, YAMLab, ContactBench 1.0) the authors collect new GPT-6 Astra episodes; for five (RoboDojo, StationeryBench, Astranomy, UniVTAC, OpenViTac) they ingest released GPT-6 Astra traces in which decision notes and frames were already logged.
2. **Intent-grounded critic.** C(G, g_t, O_t) returns outcome, failure mode and a note. Three protocol rules: contact-aware windows (closures judged on capture and retention, using lift frames), local validity decoupled from episode outcome (a recovered failed grasp is still a failure; a deliberate small probe that meets its intent is achieved), and evidence-bounded attribution against a codebook with boundary rules (for example Grasp when the object is no longer held, Alignment when a held object stays offset). GPT-6 Astra serves as the critic for all analysis labels.
3. **Choice is relative to the stated intent.** A Choice failure means the execution contradicts the object, order or category the intent names; per the codebook, pressing key 7 *as the intent requests* is not Choice even if the task needs key 3. So Choice measures intent-action consistency, not whether the agent picked the right target for the task (reader emphasis, from Appendix A).
4. **Validation and distillation.** A 400-action human-labeled test set (34% achieved, 66% failed), on which ten other critics are compared; then Muse-Glimmer-30B is LoRA-fine-tuned (rank 32, two epochs) on 12,844 GPT-6 Astra-labeled actions sampled one achieved per three failed, with splits separated by episode.

# Q6 Experiment Design

* **Scale.** 12 benchmarks; RoboDojo alone contributes 2,100 episodes and 105,429 actions (reported by five dimensions: Precision, Open, Long-horizon, Generalization, Memory); the six newly collected benchmarks have 9,232 actions across 197 episodes. Episode success ranges from 7% (StationeryBench) and 22% (RoboDojo) to 98% (LIBERO-MAX, Meta-World+).
* **Recovery analysis.** 12,163 failed actions with a failure mode in 1,989 graded episodes; a failure is recovered when a later action verifiably repairs or bypasses its sub-goal (for example a regrasp after which the object rises with the gripper); robustness by episode weighting and first-failure-only; a second independent reading of 24 failures agrees on 21.
* **Zero-shot comparison.** GPT-6 Astra against pi_0.5 and InternW0-Delta without task-specific fine-tuning (Figure 6), extended in the appendix to matched Embodied First Exam tasks against pi_0.5.
* **Critic evaluation.** Accuracy and Cohen's kappa for outcome (400 actions) and failure mode (264 failed actions), Overall Accuracy (both correct), and inference cost; intent-ablation for GPT-6 Astra; a self-preference check (how many human-failed actions each critic calls achieved).
* **Appendix probes.** One DexJoCo task re-run with and without critic feedback; local-intent requirement versus Embodied First Exam runs without it; decision latency.

The design covers each headline claim with a measurement, but the policy, most analysis labels, and the fine-tuned critic's training targets all come from one model, GPT-6 Astra, and human labels exist only for 400 actions.

# Q7 Datasets and Code

The paper releases the 12,844-action training set, the 400-action human-annotated benchmark, and the fine-tuned Muse-Glimmer-30B critic (GitHub cxcscmu/AgentRoboCritic and a project page); the critic's system prompt, user prompt and codebook are reproduced in Appendices B and J. Release contents were not checked here. Five of the twelve benchmarks rely on third-party released traces.

# Q8 Evidence Quality

* **Critic reliability.** On the human set, GPT-6 Astra scores outcome accuracy 79.25% (kappa 0.497), failure-mode accuracy 80.68% (kappa 0.600) and Overall Accuracy 71.25%; Claude Fable 5.2 is close on outcome (78.25%) but lower on failure mode (72.73%). Kappa around 0.5 on outcome is moderate agreement. The stated "exceeds 90%" agreement counts cases where annotators, after re-inspecting disagreements, accepted the critic's label; that is a post hoc adjudication that favors the critic and should not be read as independent accuracy (reader assessment).
* **Intent ablation.** Without g_t, GPT-6 Astra falls to 25.25% outcome and 25.00% failure-mode accuracy, mostly by labeling actions unverifiable. This strongly supports the paper's central methodological claim that action-level critique needs the actor's intent.
* **Self-preference.** GPT-6 Astra is both policy and critic. It calls only 19 of 264 human-failed actions achieved (7.2%), the fewest of all critics, which argues against leniency toward its own failures. It does not test whether Astra mislabels failure *modes* in a self-serving way, and the fine-tuned critic is distilled from Astra's labels, so its 74.24% failure-mode accuracy partly measures agreement with Astra's labeling style (reader assessment).
* **Recovery.** 49.8% of successful episodes contain a failed action; 38.9% of failures are recovered within 10 actions and 57.7% by episode end (60.7% episode-weighted; 76.2% for first failures). By mode: Incomplete motion 68.2%, Grasp 63.7%, Interference 59.1%, Alignment 35.7%, Effect 29.6%. Recovery and episode success correlate across the 12 benchmarks at Pearson r = 0.81 (Spearman 0.86), a 12-point correlation whose weights are uneven: RoboDojo supplies 9,923 of 12,163 failures. Recoveries are identified from local intents and frames; the review procedure does not say who identified them, and the independent re-reading covers 24 cases.
* **Semantic grounding.** Choice is 0.2% of failures and at most 3.3% on any benchmark. Because Choice is defined against the agent's own stated intent, a wrong target chosen in the intent itself is not counted, so "reliable semantic grounding" means the agent does what it says, not that it chooses the right object for the task (reader assessment; the codebook example makes this explicit).
* **Zero-shot superiority.** The comparison with pi_0.5 and InternW0-Delta is zero-shot by design, which is where VLAs are weakest; the main text gives the result only as a figure. GPT-6 Astra takes a median 31.9 s per decision against 0.11 s for pi_0.5 (Appendix H.4), a practical gap the main text does not discuss.
* **Anecdotal probes.** Critic feedback fixing one DexJoCo task is a single case with one control run; the local-intent requirement leaves success unchanged on 76 matched instances (42 of 76 both ways).
* **Reader checks.** Failure-mode accuracies are whole counts of 264 (80.68% = 213/264, 74.24% = 196/264, 32.58% = 86/264), and the 400-action split (34% / 66%) gives 136 / 264, consistent with the tables.

# Q9 Contributions

1. A formulation that makes per-action critique of manipulation well-posed by requiring the acting agent to state a local intent with each action, with a seven-mode failure codebook and contact-aware evidence windows.
2. A large action-level characterization of one frontier agent on direct robot control across 12 benchmarks: closed-loop recovery, rare intent-action mismatches, and physical bottlenecks that shift with task geometry (Grasp at closure in general tasks, Alignment in vision-only tight-tolerance tasks, Interference in clutter).
3. A 400-action human-labeled critic benchmark, a 12,844-action training set, and a fine-tuned open critic whose failure-mode accuracy beats every proprietary critic except GPT-6 Astra at over 30 times lower cost.

# Q10 Next Steps

* **Independent labels at scale.** Human-label a larger stratified sample, especially outside RoboDojo, and report agreement before any adjudication (reader suggestion).
* **Other policies.** Run the same pipeline on other frontier agents and on VLAs retrofitted to emit intents, so that conclusions are about direct control rather than about GPT-6 Astra (reader suggestion; the paper notes retrofitting VLAs is non-trivial).
* **Task-level choice errors.** Add a check of the intent itself against the task (did the agent intend the right object?) to complement Choice, which only checks action against intent (reader suggestion).
* **Online critic.** Use the cheap fine-tuned critic as an online monitor for lost objects (9.5% of Grasp failures are actions with an already empty gripper) and for retries on Alignment, the mode recovery rarely fixes; test at scale beyond the single DexJoCo case.
* **Precision and latency.** Since closure offsets and millimeter-scale mating dominate, test depth or tactile input and finer 3D localization, and report latency alongside success (reader suggestion).
* **Intent statements elsewhere.** [Intent Contracts](2611.24025.md) likewise asks the actor to state intent per step, there as an authorization record; both show that intent checks catch inconsistency between saying and doing, not a wrong choice of target (reader connection).

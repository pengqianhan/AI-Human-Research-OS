Next we should build the enviroment for AI agent. As the AI agent have limited context window, we can not give them all the information to them. We should 'progressive disclosure'. As google release the OKF, which is a open knowledge foundation, we can use the OKF to build a knowledge graph or filesystem for our research. 

In order to make the AI agent have a clear context window, we should not give them too much tool, so I design the Research-skills-hub, which including all the academic related skills. When the AI agent need one or some of them, they can install from the Research-skills-hub. Just like what we do in the appstore. 

in the root path, we start a Orchestrator, which can create workers (sub-agents) to perform tasks in their own folder. If they need any skills, the Orchestrator can install the skills from the Research-skills-hub.

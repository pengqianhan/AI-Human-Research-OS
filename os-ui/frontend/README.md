# os-ui/frontend

This is the browser UI for the read-only Research OS desktop. It is a Vite +
React + TypeScript + Tailwind app. It does not produce data by itself; it reads
`public/state.json`, which is generated by `os-ui/generator/`.

The frontend polls `state.json` every five seconds. If the file is missing, it
shows an empty state with the generator command. If fields are missing, it shows
honest empty values instead of inventing repository state.

## Run

First generate `state.json`:

```bash
cd os-ui/generator
uv run python generate.py
```

Then start the frontend:

```bash
cd os-ui/frontend
npm install
npm run dev
```

The dev server usually opens at `http://localhost:5173/`.

Build:

```bash
cd os-ui/frontend
npm run build
```

The build output goes to `dist/`, which is gitignored.

## Common Edits

- Colors and fonts: edit CSS variables in `src/index.css` and aliases in
  `tailwind.config.js`.
- App names, icons, and default window sizes: edit `src/desktop/apps.tsx`.
- Dock copy commands: edit constants in `src/desktop/Dock.tsx`.
- Skill install command construction: edit `src/lib/skills.ts`. The
  per-location enable/disable toggle lives in `src/components/SkillInstalls.tsx`
  and posts to the Vite middleware in `skill-toggle-plugin.ts`.
- `state.json` shape: update `src/types.ts`, `os-ui/DESIGN.md`, and the
  generator together.
- Fixed UI copy: edit the page or component that owns the text. Dynamic
  repository content from `state.json` should stay as source data, not be
  rewritten in the frontend.

## English-first Policy

The UI is currently English-first. Do not add a language switch or i18n layer
yet. Chinese support can be added later when the OS is stable enough to justify
the maintenance cost.

`os-ui/README_zh.md` keeps the Chinese overview for reference. Runtime UI,
generator messages, and current docs should remain English unless a later task
explicitly opens Chinese localization work.

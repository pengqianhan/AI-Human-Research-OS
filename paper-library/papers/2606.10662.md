# Summary

This paper introduces Decentralized Language Models (DeLM), a multi-agent system design where parallel agents coordinate through shared verified context and a task queue instead of a single central controller. Agents claim subtasks asynchronously, read accumulated progress, reason locally, and write compact verified updates back to the shared context.

The motivation is that centralized multi-agent orchestration can become a communication and integration bottleneck as the number of subtasks grows.

# Key Ideas

* Replace centralized task assignment and result merging with decentralized workers using a shared context substrate.
* Keep shared context compact and verified so agents can build on prior progress without forwarding every update through a controller.
* Use the design for test-time scaling in software engineering and long-context reasoning.

# Experiments

* SWE-bench Verified: reports best performance across Avg.@1, Pass@2, and Pass@4, with gains up to 10.5 percentage points over the strongest baseline.
* Cost: reports roughly 50 percent lower cost per task.
* LongBench-v2 Multi-Doc QA: reports highest average accuracy across four frontier model families, with gains up to 5.7 percentage points over the strongest baseline.

# Summary

This paper introduces OpenSkill, a framework for open-world self-evolution of LLM agents. The core setting assumes the deployed agent receives only a task prompt and cannot rely on curated skills, successful trajectories, verifier signals, or target-task supervision.

OpenSkill bootstraps a learning loop by acquiring grounded knowledge and verification anchors from documentation, repositories, and the web. It synthesizes those anchors into transferable skills, then refines the skills against self-built virtual tasks.

# Key Ideas

* Treat open-world resources as the source of both knowledge and practice environments.
* Build skills and verification signals from scratch rather than assuming they already exist.
* Reserve target-task supervision for final evaluation rather than training.
* Test whether learned skills transfer across target agents and models.

# Experiments

* Reports best automated pass rate across three benchmarks and two target agents while satisfying the no-supervision constraint.
* Reports that learned skills transfer across models without model-specific adaptation.
* Reports that the self-built verifier aligns with ground-truth outcomes despite not accessing them during skill construction.

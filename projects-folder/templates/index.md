# Templates

Reusable project templates. Copy one into `projects-folder/` to start a new
project, then fill the project-specific placeholders.

# Template Index

* [AI Research Template](ai_research_template/index.md) - ML/AI-research paper template for turning a research idea into a traceable project with code, figures, local references, writing state, and project memory.

# How To Use

```bash
cp -R templates/<TemplateName> <ProjectName>
```

After copying, follow the **Start Here After Copying** section in the template's own `index.md`.

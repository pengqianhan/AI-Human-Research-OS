# Projects

This folder holds individual research projects. Each project is instantiated from
a template and tracked with its own index, project memory, code, figures, local
bibliography, and paper source.

# Project Index

* [Example Project](Example_Project/index.md) - Worked example that walks one idea through the full loop: idea capture, runnable code, generated figure, local bibliography, LaTeX source, and compiled PDF.

# Templates

* [AI Research Template](templates/ai_research_template/index.md) - Reusable ML/AI-research paper template for turning a research idea into a traceable project with code, figures, references, writing state, and project memory.

# How To Add A Project

Copy the template into this folder, then fill the project-specific placeholders:

```bash
cp -R templates/ai_research_template <ProjectName>
```

After copying, start from the new project's [PROJECT_MEMORY.md](templates/ai_research_template/PROJECT_MEMORY.md), [paper_skeleton.md](templates/ai_research_template/paper_skeleton.md), and its own `index.md`. Add a line for the new project under **Project Index** above.

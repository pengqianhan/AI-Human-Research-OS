# Idea Bundles

OKF bundles for capturing, developing, and promoting research ideas.

## Capture an idea

- Use `ideas/<slug>.md` for a lightweight idea concept. Use a nested bundle
  with its own `index.md` when the idea needs local notes, examples, or history.
- Idea concepts use the repository's OKF profile: `type: Idea`, plus `title`,
  `description`, `status`, `created`, and optional `tags` when they carry useful
  information.
- Add the concept to this index; for a nested bundle, also update its local
  `index.md`.

## Promote an idea

Follow the [project-template instantiation contract](../projects-folder/templates/index.md),
then set the idea's `status` to `promoted`, link the instantiated project, and
add it to the Active Projects table in [global memory](../memory/MEMORY.md).
